# Waterfall Designer (конструктор схем водоспаду)

![Waterfall Designer на пристрої](annotated/app-109.jpg){ width="360" }

*Скріншот з пристрою: [Утиліти](Screens-Other#shot-109).*

Waterfall Designer створює й редагує власні кольорові палітри водоспаду. Під час редагування показується живий водоспад, тож ефект змін видно одразу. Профілі зберігаються як файли в теці `WATERFALLS/` на SD-карті й можуть замінити активну кольорову схему водоспаду.

> **Примітка:** зміни під час редагування видно в реальному часі, але вони автоматично скасовуються, коли ви виходите із застосунку — якщо явно не натиснути **Apply**. Лише після Apply палітра стає активною назавжди.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Порядок роботи

1. Натисніть **New** для нового профілю або **Open**, щоб завантажити наявний з `WATERFALLS/`.
2. Виберіть зі списку рівень сигналу (0–255 — сила сигналу).
3. Натисніть **Edit color**, щоб відкрити вибір кольору й призначити RGB-колір цьому рівню.
4. **Add level** / **Remove level** — вставити або видалити точки кольору палітри.
5. **Save** — записати профіль у файл у `WATERFALLS/`.
6. **Apply** — зробити профіль активною схемою водоспаду й вийти.

## Елементи керування

- **New** — новий порожній профіль.
- **Open** — відкриває файловий менеджер для завантаження профілю з `WATERFALLS/`.
- **Save** — зберігає профіль. Після збереження показується ім'я файлу.
- **Add level** (+) — додає нову точку кольору.
- **Remove level** (−) — видаляє вибрану точку кольору.
- **Edit color** — відкриває вибір кольору для вибраного рівня.
- **Apply** — застосовує профіль як активну палітру водоспаду й виходить.

## Вибір кольору

- **Index** — рівень сигналу, до якого застосовується колір (0–255): 0 — найслабший (тло), 255 — найсильніший.
- **R / G / B** — червона, зелена, синя складові, кожна 0–255.
- **Step** — крок зміни R/G/B енкодером.
- **Save** — підтвердити колір і повернутися.

## Налаштування радіо

Живий водоспад повністю працює під час редагування — можна налаштуватися на реальний сигнал і оцінити палітру на справжніх даних.

- **Frequency** і **крок частоти** — стандартне керування частотою RX.
- **RF Amp**, **LNA**, **VGA** — стандартне підсилення.

## Файли

Профілі зберігаються в `WATERFALLS/` на SD-карті. Налаштування — у `rx_wtf_designer.ini`. Готові схеми — див. [Кольорові схеми водоспаду](waterfalls-color-schemes).
