# ADS-B(S) TX (симуляція транспондера літака)

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

!!! danger "НЕБЕЗПЕЧНИЙ застосунок"
    HackRF може генерувати дійсні повідомлення ADS-B, які, якщо їх випромінити, можуть вплинути на те, як справжні літаки й навігаційні системи «бачать» одне одного. Застосунок можна використовувати **лише в повністю закритому ВЧ-середовищі без передавання в ефір**. Призначений виключно для експериментів. Будь-яка незаконна діяльність суворо заборонена. Не для осіб до 18 років. Усі експерименти — на ваш власний ризик.

ADS-B TX генерує й передає повідомлення ADS-B Mode S на 1090 МГц, імітуючи транспондер літака. Кадри можуть нести позицію, позивний, швидкість і код squawk, видимі приймачам ADS-B у межах дальності.

Поле адреси ICAO24 **спільне для всіх чотирьох вкладок**. Кожна вкладка додає окремо вмикуваний тип повідомлення. Налаштування вкладок **не зберігаються** — лишаються тільки частота, підсилення й AMP (у `tx_adsb.ini`).

## ICAO24 (усі вкладки)

- **ICAO24** — 6-значна **шістнадцяткова** адреса літака (наприклад, `4CA1E0`). Ця 24-бітова адреса Mode S призначається кожному зареєстрованому літаку. Вводиться енкодером по кожній цифрі.

## Вкладка Position

Увімкніть **Transmit position** для повідомлень про позицію (DF17 Type 9–18).

- **Alt** — висота у футах (−1000…50000).
- **Lat** — широта в градусах°хвилинах'секундах" (−90…+90). Праворуч — десятковий еквівалент.
- **Lon** — довгота (−180…+180).
- **Set from map** — відкриває карту; торкніться місця, щоб перенести координати, **OK** підтверджує.

## Вкладка Callsign

Увімкніть **Transmit callsign** (DF17 Type 1–4). **Callsign** — до 8 символів (за замовчуванням `TEST1234`).

## Вкладка Speed

Увімкніть **Transmit speed** (DF17 Type 19).

- **Speed** — шляхова швидкість у вузлах (0–999, крок 5).
- **Bearing** — курс (0–359°). Компас у кутку показує напрямок.
- **Vertical rate** — вертикальна швидкість у футах/хв (−4096…+4096, крок 64); додатне — набір висоти.

## Вкладка Squawk

Увімкніть **Transmit squawk** (DF17 squawk). **Squawk** — 4-значний **вісімковий** код (кожна цифра 0–7). Деякі коди мають стандартні значення: 7700 — загальна аварія, 7600 — відмова радіо, 7500 — захоплення.

## Спільні елементи

- **Frequency** — зафіксовано на **1090,000 МГц**. Не змінюйте для коректної симуляції.
- **LNA gain** (0–47 дБ), **RF Amp** (0 або 14 дБ).
- **Start / Stop** — почати/зупинити. Усі ввімкнені вкладки передають кадри циклічно.
