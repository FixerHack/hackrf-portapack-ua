# Calculator (калькулятор RPN)

![Calculator на пристрої](annotated/app-097.jpg){ width="360" }

*Скріншот з пристрою: [Утиліти](Screens-Other#shot-097).*

**Calculator** — програмований науковий калькулятор зі зворотною польською нотацією (RPN), мовою FORTH, на основі рушія [IVT (IVEE-TINY)](https://github.com/zooxo/ivee) від zooxo/deetee.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Що таке RPN?

У RPN спочатку вводять числа, а потім операцію. Замість `3 + 4` ви вводите `3`, потім `4`, потім `+`. Числа кладуться на стек; операції беруть значення з вершини стека й кладуть результат назад.

- **D** (DUP) — кладе/дублює поточне число на стек або підтверджує введення числа.
- **C** (DROP) — прибирає вершину стека або очищує поточне введення.

**Приклад:** щоб порахувати (3 + 4) × 2, натисніть `3 D 4 + 2 F ×` (× — у шарі F).

## Розкладка клавіатури

Клавіатура має два режими. Натисніть **F**, щоб перемкнути на другий шар.

### Звичайний режим

| Стовпець 1 | Стовпець 2 | Стовпець 3 | Стовпець 4 |
|-------|-------|-------|-------|
| **F** (shift) | **7** | **8** | **9** |
| **E** (10^x) | **4** | **5** | **6** |
| **N** (зміна знака) | **1** | **2** | **3** |
| **C** (DROP/очистити) | **0** | **.** (крапка) | **D** (DUP/ввести) |

### Режим F (спершу натисніть F)

| Стовпець 1 | Стовпець 2 | Стовпець 3 | Стовпець 4 |
|-------|-------|-------|-------|
| **MENU** | **SUM+** | **PRG** | **/** |
| **SWAP** | **DICT** | **USR** | **\*** |
| **ROT** | **RCL** | **STO** | **-** |
| **CA** | **PI** | **INT** | **+** |

## Довідка по клавішах

| Клавіша | Опис |
|-----|-------------|
| **0–9, .** | Цифри й десяткова крапка |
| **E** | Експонента наукової нотації (Y × 10^X) |
| **N** | Зміна знака |
| **D** | DUP — дублювати вершину стека / підтвердити введення |
| **C** | DROP — прибрати вершину стека / очистити введення |
| **F** | Перехід на шар функцій; подвійне натискання відкриває меню користувача |
| **+ − × ÷** | Базова арифметика |
| **SWAP** | Поміняти два верхні значення (1 2 → 2 1) |
| **ROT** | Обернути стек (1 2 3 → 2 3 1) |
| **STO / RCL** | Зберегти/викликати число з комірки пам'яті 0–9 (спершу введіть номер комірки) |
| **CA** | Очистити все — стек і статистичні комірки |
| **PI** | Покласти π на стек |
| **INT** | Ціла частина верхнього значення |
| **SUM+** | Додати точку X (або X,Y) для статистики / лінійної регресії |
| **DICT** | Переглянути словник усіх команд |
| **USR** | Призначити запис словника до меню користувача |
| **MENU** | Відкрити меню користувача |
| **PRG** | Редагувати програму користувача (спершу введіть номер програми 0–15) |

## Функції словника

Усі команди доступні через **DICT** (F+4):

- **Математика:** `SQRT`, `POW` (y^x), `INV` (1/x), `EXP`, `LN`, `SIN`, `COS`, `TAN`, `ASIN`, `ACOS`, `ATAN`, `GAMMA` (ln Γ)
- **Стек:** `DUP`, `DROP`, `SWAP`, `ROT`, `OVER`
- **Статистика:** `SUM+`, `SUMclr`, `MEAN/STDEV`, `LR` (лінійна регресія)
- **Інше:** `PV` (поточна вартість), `ND` (нормальний розподіл, PDF/CDF), `P>R` / `R>P` (полярні/прямокутні координати), `nPr`, `nCr`, `SOLVE` (пошук кореня)
- **Керування (для програм):** `IF`, `ELSE`, `THEN`, `BEGIN`, `UNTIL`, `<`, `=`, `<>`, `>`

## Програмування

IVT підтримує до **16 програм користувача** (номери 00–15), разом до 440 кроків.

Щоб редагувати програму:

1. Введіть номер програми (наприклад, `0`, `5`).
2. Натисніть **F + PRG**.
3. Переміщайтеся кроками клавішами **E** (вгору) і **N** (вниз).
4. Вставляйте кроки натисканням клавіші або вибором зі словника DICT.
5. Видаляйте крок клавішею **.**
6. Збережіть і вийдіть клавішею **C**.

> [!NOTE]
> Програма користувача **00** зарезервована для функції **SOLVE** (пошук кореня).

## Обмеження

| Параметр | Обмеження |
|------|-------|
| Глибина стека | 24 |
| Значущих цифр | 7 |
| Комірки пам'яті (STO/RCL) | 10 (0–9) |
| Програм користувача | 16 |
| Загалом кроків програм | 440 |
| Слотів меню користувача | 32 |
| Точність чисел | IEEE 754, 32-бітове float (~6–7 десяткових цифр) |

## Приклади програм

```
ABS:    DUP 0 > IF THEN NEG
SINH:   EXP DUP INV NEG + 2 /
LOG:    LN 1 0 LN /
%:      OVER / 1 0 0 *
C<>F:   DUP 1 . 8 * 3 2 + SWAP 3 2 - 1 . 8 /
```
