# ERT Meter (комунальні лічильники)

![ERT RX на пристрої](annotated/app-048.jpg){ width="360" }

*Скріншот з пристрою: [Приймачі: огляд застосунків](Screens-Receivers#shot-048).*

## Вступ

[ERT](https://en.wikipedia.org/wiki/Encoder_receiver_transmitter) (Encoder Receiver Transmitter) — протокол компанії Itron для автоматичного зчитування лічильників води, газу й електроенергії. Використовує OOK-радіо малої дальності в неліцензованому діапазоні ISM 902–928 МГц, щоб лічильники можна було зчитувати з автомобіля. Поширений переважно в США. Підтримуються протоколи IDM, SCM і SCM+.

!!! info "В Україні"
    Діапазон 902–928 МГц і лічильники ERT в Україні не використовуються, тож застосунок, найімовірніше, нічого не прийме.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Елементи керування

- **Рядок заголовка** — звичні значки.
- **Frequency** — за замовчуванням 911,6 МГц (діапазон ISM зазвичай 902–928 МГц).
- **Підсилення** — AMP (0 = 0 дБ, 1 = 14 дБ), LNA (0–40), VGA (0–62).

## Поля на екрані

- **ID** — ідентифікатор лічильника (десятковий); має збігатися з номером чи штрихкодом на лічильнику.
- **Ty** — тип пакета: `IDM`, `SCM` або `SCM+`.
- **Consumpt** — показання споживання.
- **Tamp** — прапорці втручання. Для SCM — дві однозначні цифри (фізичне втручання / втручання в енкодер); для SCM+ та IDM — 4-значне шістнадцяткове значення.
- **Ct** — кількість прийомів від лічильника з цим ID (`++`, якщо число не вміщується).

Приймач охоплює близько 2,5 МГц навколо 911,6 МГц без канальних фільтрів — чутливість менша, зате одночасно відстежується більше «каналів».

## Журнал

Якщо є SD-карта у FAT, прийняті пакети записуються в `LOGS/ERT.TXT`, по рядку на пакет:

```
YYYYMMDDHHMMSS FREQUENCY TYPE data/errors ID:meterID
```

- `YYYYMMDDHHMMSS` — мітка часу;
- `FREQUENCY` — частота налаштування в Гц;
- `TYPE` — тип пакета;
- `data/errors` — дані після манчестерського декодування, `/` і побітовий індикатор помилок (`1` — помилка);
- `ID:meterID` — ID лічильника.

Дані, схожі на пакет, але з невірною контрольною сумою, на екрані не показуються, але записуються в журнал для налагодження. Зменшити кількість таких пакетів може зміна підсилення.
