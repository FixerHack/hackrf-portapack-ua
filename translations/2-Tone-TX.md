# 2-Tone TX (двотональний виклик)

## Вступ

Передає двотональний виклик у стилі Motorola / QCII з налаштовуваними тонами A і B, тривалістю, необов'язковою паузою й CTCSS. Корисний для стендових тестів, перевірки сумісності чи генерування відомих пейджингових послідовностей для тестування декодерів.

Це зовнішній застосунок; файл `.ppma` має відповідати версії прошивки.

!!! danger "Передавання регулюється законом"
    Цей застосунок **передає** радіосигнали. Передавання без дозволу в більшості випадків незаконне. Використовуйте лише дозволені частоти й потужність, власне обладнання або екрановане середовище. Див. [Призначення та законність](Intended-Use-and-Legality).

## Елементи керування

- **CTCSS** — тон CTCSS, що мікшується з викликом. `None` — без CTCSS.
- **A** — тон A з таблиці частот Motorola / QCII або `Custom`.
- **B** — тон B з таблиці або `Custom`.
- **ADur / BDur** — тривалість тонів A і B у мілісекундах.
- **Gap** — необов'язкова пауза між тонами A і B.
- **Timing** — пресет таймінгу: `Moto Std`, `Short Alert`, `Fire Std`, `Long Alert` або `Custom`.
- **Slot** — один із п'яти слотів збереження.
- **Save / Load** — зберегти/завантажити налаштування слота.
- **AHz / BHz** — для режиму `Custom`: пряме введення частоти в Гц.
- Рядок TX показує загальну тривалість передавання й назви тонів; рядок стану — дії (`Stopped`, `Done`).

## Поради

- Використовуйте лише легальні у вашому регіоні частоти й модуляцію.
- Тримайте девіацію й підсилення помірними при тестуванні з іншим приймачем.
- Для тестування декодера пауза `0 ms` найближча до стандартного двотонального пейджингу.
