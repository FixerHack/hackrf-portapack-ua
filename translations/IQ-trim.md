# IQ Trim (обрізання записів)

![IQ Trim на пристрої](annotated/app-090.jpg){ width="360" }

*Скріншот з пристрою: [Утиліти](Screens-Other#shot-090).*

IQ Trim обрізає «радіотишу» на початку й наприкінці файлу запису C16, C8 або CU8.

## Елементи інтерфейсу

| Поле | Опис |
|-------|-------------|
| **Capture File** | Торкніться, щоб відкрити файл `.C16`, `.C8` чи `.CU8` з теки `CAPTURES/`. |
| **Відображення IQ** | Показує потужність сигналу в 240 відрізках. Зелена лінія — позиція початку (Start), червона — кінця (End). |
| **Start** | Перший відлік області обрізання. Можна змінювати вручну; крок залежить від довжини файлу. |
| **End** | Останній відлік області обрізання. Можна змінювати вручну. |
| **Samples** | Загальна кількість відліків у файлі. |
| **Max Pwr** | Потужність (комплексна величина) найсильнішого відліку після підсилення. Показується **червоним**, якщо вибране підсилення спричинить обмеження. |
| **Cutoff** | Поріг сигнал/шум у відсотках від Max Pwr (1–100 %). За замовчуванням **7 %**. Використовується для автоматичного визначення Start/End. |
| **Amplify** | Коефіцієнт підсилення обрізаного файлу (1–9×). За замовчуванням **1×** (без підсилення). Корисно, якщо записаний сигнал був слабким. |
| **Trim** | Виконує обрізання (і підсилення). **Перезаписує файл на місці — резервна копія не створюється.** |

## Обрізання файлу

1. Відкрийте файл запису, торкнувшись поля шляху. У відображенні IQ має з'явитися потужність сигналу.
    - Якщо видимого блоку немає, сигнал був надто слабким для автоматичного виявлення.
2. Або змініть **Cutoff %**, щоб автоматично задати Start/End, або встановіть **Start** і **End** вручну.
3. За потреби збільште **Amplify**, якщо сигнал був слабким. Стежте за полем **Max Pwr** — воно червоніє, якщо буде обмеження.
4. Натисніть **Trim**. Файл буде змінено на місці.

> [!WARNING]
> Trim перезаписує оригінальний файл без резервної копії. Якщо хочете зберегти оригінал — спершу скопіюйте його у [File Manager](File-manager).

## Розділення файлу запису

Файл можна розділити на кілька, поєднавши File Manager і IQ Trim:

1. Зробіть у [File Manager](File-manager) копії оригінального файлу.
2. Відкрийте кожну копію в IQ Trim і обріжте до потрібного діапазону Start/End.
3. Отримані файли можна обрізати й далі.
