# P25 TX (цифрове радіо P25)

![P25 TX на пристрої](annotated/app-067.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-067).*

!!! danger "Критично небезпечно"
    P25 TX передає симульований службовий канал транкінгового радіо. Передавання на нелінцензованих частотах незаконне й може заважати зв'язку служб громадської безпеки. Використовуйте лише на ліцензованих частотах, в екранованому середовищі або на еквівалент навантаження.

P25 TX генерує безперервний службовий канал P25 Phase 1 (TSCC). Він перебирає пакети TSBK, що ідентифікують мережу й призначають голосові канали групам, дозволяючи радіостанціям і декодерам P25 «захопитися» на симульовану систему. Кадри передаються безперервно, доки не зупинити.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Параметри

Частота за замовчуванням 155,000 МГц, смуга 12,5 кГц, частота дискретизації 2 400 000 Гц, модуляція C4FM 9600 бод, тип кадру TSBK.

## Елементи керування (усі поля шістнадцяткові)

| Поле | Цифр | Опис | За замовч. |
|-------|--------|-------------|---------|
| **NAC** | 3 | Код доступу до мережі | `293` |
| **SYS** | 3 | ID системи | `001` |
| **WACN** | 5 | ID мережі широкої зони | `BEEF0` |
| **RFSS** | 2 | ID ВЧ-підсистеми | `01` |
| **SITE** | 2 | ID майданчика | `01` |
| **TG** | 4 | ID групи у повідомленнях надання каналу | `0001` |
| **VCH** | 3 | Номер голосового каналу | `001` |

- **Frequency / Gain / AMP** — стандартні (частота також вбудовується в пакет IDEN_UP).
- **Start / Stop** — почати/зупинити (статус `TX TSCC`).

Застосунок передає повторюваний цикл із 5 пакетів: IDEN_UP, NET_STATUS, RFSS_STATUS, GRP_V_GRANT, NET_STATUS.

Налаштування — у `tx_p25_tx.ini`.
