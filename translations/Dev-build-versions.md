# Версії для розробки (GCC)

Команда намагається визначити, до якої найновішої версії можна оновитися так, щоб усі розробники могли далі працювати з версією у своїй ОС/дистрибутиві.

Тестування з різними версіями компілятора GCC і апаратури показує стабільність коду й допомагає виявити періодичні проблеми (таймінг, неініціалізована пам'ять). Але якщо нічна система збирання використовує іншу версію GCC, ніж більшість розробників, для майбутніх кандидатів у релізи може знадобитися фаза тестування перед світовим анонсом.

> Вищі версії GCC містять більші бібліотеки, що займають більше нашого обмеженого простору ROM.

| @jlynx | 9.4.0 | Ubuntu (WSL) | Немає (наскільки відомо) |
| @u-foka | 13.2.1 | M1 Mac | Завеликий розмір файлу |
| @notherngineer | 9.3.1 | Debian 11 | Немає |
