# OOK Brute (перебір OOK-кодів)

![OOK Brute на пристрої](annotated/app-069.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-069).*

!!! danger "Юридичне попередження"
    Перебір кодів пультів для керування пристроями, якими ви не володієте чи не маєте дозволу, незаконний у більшості юрисдикцій — зокрема гаражні ворота, шлагбауми, системи доступу чужих будівель. Використовуйте лише на власному обладнанні для легітимного тестування безпеки.

OOK Brute послідовно передає всі OOK-коди пультів у заданому діапазоні для вибраного протоколу. Призначений для тестування простору кодів систем із фіксованим OOK-кодом — наприклад, перевірити, що власний приймач реагує на правильний код.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Налаштування

- **Protocol** — стандарт кодування: **Came12**, **Came24**, **Nice12**, **Nice24**, **Holtek12** (HT12E), **Princeton24** (PT2262).
- **Start** — перший код (десятковий).
- **Stop** — останній код. Застосунок перебирає від Start до Stop включно.
- **Frequency** — за замовчуванням 433,920 МГц.
- **Start / Stop** — почати/зупинити перебір.

Налаштування — у `tx_ookbrute.ini`.
