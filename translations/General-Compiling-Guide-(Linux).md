# Загальний посібник зі збирання (Linux, для досвідчених)

## Нотатки

- Цей посібник — на випадок, якщо ви використовуєте не надто поширений дистрибутив Linux, ви досвідчений користувач і хочете компілювати на своїй машині.
- Він лише для досвідчених і не дає покрокових інструкцій.
- Для Debian та похідних, а також для Arch Linux є окремі спеціалізовані посібники — скористайтеся ними.

## Базові поняття

- Проєкт використовує cmake як систему збирання.
- cmake-скрипти викликають toolchain arm-none-eabi-gcc (попри «gcc» у назві, це повний C/C++-toolchain).
- cmake-скрипти викликають linker-скрипти для реалізації зовнішніх застосунків.
- cmake-скрипти під час збирання викликають python-скрипти, що генерують деякі нестандартні файлові структури.

## «Кроки»

1. Переконайтеся, що підтягнули git-підмодулі.
2. Переконайтеся, що маєте правильний toolchain arm-none-eabi-gcc (із сайту ARM або з пакетного менеджера) і що система (й cmake) можуть його запускати.
3. Ninja і ccache підтримуються — за бажання користуйтеся.
4. Нарешті — звичайний шлях для cmake-проєкту: `mkdir build && cd build && cmake .. && make`.
