# POCSAG RX (приймач пейджерів)

![POCSAG RX на пристрої](annotated/app-022.jpg){ width="360" }

*Скріншот з пристрою: [Приймачі: огляд застосунків](Screens-Receivers#shot-022).*

Приймає повідомлення пейджерів за протоколом POCSAG. Протокол працює в діапазонах VHF/UHF з FSK-модуляцією.

!!! warning "Законність"
    Приймання пейджингових повідомлень, призначених іншим, може бути обмежене законом. Перевірте місцеві правила.

## Огляд інтерфейсу

### Налаштування

- **Frequency** — частота приймання. Змінюється енкодером, цифровою клавіатурою або завантажується з SD-карти. 439,9875 МГц — найпопулярніша світова радіоаматорська частота POCSAG (1200 біт/с).
- **RF amplifier** (0 або 1) — внутрішній ВЧ-підсилювач.
- **LNA gain** (0, 8, 16, 24, 32, 40) — підсилення LNA. Див. [Проблеми з якістю приймання](Help!-Im-not-receiving-anything!---Receive-Quality-Issues#gain-settings).
- **VGA gain** (0–62) — підсилення VGA.
- **RSSI/Audio** — верхня смужка: сила сигналу; нижня: рівень звуку (корисно для налаштування без навушників).
- **Squelch** (0–99) — мінімальний рівень сигналу для початку декодування. 0 вимикає шумоподавлювач. Вищі значення потребують сильнішого сигналу — щоб не декодувати слабкі чи зашумлені сигнали з «кашею».
- **Volume** — гучність.

### Інформація

- **Decoder Status** — стан декодера: білий — очікування, блакитний — чисто, жовтий — очікування початку повідомлення, зелений — очікування решти повідомлення.
- **Batch Count** — кількість прийнятих пакетів (у пакеті 16 кодових слів).
- **Bits** — біти, що декодуються в кодові слова.
- **Sync** — зелений, коли декодер отримав кадр синхронізації. Без нього повідомлення не декодуються.
- **Codewords** — кількість кодових слів у поточному пакеті.
- **Baud Rate** — виявлена швидкість: `05` — 512 біт/с, `12` — 1200 біт/с, `24` — 2400 біт/с.

### Кнопки

- **Ignore Last** — відкидати повідомлення на останню прийняту адресу.
- **Config** — відкриває сторінку налаштувань.

## Config

- **Enable Log** — записувати декодовані повідомлення в `LOGS/POCSAG.TXT`.
- **Log Raw Data** — також записувати кодові слова пакета в шістнадцятковому вигляді (для налагодження).
- **Use Small Font** — менший шрифт, щоб бачити більше повідомлень.
- **Hide Bad Data** — не показувати (й не записувати) кодові слова з помилкою контрольної суми.
- **Hide Addr Only** — не показувати кодові слова з адресою без тексту.
- **Filter Mode** / **Filter Address** — фільтрація за адресою: `None` — вимкнено, `Drop` — ховати повідомлення на вказану адресу, `Keep` — показувати лише на вказану адресу.
- **Beta** — вмикає новіший процесор основної смуги POCSAG (після зміни потрібен перезапуск застосунку).
- **Save** — зберегти зміни.

> **Примітка:** налаштування зберігаються й відновлюються, лише якщо ввімкнено **App Settings** у [Settings](Settings#app-settings).

## Відображення повідомлення

Типове повідомлення:

```
12:34 1200 #432123 F2
This is a test message
```

- `12:34` — **час** прийому (годинник PortaPack);
- `1200` — **швидкість** прийому;
- `#432123` — **адреса** пейджера;
- `F2` — **функція** (0–3, тип повідомлення чи категорія джерела);
- далі — **текст** повідомлення.

Повідомлення **пурпуровим** містять багато помилок декодування й можуть бути ненадійними.
