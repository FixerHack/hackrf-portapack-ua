# KeeLoq TX (передавання плаваючого коду KeeLoq)

![KeeLoq TX на пристрої](annotated/app-075.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-075).*

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

!!! danger "Юридичне попередження"
    Передавання сигналів KeeLoq до гаражних воріт, шлагбаумів чи автомобілів, якими ви не володієте або не маєте дозволу, незаконне в більшості юрисдикцій. Застосунок призначений для тестування власного обладнання й досліджень безпеки систем, які ви маєте право оцінювати.

KeeLoq TX повторно передає сигнали KeeLoq з плаваючим кодом із файлів `.keeloq`. Ці файли створює приймач [SubGhzD](SubGhzD) кнопкою Save на прийнятому пакеті KeeLoq чи Superrollo. Застосунок відтворює зашифроване навантаження за захопленим серійним номером, лічильником, кодом кнопки й варіантом навчання KeeLoq.

Підтримувані режими:

- **KeeLoq simple learning** — 64-бітовий OOK-кадр при Te=400 мкс;
- **KeeLoq normal learning** — 64-бітовий OOK-кадр при Te=400 мкс;
- **Superrollo (GW60/HCS361)** — 67-бітовий OOK-кадр при Te=450 мкс (вибирається автоматично для файлу з `mf_name=Superrollo`).

Для всіх режимів у `KEELOQKEYS/MFCODES` має бути правильний ключ виробника. Без ключа передавання не згенерувати коректно.

## Налаштування

- **Open file** — вибрати `.keeloq` з `KEELOQREMOTES/`.
- **Serial** — 28-бітовий серійний номер із файлу.
- **Counter** — 16-бітовий лічильник синхронізації (редагується).
- **Button** — код кнопки (0–15).
- **Repeat** — кількість повторів (за замовчуванням 4).
- **Payload** — живий перегляд зашифрованого кадру (hex).
- **Transmit / Stop** — почати/зупинити.

## Файл ключів (MFCODES)

Шифрування KeeLoq потребує 64-бітового ключа виробника для бренду. Ключі — у `KEELOQKEYS/MFCODES` (у прошивці його немає, створюється вручну). Формат — один запис у рядку через крапку з комою:

`mf_name;key_hex;type`

| Поле | Опис |
|---|---|
| `mf_name` | Назва виробника, як її розпізнає SubGhzD (наприклад, `Superrollo`) |
| `key_hex` | 64-бітовий ключ у hex (16 символів) |
| `type` | Режим: `1` = simple, `2` = normal |

Приклад: `Superrollo;XXXXXXXXXXXXXXXX;1`. Ключ не поширюється публічно й здобувається самостійно (наприклад, апаратним аналізом мікросхеми передавача).

Налаштування — у `tx_keeloq.ini`.
