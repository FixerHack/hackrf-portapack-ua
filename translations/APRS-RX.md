# APRS RX (приймач APRS)

![APRS RX на пристрої](annotated/app-019.jpg){ width="360" }

*Скріншот з пристрою: [Приймачі: огляд застосунків](Screens-Receivers#shot-019).*

> [!NOTE]
> Це [зовнішній застосунок](External-apps-informations); має бути на SD-карті в теці `APPS/`.

Застосунок APRS RX приймає й показує повідомлення протоколу APRS (Automatic Packet Reporting System) — радіоаматорської системи передавання позицій і коротких повідомлень. Він показує живий список прийнятих станцій: позивний, позицію (якщо є), кількість прийомів і час останнього прийому.

## Готові регіони

Виберіть регіон — частота налаштується автоматично:

| Код | Частота | Регіон |
|------|-----------|--------|
| MAN | задається вручну | Ручний режим |
| NA | 144,390 МГц | Північна Америка |
| NZ | 144,575 МГц | Нова Зеландія |
| JAP | 144,640 МГц | Японія |
| PHI | 144,740 МГц | Філіппіни |
| **EUR** | **144,800 МГц** | **Європа / Велика Британія — використовуйте в Україні** |
| THA | 144,900 МГц | Таїланд |
| AUS | 145,175 МГц | Австралія |
| BR | 145,570 МГц | Бразилія |
| ISS | 145,825 МГц | Міжнародна космічна станція |

Коли вибрано регіон, частота оновлюється автоматично. Якщо після цього змінити частоту вручну, вибір регіону перемкнеться на **MAN**.

Частоти поза списком налаштовуються вручну (MAN), наприклад **432,500 МГц** (Європа, UHF).

!!! info "На вашому знімку"
    Вибрано MAN з частотою 144,390 МГц (північноамериканська). Для України виберіть **EUR**.

## Елементи керування

### Частота

- обертайте енкодер над полем частоти, щоб змінювати кроками;
- натисніть середню кнопку над полем частоти, щоб ввести вручну;
- завантажте частоту з SD-карти через менеджер частот.

### Налаштування радіо

Зліва направо:

- **AMP** — ВЧ-підсилювач: `0` — вимкнено, `1` — увімкнено (+14 дБ). Вмикайте для слабких сигналів.
- **LNA** — підсилення ПЧ (0–40 дБ кроками по 8 дБ).
- **VGA** — підсилення основної смуги (0–62 дБ кроками по 2 дБ).

Докладніше — [Основні елементи керування](Main-Controls).

### Гучність

Гучність показується після смужок сили сигналу. Регулюється енкодером, коли поле в фокусі.

## Список станцій

| Стовпець | Опис |
|--------|-------------|
| Source | Позивний станції (із SSID, якщо є) |
| Location | GPS-координати, якщо пакет містив звіт про позицію |
| Hits | Скільки разів станцію прийнято |
| Time | Час останнього пакета |

Торкніться чи виберіть запис, щоб відкрити **детальний вигляд**.

Вкладки **Stream** і **List** угорі перемикають між потоком прийнятих пакетів і списком станцій.

## Детальний вигляд

Показує повну декодовану інформацію пакета APRS, включно з «сирим» вмістом поля info. Кнопки:

- **Done** — повернутися до списку;
- **See Map** — відкрити карту з центром на позиції станції. Видима лише, якщо станція передала дійсну позицію GPS.

## Журнал

Прийняті пакети автоматично записуються на SD-карту в `LOGS/APRS.TXT`. Кожен рядок — «сирий» декодований потік APRS. Журнал працює, поки застосунок запущено й є SD-карта, доступна для запису.

## Важливі примітки

- APRS RX на HackRF відносно малочутливий. Увімкніть **AMP**, якщо не приймаєте станції, які чітко чути на окремому приймачі.
- ⚠️ Не підключайте сильні сигнали безпосередньо — HackRF не має вхідного захисту.
- Деякі станції передають ширшою смугою за типові 8,5 кГц. Якщо пропускаєте пакети, збільште смугу в файлі налаштувань на SD-карті:
    1. Відкрийте `SETTINGS/rx_aprs.ini` у File Manager.
    2. Виберіть файл, натисніть вниз, щоб вибрати значок олівця, натисніть OK.
    3. Знайдіть рядок `nbfm_config_index` і змініть значення: `0` = 8,5 кГц (за замовчуванням), `1` = 11 кГц, `2` = 16 кГц.

## Протокол

APRS передається через **AX.25** модемом **Bell 202** на **1200 біт/с** (AFSK): тон **1200 Гц** — *mark* (двійкова 1), **2200 Гц** — *space* (двійковий 0).

## SSID (вторинний ідентифікатор станції)

SSID — числовий суфікс до позивного, щоб розрізняти кілька станцій одного позивного. APRS дозволяє 16 SSID (0–15); рекомендовані значення:

| SSID | Типове використання |
|------|-------------|
| 0 | Основна станція, зазвичай стаціонарна й з підтримкою повідомлень |
| 1–4 | Додаткові станції (діджипітер, мобільна, метео тощо) |
| 5 | Інші мережі (D-STAR, смартфони тощо) |
| 6 | Спеціальні активності, супутникові сеанси тощо |
| 7 | Портативні радіостанції |
| 8 | Човни, яхти, автобудинки або друга основна мобільна |
| 9 | Мобільні станції чи трекери |
| 10 | Інтернет, iGate, Echolink, Winlink, AVRS, APRN тощо |
| 11 | Аеростати, літаки, космічні апарати тощо |
| 12 | APRStt, DTMF, RFID, односпрямовані трекери тощо |
| 13 | Метеостанції |
| 14 | Далекобійники |
| 15 | Додаткові станції |
