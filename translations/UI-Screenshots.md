# Скриншоти UI (ресурси для документації)

Ця сторінка — галерея скриншотів інтерфейсу, які можна використовувати в документації. У вихідній вікі вони вставляються через wiki-синтаксис `[[img/screenshots/Назва.png]]`.

Доступні скриншоти (у теці `img/screenshots/`): меню Main, Receive, Transmit, Tools, Options, Debug, HackRF, а також окремі застосунки — ADS-B, AIS Boats, AFSK, Analog TV, Audio, BTLE, ERT Meter, NRF, POCSAG, Radiosonde, TPMS, Scanner, Replay, Capture; передавачі — APRS, BHT, Burger Pager, GPS Sim, Jammer, Key fob, LGE Tool, Mic, Morse, OOK, RDS, Soundboard, SSTV, TEDI/LCR, TouchTunes; утиліти — Antenna length, File manager, Freq manager, Signal gen, Wave viewer, Wipe SD card; екрани Debug (Buttons test, Memory, Peripherals: AK4951, MAX2837, RFFC5072, Si5351C, Temperature, SD Card) та About.

> Це оригінальна галерея англійської вікі. Для української локалізації ми зробили власний набір анотованих скриншотів — див. розділ **Моє залізо / Екрани** та сторінки застосунків.
