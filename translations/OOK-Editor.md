# OOK Editor (редактор OOK-сигналів)

![OOK Editor на пристрої](annotated/app-070.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-070).*

OOK Editor — передавач OOK у вільній формі. На відміну від [OOK TX](OOK), він не використовує готові протоколи мікросхем — ви задаєте навантаження біт за бітом: вводите напряму, складаєте «Bug Key» або завантажуєте файл `.OOK` з SD-карти.

Це дещо вдосконалена версія застосунку ROOK від @sasaga.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

!!! danger "Передавання регулюється законом"
    Цей застосунок **передає** радіосигнали. Передавання без дозволу в більшості випадків незаконне. Використовуйте лише дозволені частоти й потужність, власне обладнання або екрановане середовище. Див. [Призначення та законність](Intended-Use-and-Legality).

## Елементи керування

- **Frequency / Gain / AMP** — стандартні (за замовчуванням 433,920 МГц).
- **SampleRate** — частота дискретизації: 250k, 1M, 2M, 5M, 10M, 20M Гц.
- **Step** — крок зміни SymbolRate/PauseSymbol: 1, 10, 100.
- **SymbolRate** (0–9999) — символів за секунду.
- **Repeat** (1–999) — повторів навантаження.
- **PauseSymbol** (0–9999 мкс) — пауза між повторами.
- **Payload** — бітовий рядок (`0` = несуча вимкнена, `1` = увімкнена).
- **Set** — ввести навантаження вручну.
- **Open File / Save File** — завантажити/зберегти `.OOK` у `OOKFILES/`.
- **Bug Key** — композитор шаблону (додає повторювані біти 0 чи 1 заданими кроками: Primary Step для коротких кнопок `0`/`1`, Secondary Step для довгих `00`/`11`).
- **Waveform** — живий перегляд.
- **Send / Stop** — почати/зупинити.
