# Процес завантаження

Процес завантаження — трохи божевільний, але це виправдане божевілля.

## Огляд

Завантажувач LPC4320 ініціалізує ядро Cortex-M4F для старту з початку зовнішнього SPI-флешу. Ядро M0 лишається в скиданні. Bootstrap-код виконується з SPI-флешу на Cortex-M4F. Bootstrap ініціалізує Cortex-M0 на виконання коду застосунку з SPI-флешу, а потім засинає. Код застосунку копіює baseband-код у RAM, налаштовує Cortex-M4F на виконання з RAM, потім скидає Cortex-M4F, щоб почати виконання baseband.

## Bootstrap

В образі PortaPack bootstrap-образ Cortex-M4F розташований на початку SPI-флешу й виконується вбудованим завантажувачем LPC4320. Тактова частота M4 вже встановлена на 96 МГц. Bootstrap-код налаштовує SPIFI на (приблизно) максимальну швидкість, потім ініціалізує карту пам'яті Cortex-M0 на образ «application» у SPI-флеші й виводить Cortex-M0 зі скидання. Після цього bootstrap присипляє Cortex-M4, доки застосунок на M0 не потребує запустити на ньому baseband-прошивку.

## Застосунок (ядро Cortex-M0)

Послідовність завантаження на M0:

```
ResetHandler:
    Ініціалізувати вказівник стеку процесу
    Ініціалізувати області стекового RAM (заповнити шаблоном)
    __early_init()
        Увімкнути додаткові винятки процесора для налагодження
    Ініціалізувати сегмент data (копіювати SPI-флеш -> data у RAM)
    Ініціалізувати BSS (заповнити область RAM нулями)
    __late_init()
        reset()  — скидання більшості периферії (крім SCU, SPIFI, M0APP)
        halInit() — hal_lld_init, palInit, gptInit, i2cInit, sdcInit, spiInit, rtcInit, boardInit
        chSysInit() — port_init, scheduler, vt, core, heap, увімкнення, створення idle-потоку
    Конструктори
    main()
    Деструктори
    _default_exit() — while(1);
```

## Baseband (ядро Cortex-M4F)

Стадії, крізь які проходить baseband-образ, аналогічні, але: ініціалізується FPU; у hal_lld_init налаштовуються SysTick і DWT як лічильник циклів; baseband не керує апаратурою, тож апаратної ініціалізації тут немає.

> Оригінальна вікі — sharebrained, [Boot Process](https://github.com/sharebrained/portapack-hackrf/wiki/Boot-Process).
