# RDS TX (передавання даних RDS)

![RDS TX на пристрої](annotated/app-058.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-058).*

RDS TX передає дані системи радіоданих (RDS) на піднесучій 57 кГц FM-сигналу. Дозволяє транслювати назву станції, тип програми, ID програми, прапорці дорожніх повідомлень і текст, що прокручується, на RDS-сумісні FM-приймачі.

Чотири вкладки: **Name**, **Text**, **Time**, **Audio**. Працюють лише Name і Text; Time та Audio показують «Not yet implemented».

!!! danger "Передавання регулюється законом"
    Цей застосунок **передає** радіосигнали. Передавання без дозволу в більшості випадків незаконне. Використовуйте лише дозволені частоти й потужність, власне обладнання або екрановане середовище. Див. [Призначення та законність](Intended-Use-and-Legality).

## Параметри

Частота зберігається в постійній пам'яті, крок 50 кГц, смуга 1,75 МГц, частота дискретизації 2,28 МГц, підсилення TX 0–47 дБ (LNA), 0/14 дБ (AMP). Налаштування — у `tx_rds.ini`.

## Спільні елементи (усі вкладки)

- **Program type (PTY)** — 32 варіанти (0–31): None, News, Affairs, Info, Sport, Educate, Drama, Culture, Science, Varied, Pop, Rock, Easy, Light, Classics, Other, Weather, Finance, Children, Social, Religion, PhoneIn, Travel, Leisure, Jazz, Country, National, Oldies, Folk, Docs, AlarmTst, Alarm.
- **Program ID (PI)** — 4-значне hex-значення (0000–FFFF).
- **TP** — прапорець, станція регулярно передає дорожню інформацію.

## Вкладка Name

- **Transmit PSN** — передавати назву станції.
- **PSN** — назва на FM-приймачах (до 8 символів, за замовчуванням `TEST1234`). Кнопка **Set**.
- **Stereo** — біт DI (стереозвук).
- **Music** — біт MS (музика/мова).
- **Traffic announcement (TA)** — активне дорожнє оголошення.

## Вкладка Text

- **Transmit Radiotext** — передавати RadioText.
- **Text** — текст, що прокручується (до 28 символів, за замовчуванням `Radiotext test ABCD1234`). Кнопка **Set**.

## Запуск

Кнопка **Start** унизу починає передавання. Усі ввімкнені вкладки (PSN та/або Radiotext) передаються по черзі.
