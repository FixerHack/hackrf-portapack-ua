# SolveBoard: проблема → розв'язок

Швидка таблиця «проблема → розв'язок». Повний перелік статей — на сторінці [Усунення несправностей](Troubleshooting).

| № | Проблема | Розв'язок |
|---|---|---|
| 1 | Не завантажується / білий екран / чорний екран | Див. [Не завантажується](Won't-boot) і [Меню конфігурації](Config-Menu). |
| 2 | Вмикається лише раз після прошивання | Прошивання через DFU записує прошивку лише в ОЗП. Потрібно ще раз прошити у SPI flash (звичайним способом) — див. [Оновлення прошивки](Update-firmware). |
| 3 | Збій / Guru Meditation | Спробуйте [Повне скидання](Full-reset). Якщо не допомогло — [Оновлення Xilinx CPLD на платі HackRF](Updating-the-Xilinx-CPLD-on-hackrf-board). Якщо ніщо не працює — [повідомте про проблему на GitHub](https://github.com/portapack-mayhem/mayhem-firmware/issues/new/choose). |
| 4 | Зависає під час запуску певного застосунку (без збою чи Guru Meditation) | Переважно це проблема живлення. Спробуйте: повністю зарядити; замінити акумулятор; підключити до надійного джерела живлення; змінити щонайменше 5 кабелів; від'єднати плату розширення, якщо вона підключена. |
| 5 | Немає заставки / немає часу й дати / не працює сенсорний екран / зник значок рядка стану / неправильне вимкнення підсвічування / дивно працює енкодер | Перевірте [налаштування](Settings). |
| 6 | Пише «xxx missing» / «can't find xxx» / «xxx read error» / «xxx is outdated» / «xxx empty» або ви не бачите xxx | Переконайтеся, що вміст SD-карти відповідає [версії прошивки](https://github.com/portapack-mayhem/mayhem-firmware/releases). |
| 7 | Після оновлення застосунки зникли або неактивні (сірі) | Переконайтеся, що [вміст SD-карти](Update-firmware#update-sdcard-files) відповідає [версії прошивки](https://github.com/portapack-mayhem/mayhem-firmware/releases), особливо тека APPS, і що ви [правильно поклали вміст SD-карти](Update-firmware#update-sdcard-files). |
| 8 | `hackrf_info` пише `Hardware does not appear to have been manufactured by Great Scott Gadgets` | У вас клон HackRF, а не оригінал від GSG. Якщо вважаєте, що це помилка, зверніться до продавця або офіційної підтримки GSG. |
| 9 | Несподіваний сплеск на водоспаді / IQ / спектрі | Це або [зміщення постійної складової (DC offset)](hackrf/troubleshooting#bigspike), або шум від живлення. Щоб зменшити шум, працюйте від внутрішнього акумулятора. З DC offset нічого не зробити, для SDR це нормально. |
| 10 | Комп'ютер не бачить HackRF | Спробуйте щонайменше 5 різних кабелів. У Windows встановіть драйвери з пакета релізу. Також спробуйте [Zadig](https://zadig.akeo.ie/). Якщо не працює — спробуйте на комп'ютері з Linux (не Ubuntu). |
| 11 | Soundboard не бачить мої файли, хоча File Manager бачить | Підготуйте файли за інструкцією [Soundboard](Soundboard). |
| 12 | Під час передавання / відтворення гасне екран | Перевірте [прихований режим](Stealth-Mode). |
| 13 | Збій / зависання під час запису / не видно файлів, хоча вміст SD-карти покладено правильно | Переконайтеся, що SD-карта у форматі FAT32 і що це карта відомого виробника з прийнятною якістю. |
| 14 | Не працює GPS-симуляція / не працює Bluetooth | Більшість сучасних пристроїв перевіряють GPS через мобільну мережу. Перевірте в **Settings → Radio**, що «Reference Source» показує «External» або «portapack». Якщо ні — позначте останній прапорець і перевірте, чи стало краще. |
| 15 | Дуже повільне заряджання | Спробуйте щонайменше 5 кабелів. Використовуйте хороший адаптер, наприклад **фірмовий** 5 В 1 А. Не заряджайте від комп'ютера чи ноутбука. |
| 16 | Як увімкнути / вимкнути | Одне з цього може вмикати, а інше вимикати: одне натискання енкодера; подвійне натискання; довге натискання; підключення USB-кабелю; від'єднання USB-кабелю. |
| 17 | Replay показує порожній список | Ви натиснули не ту кнопку. Див. [Replay](Replay). |
| 18 | Проблеми з SD-картою | Використовуйте **фірмову** SD-карту від надійного продавця; формат FAT32; правильно покладений вміст SD-карти, що відповідає версії прошивки. |
| 19 | DFU suffix CRC doesn't match / Cannot open DFU device | У Windows встановіть драйвери з пакета релізу. Також спробуйте [Zadig](https://zadig.akeo.ie/). Якщо не працює — спробуйте на Linux (не Ubuntu). |
| 20 | Підсвічування ніколи не вимикається автоматично, хоча тайм-аут налаштовано | Налаштуйте поріг автоматично: [Settings → Touchscreen Threshold](Settings#touchscreen-threshold). |
| 21 | Проблеми з диском / ручкою / енкодером | У налаштуваннях спробуйте всі варіанти чутливості диска й множника швидкості — [Encoder Dial](Settings#encoder-dial). |
| 22 | На екрані «FLASH ERR» | Прошивку записано неправильно — наприклад, ви від'єднали пристрій під час прошивання. Якщо ви впевнені, що все зробили правильно, а напис лишається, — можливо, пошкоджена SPI flash на платі HackRF. |
| 23 | Щось інше | Дивіться інші теми в розділі [Усунення несправностей](Troubleshooting). |
| 24 | Мені не подобаються деякі застосунки | Див. [тут](What-if-I-don't-like-some-of-the-apps). |
