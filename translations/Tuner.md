# Tuner (камертон)

![Tuner на пристрої](annotated/app-104.jpg){ width="360" }

*Скріншот з пристрою: [Утиліти](Screens-Other#shot-104).*

**Tuner** відтворює еталонні тони через аудіовихід PortaPack, щоб налаштовувати музичні інструменти на слух.

!!! note "Не плутати"
    Це не інструмент для калібрування частоти радіо. Для корекції частоти HackRF використовуйте [Settings → Freq. Correct](Settings#freqcorrect).

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Елементи керування

| Поле | Опис |
|-------|-------------|
| **Instrument** | Пресет інструмента: Guitar (гітара), Violin (скрипка) або Pitch Fork (камертон). |
| **Note** | Струна чи нота. Змінюється залежно від інструмента. |
| **Note Frequency** | Частота (Гц), що буде відтворена. |
| **Note Octave Shift** | Зсув октави. `-1` означає, що PortaPack відтворює ноту на одну октаву **вище** від справжньої висоти струни (апаратне обмеження для дуже низьких частот). |
| **Volume** | Гучність (0–99). |
| **Play / Stop** | Велика кнопка внизу. Запускає/зупиняє тон. |

## Індикатор зсуву октави

Коли нота має ненульовий зсув, на екрані показуються:

- **відтворювана частота** (ліворуч, червоним) — що реально видає динамік;
- **справжня цільова частота** (праворуч, червоним) — як має звучати струна;
- **зсув** в октавах (наприклад, `-1 * 8ev`).

Без зсуву ці індикатори приховані.

## Примітки

- Звук іде на гніздо 3,5 мм або внутрішній динамік.
- Тон звучить безперервно, доки не натиснути **Stop** або не змінити ноту.
- Зміна ноти під час звучання одразу перемикає частоту без зупинки.
- Дуже низькі частоти (наприклад, E2 гітари) відтворюються на октаву вище через обмеження динаміка PortaPack.
