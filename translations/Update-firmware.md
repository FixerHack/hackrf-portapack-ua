# Оновлення прошивки

## Загальний порядок дій

> Примітка: коротка інструкція (TLDR) призначена для досвідчених користувачів. Якщо вам важко її зрозуміти, прочитайте повну інструкцію, перш ніж звертатися до спільноти.

1. Оновіть вміст SD-карти.
2. Підключіть USB-кабель.
3. Скористайтеся **ОДНИМ З** таких способів:
    * (Спосіб 1) Увійдіть у режим HackRF і прошийте за допомогою `hackrf_spiflash`.
    * (Спосіб 2) Залишайтеся в режимі Mayhem і скористайтеся сайтом [hackrf.app](https://hackrf.app/).
    * (Спосіб 3) Скопіюйте єдиний пакет прошивки (tar) на SD-карту й виконайте оновлення без підключення до комп'ютера через застосунок Flash Utility на PortaPack.
        * (Спосіб 3-1) Файл із розширенням `.bin` — оновлює лише флеш-пам'ять.
        * (Спосіб 3-2) Файл із розширенням `.ppfw.tar` — оновлює і флеш-пам'ять, і зовнішні застосунки на SD-карті.
        * `.bin` корисний для першої прошивки або відновлення, якщо Mayhem втрачено. За можливості завжди оновлюйтеся через `.ppfw.tar`.

```
примітки:
- способи 2 і 3 автоматично оновлюють і зовнішні застосунки;
- не обов'язково щоразу оновлювати весь вміст SD-карти, але це рекомендовано, оскільки майже кожне оновлення має нові файли для SD-карти;
- ДЛЯ СПОСОБІВ 2 І 3 ПОТРІБЕН ПРАЦЮЮЧИЙ ПРИСТРІЙ З ПРОШИВКОЮ MAYHEM.
```

## Докладні процедури оновлення прошивки

### Файл прошивки зі сторінки релізів GitHub і застосунок [Flash Utility](Flash-Utility)

- Завантажте останню прошивку зі сторінки [релізів](https://github.com/portapack-mayhem/mayhem-firmware/releases/latest).
- Скопіюйте її на SD-карту й вставте карту назад у PortaPack.
- Прошийте через [Flash Utility](Flash-Utility) у меню «Utilities» на PortaPack.

> [!Note]
> - Якщо ви не бачите застосунок Flash Utility, скористайтеся іншими способами, щоб оновитися до останньої версії.
> - [Flash Utility](Flash-Utility) також можна використовувати для запису нової прошивки з bin-файлу, що зберігається на карті microSD.

### Файл прошивки зі сторінки релізів GitHub і класична утиліта hackrf_spiflash

> [!Note]
> ⚠️ За цього способу ви **ПОВИННІ** оновити вміст SD-карти відповідно до обраного релізу, інакше зовнішні застосунки не працюватимуть!

#### Windows

1. Підключіть пристрій через USB.
2. Перемкніться в режим HackRF за допомогою екранного пункту (на PortaPack).
3. Двічі клацніть `mayhem_flasher.bat` і дотримуйтесь інструкцій.
4. Перезавантажте пристрій.

#### Linux

1. Підключіть пристрій через USB.
2. Перемкніться в режим HackRF за допомогою екранного пункту (на PortaPack).
3. Завантажте прошивку командою `hackrf_spiflash -w new_firmware_file.bin` (наприклад, `portapack-h1_h2-mayhem.bin` для прошивки Mayhem або `hackrf_one_usb.bin` для стокової прошивки HackRF).
4. Перезавантажте пристрій.

> [!NOTE]
> Користувачам Ubuntu та Mint: дистрибутиви на основі Ubuntu ніколи не підтримують свій репозиторій із пакетом хост-клієнта HackRF (CLI) в актуальному стані. Ви зіткнетеся з безліччю дивних проблем, якщо ваш HackRF має ревізію R9. Щоб їх розв'язати, зберіть пакет HackRF самостійно або скористайтеся іншим дистрибутивом.

#### macOS

1. За потреби встановіть інструменти HackRF: `brew install hackrf`
2. Підключіть пристрій через USB.
3. Перемкніться в режим HackRF за допомогою екранного пункту (на PortaPack).
4. Завантажте прошивку командою `hackrf_spiflash -w new_firmware_file.bin`.
5. Перезавантажте пристрій.

### Оновлення файлів SD-карти {#update-sdcard-files}

Вам потрібна карта microSD із достатнім обсягом; 16 ГБ цілком достатньо, якщо у вас немає багатьох записів. Це потрібно для певних функцій, як-от карта світу, GPS-симулятор, зовнішні застосунки та інші.

Завантажте останні файли зі сторінки [релізів](https://github.com/portapack-mayhem/mayhem-firmware/releases/latest). Потрібно розпакувати (наприклад, за допомогою [7-zip](https://www.7-zip.org/download.html)) файли з `mayhem_vX.Y.Z_COPY_TO_SDCARD.7z` на карту microSD у форматі FAT32.

> [!NOTE]
> Як покласти файли на SD-карту?
> Розпакуйте кореневу теку архіву 7z у корінь SD-карти.
> - Не кладіть сам архів 7z на SD-карту.
> - Не розпаковуйте в жодну підтеку SD-карти.
> - Не користуйтеся SD-картами невідомих виробників.

#### Докладніше про вміст SD-карти

Прочитайте статтю [Вміст SD-карти](SD-Card-Content).

### Сайт hackrf.app

- Потрібен браузер, сумісний з Web USB Serial.
- Оновлення через сайт змінює лише прошивку та зовнішні застосунки на SD-карті. Якщо потрібне повне оновлення вмісту SD-карти, спершу виконайте розділ [Оновлення файлів SD-карти](#update-sdcard-files), а потім оновіться через сайт.

#### Порядок дій

1. Підключіть PortaPack USB-кабелем із підтримкою **передавання даних**.
2. Відкрийте https://hackrf.app/.
3. Якщо ви цього ще не робили, натисніть «Connect Device».
4. У невеликому вікні виберіть свій PortaPack і натисніть «Connect».
5. Угорі сторінки має з'явитися «HackRF Connected», а Live Screen завантажить перший знімок екрана.
6. Прокрутіть униз до «Manage Firmware» і натисніть на нього.
7. Виберіть версію прошивки для встановлення (stable, nightly або з власного файлу ppfw).
8. Дочекайтеся завантаження файлу та автоматичного перезавантаження пристрою.
9. Готово!

## Усунення несправностей

- Прочитайте [цей посібник](Update-firmware-troubleshooting).
- Зовнішні застосунки (файли `.ppma` у теці APPS) працюватимуть, лише якщо їхня версія збігається з версією прошивки.
- Перегляньте [FAQ](https://github.com/portapack-mayhem/mayhem-firmware#frequently-asked-questions).
- Якщо версія вашої прошивки ≤ v2.0.0 або nightly n_240114, оновлювати прошивку можна лише в режимі HackRF класичним способом.
- Оновлення через сайт hackrf.app працює лише зі стабільними версіями ≥ v2.0.1 і nightly новішими за n_240114.
- Під час повернення до старішої версії переконайтеся, що версії вмісту SD-карти збігаються.
- Прошивка Mayhem містить прошивку HackRF. Прошивати прошивку HackRF **НЕ ПОТРІБНО**.
- Теоретично пристрій неможливо «збрикувати», оскільки завжди можна спробувати процедуру відновлення DFU. Проте за певних умов оновлення може стати складним. Тому вам, імовірно, знадобляться базові навички роботи з комп'ютером (запуск/встановлення програм, читання документації, знання USB-портів, зміна налаштувань системи, читання англійською тощо). Якщо їх немає, попросіть друзів або знайомих, які розуміються на цьому, зробити це за вас.
