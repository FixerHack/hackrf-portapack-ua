# DFU-накладення (діагностичні оверлеї)

Коли працює прошивка Mayhem, коротке натискання кнопки **DFU** перебирає два діагностичні накладення, а потім ховає їх:

| Натискання DFU | Результат |
|-----------|--------|
| 1-ше | Показати накладення **Performance** (продуктивність) |
| 2-ге | Показати накладення **Radio Settings** (налаштування радіо) |
| 3-тє | Сховати накладення |

Накладення малюється поверх поточного екрана без виходу з активного застосунку. Значення оновлюються приблизно раз на секунду.

> [!NOTE]
> Поля обох накладень визначено безпосередньо у вихідному коді прошивки (`ui_dfu_menu.hpp`) і залежать від спільної структури пам'яті двох процесорів (`portapack_shared_memory.hpp`). Вони можуть змінюватися між версіями прошивки.

!!! tip "Завдання"
    Якщо зробите знімок екрана з обома накладеннями — це допоможе пояснити їх наочно (див. [Завдання для вас](tasks)).

## Накладення 1 — Performance

Діагностика процесора й пам'яті обох процесорів.

| Поле | Опис |
|-------|-------------|
| M0 core | Вільна пам'ять ядра M0 (байтів) |
| M0 heap | Вільна купа M0 (байтів) |
| M0 frags | Кількість фрагментів купи M0 |
| M0 stack | Вільний стек M0 (байтів) |
| M0 cpu % | Завантаження процесора M0 (%) |
| M4 heap | Використання купи M4 (байтів) |
| M4 stack | Використання стеку M4 (байтів) |
| M4 cpu % | Завантаження процесора M4 (%) |
| M4 miss | Кількість пропусків буфера основної смуги M4 |
| Uptime | Час роботи пристрою (секунд) |

## Накладення 2 — Radio Settings

Поточна конфігурація радіо для приймача й передавача.

| Поле | Опис |
|-------|-------------|
| RX Freq | Цільова частота приймача (Гц) |
| RX BW | Смуга основної смуги приймача (Гц) |
| RX SampR | Частота дискретизації приймача (Гц) |
| RX Satu% | Відсоток насичення M4 — допомагає підібрати підсилення, див. [Основні елементи керування](Main-Controls) |
| Modulatn | Індекс модуляції |
| AM cfg | Індекс конфігурації AM |
| NBFM cfg | Індекс конфігурації вузькосмугової FM |
| WFM cfg | Індекс конфігурації широкосмугової FM |
| TX Freq | Цільова частота передавача (Гц) |
| TX BW | Смуга основної смуги передавача (Гц) |
| TX SampR | Частота дискретизації передавача (Гц) |

## Кнопка DFU для прошивання

Кнопка DFU має й друге, окреме призначення: вхід у режим DFU (Device Firmware Upgrade) для прошивання базової прошивки HackRF з комп'ютера. Це працює лише **до** повного завантаження Mayhem — натискання DFU, коли прошивка вже працює, лише перемикає описані вище накладення.

Щоб увійти в режим DFU для прошивання, спробуйте один зі способів, поки пристрій ще не завантажив Mayhem:

- Утримуйте **DFU**, підключіть USB-кабель, відпустіть **DFU**.
- Утримуйте одночасно **DFU** і **RESET**, спершу відпустіть **RESET**, потім **DFU**.
- Утримуйте **DFU**, увімкніть пристрій (натисніть енкодер на H1/H2 або вимикач на H4M), відпустіть **DFU**, потім підключіть USB.

У режимі DFU світлодіоди світяться, а екран лишається порожнім.

Повні інструкції з прошивання — [Повне скидання](Full-reset) і [Усунення проблем з оновленням](Update-firmware-troubleshooting).
