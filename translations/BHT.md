# BHT Xy/EP (керування вуличним освітленням)

![BHT TX на пристрої](annotated/app-084.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-084).*

BHT TX передає повідомлення керування вуличним освітленням за двома протоколами — **Xylos** і **EPAR**, розробленими BH-Technologies для керування громадським освітленням у Франції та деяких європейських містах. Протоколи вибираються вкладками. Налаштування в `tx_bht.ini`.

!!! danger "Потрібен дозвіл"
    Передавання на частотах цих систем потребує дозволу. Використовуйте лише в закритому ВЧ-середовищі або з явного дозволу оператора мережі.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Вкладка Xylos

Xylos кодує команди послідовністю з 20 тонів CCIR (100 мс на тон, 400 мс тиша).

- **Header A / Header B** — два 2-значні коди (0–99) — заголовок протоколу.
- **City code** — код міста (0–99).
- **Family** — родина приймачів (0–9).
- **Subfamily** — підгрупа (0–9). Прапорець **All** — для всіх підгруп родини.
- **Receiver ID** — адреса приймача (0–99). **All** — для всіх приймачів підгрупи.
- **Relay 1–4** — чотири реле: **Ignore** (без змін), **Off** або **On** (значки ламп).

## Вкладка EPAR

EPAR використовує OOK ~580 бод; кожна передача повторюється 26 разів.

- **City code** — код міста (0–255).
- **Group** — група приймачів: **A**, **B**, **C** або **TP** (тестова точка).
- **Relay 1–2** — два реле, **Off** або **On**.

## Спільні елементи

- **Scan** — автоматично перебирати діапазон адрес після кожної передачі.
- **Flashing** — після кожної передачі чекати задані секунди, перемкнути всі реле на протилежні й передати знову (ефект блимання).
- **Speed** — інтервал між перемиканнями (1–99 с).
- **Frequency** — Xylos працює в діапазоні 31–32 МГц; EPAR залежить від установки.
- **LNA gain** (0–47 дБ), **RF Amp** (0 або 14 дБ).
- **TX / Stop** — почати/зупинити.
