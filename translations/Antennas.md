# Antenna Length (калькулятор довжини антени)

![Antenna Length на пристрої](annotated/app-096.jpg){ width="360" }

*Скріншот з пристрою: [Утиліти](Screens-Other#shot-096).*

Калькулятор **Antenna Length** обчислює оптимальну довжину антени для заданої частоти в метричних і британських одиницях. Також він показує, на скільки секцій розсунути кожну з ваших збережених телескопічних антен.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

> [!WARNING]
> Правильно підібрана («налаштована» чи «узгоджена») антена для кожної частоти надзвичайно важлива — інакше приймання чи передавання буде гіршим. За певних умов, наприклад із дуже неузгодженою антеною під час передавання на високій потужності, можна пошкодити обладнання. Це стосується будь-якого радіопередавального обладнання.

## Елементи керування

| Поле | Опис |
|-------|-------------|
| **Frequency** | Цільова частота. Змінюється енкодером, крок 1 МГц. |
| **Wave** | Тип антени / частка довжини хвилі для розрахунку. |
| **Metric** | Розрахована довжина в метрах і сантиметрах. |
| **Imperial** | Розрахована довжина у футах і дюймах. |

## Варіанти Wave

| Варіант | Частка | Примітки |
|--------|----------|-------|
| Full | 1 | Повна довжина хвилі |
| Half | 1/2 | Звичайний диполь |
| Quarter | 1/4 | **За замовчуванням** — звичайний штир/монополь |
| 3/4 | 3/4 | |
| 1/8 | 1/8 | |
| 3/8 | 3/8 | |
| 5/8 | 5/8 | Популярна для підсилення на VHF/UHF |
| 7/8 | 7/8 | |

**Приклад з вашого пристрою:** для 100 МГц чверть хвилі = **0 м 74,9 см** (2 фути 5,5 дюйма).

## Підказки для телескопічних антен

Під розрахованою довжиною застосунок показує, на скільки **секцій** розсунути кожну зі збережених телескопічних антен, щоб отримати потрібну довжину.

Наприклад: `ANT500: 3 1/4 elements` означає «розсуньте 3 повні секції плюс приблизно чверть наступної».

Якщо потрібна довжина виходить за фізичні межі антени, замість кількості секцій показується: **`retracted`** — потрібна довжина коротша за повністю складену антену (частота вища за діапазон антени); **`fully ext.`** — довша за повністю розсунуту (частота нижча за діапазон антени).

Якщо на SD-карті немає файлу `ANTENNAS.TXT`, застосунок використовує лише вбудовану антену **ANT500**.

## Додавання власних антен

Покладіть файл `WHIPCALC/ANTENNAS.TXT` на SD-карту. Рядки, що починаються з `#`, — коментарі.

**Формат:** `назва,секція1_мм,секція2_мм,...`

Кожне значення — загальна довжина антени в міліметрах, коли відповідна секція повністю розсунута.

### Приклад ANTENNAS.TXT

```
#antenna label,elements length in mm, separated by commas
ANT700,95,134,175,206,230,245
ANT500,185,315,450,586,724,862
TELESCOPIC,118,183,253,326,399,476
Cheap 11cm,118,183,253,326,399,476
Comet W100RX,200,300,400,510,615,800,986
```

Образ SD-карти містить готовий `ANTENNAS.TXT` з кількома пресетами, зокрема **Comet W100RX**.

!!! tip "Як виміряти свою антену"
    Розсувайте антену по одній секції й щоразу міряйте загальну довжину від основи роз'єму до кінця. Запишіть числа в мм через кому в новий рядок файлу.
