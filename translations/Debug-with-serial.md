# Налагодження через послідовний порт

Так можна лише виводити повідомлення для налагодження. Щоб ставити точки зупину, перевіряти регістри тощо — використовуйте інший метод (SWD/JTAG).

> Довідка й код: PR #2111 у репозиторії прошивки.

## Використання

1. Підключіть заголовок асинхронних повідомлень:
   ```cpp
   #include "usb_serial_asyncmsg.hpp"
   ```
   Якщо після підключення виникає помилка — спробуйте не підключати, але все одно використовувати (ми ще впорядковуємо заголовки, щоб уникнути циклічних включень).
2. Виводьте значення у своєму коді — вони з'являться на послідовному порту:
   ```cpp
   std::string s = "test string:";
   UsbSerialAsyncmsg::asyncmsg(s);

   std::vector<uint32_t> v{1, 2, 3};
   UsbSerialAsyncmsg::asyncmsg(v);

   uint8_t test = 254;
   UsbSerialAsyncmsg::asyncmsg(test);
   ```

## Чому нічого не виводиться?

- Переконайтеся, що блокування asyncmsg вимкнене: надішліть `asyncmsg enable`.
- Переконайтеся, що послідовний порт під'єднаний: надішліть `help`.
- MayhemHub наразі не підтримує обмін командами в реальному часі — використовуйте інший термінал.

## Помилка лінкування

Можливо, об'єкт, який ви виводите, ще не реалізовано (наприклад, об'єкт кольору). За бажання реалізуйте його, відредагувавши `usb_serial_asyncmsg.cpp` і `.hpp`.
