# RDS RX (дані FM-радіостанцій)

Декодує **RDS** (Radio Data System) — цифрові дані, що передаються разом зі звуком FM-станцій, — і показує назву станції та текст у реальному часі.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Огляд

RDS — цифровий потік, який FM-станції передають на піднесучій поряд зі звуком. Він несе назву станції, тип програми, прапорець дорожніх повідомлень і текст, що прокручується. Застосунок демодулює FM вибраної станції, відновлює піднесучу RDS на **57 кГц**, декодує групи й показує поля нижче.

Налаштуйтеся на FM-станцію (87,5–108 МГц). Для стабільного декодування потрібен сильний чистий сигнал.

## Елементи керування

| Елемент | Опис |
|---|---|
| **Frequency** | Налаштування на FM-станцію (крок 100 кГц). |
| **RF Amp** | ВЧ-підсилювач: `0` — вимкнено, `1` — увімкнено (+14 дБ). |
| **LNA** | Підсилення ПЧ (0–40 дБ). Див. [Проблеми з якістю приймання](Help!-Im-not-receiving-anything!---Receive-Quality-Issues#gain-settings). |
| **VGA** | Підсилення основної смуги (0–62 дБ). |
| RSSI / Channel | Індикатори сили сигналу й потужності каналу. |

## Декодовані поля

| Поле | Значення |
|---|---|
| **PI** | Код ідентифікації програми (hex) — унікально визначає станцію/мережу |
| **TP** | Прапорець дорожніх повідомлень (Yes / No) |
| **PTY** | Тип програми: номер + назва (новини, поп, рок, класика, погода, спорт…) |
| **PS** | Назва програми — 8-символьна назва станції |
| **Radio Text** | Довільний текст станції (до 64 символів), показується у три рядки |

Під полями **діагностична консоль** друкує кожну прийняту групу як чотири «сирі» блоки `[A B C D]` і тип групи (наприклад, `G:0A`, `G:2A`). Блоки з помилкою показуються як `----`.

## Протокол

RDS передається на піднесучій **57 кГц** (третя гармоніка пілот-тону FM-стерео 19 кГц), двофазним кодом на **1187,5 біт/с**, групами по чотири блоки, кожен із захисним контрольним словом.
