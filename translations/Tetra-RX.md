# Tetra RX (цифрове радіо TETRA)

![Tetra RX на пристрої — екран очікування](annotated/ui-receiver-list-subghzd.jpg){ width="320" }

*Окремого скріншота Tetra RX у вашому архіві немає — його приклад буде додано пізніше (див. [завдання](tasks)).*

## Огляд

Застосунок **Tetra RX** дозволяє приймати, демодулювати й розбирати сигнали низхідної лінії TETRA (Terrestrial Trunked Radio) прямо на PortaPack. Він декодує незашифровані параметри мережі, структуру кадрів і події керування викликами від базової станції в реальному часі.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

!!! info "В Україні"
    TETRA використовують деякі відомчі та екстрені служби. Декодується лише незашифрований службовий канал; аудіо й корисне навантаження не декодуються.

## Інтерфейс

### Верхня панель / налаштування радіо

- **Frequency** — центральна частота низхідної лінії базової станції TETRA (наприклад, `427.1625` МГц).
- **Підсилення** — стандартне (наприклад, `1 40 6` — AMP, LNA, VGA).
- **Індикатор сигналу** — сила сигналу та якість декодування.

### Параметри мережі та станції

- **MCC** (Mobile Country Code) — код країни мережі (наприклад, `216`).
- **MNC** (Mobile Network Code) — код оператора (наприклад, `2163`).
- **BCC** (Base Color Code) — розрізняє сусідні базові станції на одній частоті (0–63).
- **LA** (Location Area) — код зони розташування комірки (наприклад, `1105`).

### Кадр і навантаження

- **TS** (Time Slot) — поточний часовий слот (TETRA має 4 слоти на кадр TDMA).
- **FN** (Frame Number) — номер кадру в ієрархії мультикадру.
- **ENC** — стан шифрування (наприклад, `Clear` — незашифрований службовий канал).
- **PDU** — останній декодований тип MAC-блоку (наприклад, `MAC-RESOUR`).

### Статистика демодулятора

- **Syn / V / H / E** — метрики демодулятора й декодера: захоплення синхронізації (`Syn`), лічильники помилок (`E`). Стабільно низькі або нульові помилки (`E: 0`) означають чистий, добре налаштований сигнал.

### Журнал подій

Нижня частина екрана — прокручуваний журнал декодованої активності мережі та подій керування викликами в реальному часі.

## Поради

- **Налаштування:** канали TETRA рознесені на 25 кГц. Налаштовуйтеся точно — демодулятор π/4 DQPSK потребує центрованого сигналу для захоплення синхронізації.
- **Підсилення:** налаштуйте LNA і VGA для чистого сигналу без перевантаження.
- **Аудіо:** застосунок декодує параметри мережі й ідентифікатори абонентів незашифрованих службових каналів, але не декодує аудіо чи корисне навантаження.
