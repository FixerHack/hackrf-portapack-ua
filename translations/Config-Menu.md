# Меню конфігурації (Config Menu)

Config Menu — мінімальний інтерфейс налаштування, що працює до завантаження основної прошивки. Він використовує лише кнопки та світлодіоди — **РК-екран не використовується**.

## Як увійти в Config Menu

Config Menu вмикається автоматично після **3 невдалих спроб завантаження поспіль** (збої або перезапуски до повного завантаження прошивки). Щоб увійти навмисно, натисніть кнопку RESET 3 рази швидко поспіль — щоразу до того, як прошивка завершить завантаження.

> [!NOTE]
> На деяких моделях PortaPack кнопка RESET не працює. На них від'єднання й повторне підключення USB-кабелю вважається перезапуском; зробивши це 3 рази досить швидко, ви ввімкнете Config Menu.

> [!NOTE]
> Config Menu можна повністю вимкнути в **Settings → Config Mode**. Тоді воно ніколи не вмикатиметься ні автоматично, ні вручну.

Після успішного входу всі три світлодіоди (TX, RX, USB) швидко блимають (близько 8 разів на секунду). Тепер натисніть кнопку DFU один раз, щоб показати поточні налаштування.

## Доступні налаштування

Налаштування показуються світлодіодами TX і RX. Світлодіод USB використовується лише на початковому етапі очікування й гасне після натискання DFU.

### Драйвер РК (світлодіод TX)

| Світлодіод TX | Налаштування |
|--------|---------|
| Не світиться | Варіант 1: автоматичне визначення (типово) |
| Світиться | Варіант 2: драйвер РК 1 |
| Швидко блимає | Варіант 3: драйвер РК 2 |
| Повільно блимає | Варіант 4: драйвер РК 2, чип QFP100 |
| Інверсне повільне блимання | Варіант 5: драйвер РК 1, чип QFP100 |

> [!NOTE]
> Драйвер РК також можна вибрати під час увімкнення кнопками напрямку — див. [Не завантажується](Won't-boot).

### Вимкнути зовнішній TCXO (світлодіод RX)

| Світлодіод RX | Налаштування |
|--------|---------|
| Не світиться | Зовнішній TCXO увімкнено / автовизначення (типово) |
| Світиться | Зовнішній TCXO вимкнено |

> [!NOTE]
> Це налаштування також змінюється в **Settings → Radio**.

> [!NOTE]
> На HackRF R9, якщо Config Menu ввімкнулося автоматично через збої завантаження, зовнішній TCXO тимчасово вимикається на час сеансу Config Menu, бо саме TCXO — найімовірніша причина збою. Початкове налаштування відновлюється після виходу.

## Перемикання налаштувань

Кожне натискання кнопки DFU перемикає на наступну комбінацію налаштувань. Драйвер РК і TCXO перебираються разом — після **10 натискань** ви повертаєтеся до початкової комбінації.

> [!WARNING]
> Не натискайте DFU надто швидко. Утримуйте її щонайменше **200 мс**, інакше натискання може бути проігнороване.

Кожен новий вибір одразу зберігається в постійній пам'яті. Пристрій можна перезапустити будь-коли — вибрані налаштування буде застосовано.

## Небажане ввімкнення Config Menu

Іноді PortaPack несподівано входить у Config Menu — наприклад, якщо кнопку живлення швидко натискали кілька разів, або якщо при підключенні USB-кабелю виникли електричні завади (хибні перезапуски). Якщо це трапляється часто (темний екран і блимання світлодіодів), Config Menu можна назавжди вимкнути в **Settings → Config Mode** — це встановлює прапорець у постійній пам'яті, щоб пропускати Config Menu під час усіх наступних завантажень.
