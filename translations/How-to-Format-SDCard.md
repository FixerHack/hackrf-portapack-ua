# Як відформатувати SD-карту

PortaPack **потребує** SD-карту у форматі **FAT32** або **exFAT**! Ось як відформатувати її на комп'ютері.

!!! warning
    Форматування видаляє всі дані на карті. Спершу збережіть потрібні файли.

## Linux

Зазвичай кожне графічне середовище має власний інструмент розділів, наприклад GParted або KDE Partition Manager. У командному рядку:

1. Визначте пристрій SD-карти: `sudo fdisk -l`.
2. Відмонтуйте SD-карту: `sudo umount /dev/sdX1`.
3. Відформатуйте: `sudo mkfs.vfat -F 32 /dev/sdX1`.
    - якщо `mkfs.vfat: command not found` — встановіть пакет dosfstools (наприклад, `sudo pacman -S dosfstools` або `sudo apt install dosfstools`).
4. (Необов'язково) Задайте мітку: `sudo mkfs.vfat -F 32 -n "SDCARD" /dev/sdX1`.
5. Змонтуйте SD-карту: `sudo mount /dev/sdX1 /mnt`.

!!! danger "Обережно з /dev/sdX"
    Переконайтеся, що `sdX` — саме SD-карта, а не ваш диск. Помилка видалить дані з іншого диска.

## macOS

Скористайтеся програмою **Дискова утиліта** (Disk Utility): виберіть карту → «Стерти» → формат **MS-DOS (FAT)** (це FAT32) або **ExFAT**.

## Windows

- Якщо обсяг карти **32 ГБ або менше** — клацніть правою кнопкою по диску SD-карти в Провіднику → «Форматувати» → FAT32.
- Якщо обсяг **понад 32 ГБ** — Windows не пропонує FAT32 для великих карт; завантажте безкоштовний менеджер розділів (наприклад, DiskGenius) і відформатуйте ним у FAT32.
