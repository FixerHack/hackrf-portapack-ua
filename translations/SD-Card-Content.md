# Вміст SD-карти

**SD-карта** — важлива частина прошивки **PortaPack Mayhem**: вона розширює можливості пристрою, даючи додаткове місце для файлів, налаштувань і даних користувача. Хоча PortaPack має вбудовані функції, багато можливостей потребують SD-карти для повноцінної роботи.

## Для чого потрібна SD-карта

- **Записи** — власні **IQ-записи** та заздалегідь згенеровані сигнали для відтворення або аналізу.
- **Зовнішні застосунки** — застосунки в теці `APPS` на SD-карті.
- **Файли налаштувань** — параметри користувача, профілі й налаштування, що зберігаються між сеансами.
- **Оновлення прошивки** — файли прошивки, які записуються й завантажуються з SD-карти.
- **Записані дані** — журнали, результати сканування й записані передачі для подальшого аналізу.

## Файлова система й організація

- SD-карту слід форматувати у **FAT32** або **exFAT**.
- Для деяких функцій потрібні певні теки й правила іменування.
- Правильна структура тек забезпечує безперебійну роботу.
- SD-карта — гнучке сховище, яке можна налаштувати під свої потреби.

## Завантаження та встановлення файлів SD-карти

Щоб повноцінно використовувати прошивку Mayhem, потрібно підготувати SD-карту з потрібними файлами.

Нижче — швидкий порядок дій; докладний опис оновлення вмісту SD-карти дивіться в статті [Оновлення прошивки](Update-firmware#update-sdcard-files).

Стандартний образ SD-карти входить до складу завантаження прошивки — у списку файлів (assets) [кожного релізу](https://github.com/portapack-mayhem/mayhem-firmware/releases).

### Порядок дій

1. Відкрийте [сторінку релізів](https://github.com/portapack-mayhem/mayhem-firmware/releases).
2. Виберіть потрібну версію (nightly або stable). **Версія має збігатися з версією прошивки на пристрої** (у вас — v2.4.0).
3. У розділі Assets знайдіть два файли, що закінчуються на `...COPY_TO_SDCARD.zip` і `...COPY_TO_SDCARD-no-world-map.zip`.
4. Завантажте потрібний:
    - якщо ви вже раз встановлювали вміст SD-карти, вам не потрібна велика версія з картою світу для ADS-B.
5. Розпакуйте вміст ZIP **у корінь SD-карти**.

Структура даних **у корені SD-карти** має виглядати приблизно так:

![Корінь SD-карти](https://github.com/user-attachments/assets/fa5a79b5-6083-42a5-8ad2-7ab1ebd8d515)

На вашому пристрої вміст кореня видно в застосунку File Manager:

![File Manager на пристрої](annotated/app-088.jpg){ width="320" }

> [!IMPORTANT]
> ZIP-файл **обов'язково** потрібно розпакувати.

> [!IMPORTANT]
> Теки, показані на знімку, **мають бути в корені SD-карти**.

## Подробиці про вміст SD-карти

### Теки на SD-карті

Ці теки зберігають дані різних застосунків. Частина з них є в образі SD-карти, інші створюються пізніше прошивкою або користувачем:

| Тека | Що містить |
|---|---|
| **ADSB** | Бази авіакомпаній та ICAO. Тут також лежить карта світу (`world_map.bin`). Див. документацію про створення власної карти. |
| **AIS** | База даних AIS. |
| **APPS** | Зовнішні застосунки (файли `.ppma`), винесені з флеш-пам'яті прошивки. |
| **APRS** | Журнали застосунку APRS RX. |
| **AUDIO** | WAV-записи звуку із застосунку Audio. |
| **BLERX** | Записи застосунку BLE RX. |
| **BLETX** | Файли пакетів для застосунку BLE TX (формат `.TXT`). |
| **BMP** | BMP-зображення, збережені застосунком NOAA APT. Створюється автоматично при першому використанні. |
| **CAPTURES** | Файли IQ-записів (`.C16`, `.C8`, `.CU8` і метадані `.TXT`) із застосунку Capture. |
| **CVSFILES** | Файли для застосунку CVS Spam. |
| **DEBUG** | Файли дампів, створені застосунком Debug Dump. |
| **EPIRB** | Файли для EPIRB RX і TX. EPIRB RX читає `FREQ.TXT` для вибору частоти, EPIRB TX — `BEACONS.TXT` для відтворення маяків у режимі файлу. |
| **FIRMWARE** | Файли `.bin` для оновлення прошивки PortaPack. |
| **FREQMAN** | Бази частот, які завантажують різні застосунки. |
| **GPS** | Дані для генерування файлів GPS-симуляції. |
| **HOPPER** | Файли для застосунку Hopper. |
| **KEELOQKEYS** | Файл ключів `MFCODES` для KeeLoq TX і SubGhzD. `MFCODES` — звичайний текстовий файл, один запис у рядку у форматі `mf_name;key_hex;type`. Без відповідного запису сигнали KeeLoq і Superrollo не можна розшифрувати чи повторно передати. |
| **KEELOQREMOTES** | Файли пультів `.KEELOQ`, створені SubGhzD під час збереження декодованого сигналу KeeLoq чи Superrollo. Їх завантажує KeeLoq TX для повторного передавання. |
| **LOGS** | Журнали різних застосунків: ADSB RX, ERT, TPMS, POCSAG, Radiosonde, SubGhzD (`SUBGHZDLOG_*.CSV`), SubCar (`SubCarLOG_*.CSV`). |
| **LOOKINGGLASS** | Готові діапазони частот для Looking Glass. Усі файли `.TXT` у цій теці завантажуються автоматично. |
| **MACADDRESS** | Файли MAC-адрес. |
| **OOKFILES** | Файли сигналів для OOK Editor. |
| **PLAYLIST** | Файли плейлистів `.PPL` для Replay. |
| **REMOTES** | Файли панелей для застосунку Remote. |
| **SAMPLES** | Приклади файлів записів. |
| **SCREENSHOTS** | Знімки екрана. |
| **SECPLUS** | Файли пультів `.SECPLUS` для Security+ TX. |
| **SETTINGS** | Налаштування застосунків (файли `.ini`). Якщо застосунок працює неправильно, видалення його файлу налаштувань скидає його. Тут також може лежати файл `blacklist` для вимкнення застосунків. |
| **SPECTRUM** | Зображення `.BMP` для Spectrum Painter. |
| **SPLASH** | Власні заставки `.BMP` (активна заставка має лежати в корені як `splash.bmp`). |
| **SSTV** | Зображення для SSTV. |
| **SUBGHZ** | Файли сигналів `.sub` для FlipperTX. |
| **TPMS** | Файли журналів TPMS RX. |
| **WATERFALLS** | Готові схеми для Waterfall Designer. |
| **WAV** | Звукові файли для Soundboard. |
| **WHIPCALC** | Дані для розрахунку довжини штирьової антени. Можна додати власні антени з потрібними параметрами. |

Керувати вмістом SD-карти можна застосунком File Manager, застосунком «SD over USB» або вийнявши карту й підключивши її до комп'ютера.

> [!WARNING]
> Якщо неакуратно вставляти карту назад, вона може провалитися всередину корпусу — тоді пристрій доведеться розбирати.
