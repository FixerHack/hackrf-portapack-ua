# SAME TX (аварійні оповіщення SAME/EAS)

![SAME TX на пристрої](annotated/app-062.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-062).*

SAME TX генерує й передає цифрові заголовки SAME (Specific Area Message Encoding) — протокол системи аварійних сповіщень США (EAS) і метеорадіо NOAA. SAME-приймачі використовують ці заголовки, щоб вибірково активуватися для сповіщень у запрограмованому окрузі.

!!! danger "Лише тести в закритому середовищі"
    Передавання підроблених аварійних оповіщень незаконне й небезпечне. Використовуйте лише в екранованому середовищі або на еквівалент навантаження. Це американський протокол, що в Україні не застосовується.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Елементи керування

- **Org** — код джерела: WXR (метеослужба), EAS (учасник EAS), CIV (цивільна влада), PEP (президентський рівень). За замовчуванням WXR.
- **Evt** — тип події (індекс 0–25; RWT — щотижневий тест, TOR — попередження про торнадо тощо).
- **FIPS State** — 2-значний код штату (за замовчуванням 39 — Огайо).
- **FIPS County** — 3-значний код округу (за замовчуванням 007).
- **Dur H / Dur M** — тривалість сповіщення (години/хвилини).

Живий перегляд рядка повідомлення оновлюється під час зміни полів.

## Формат

```
ZCZC-ORG-EVT-SS0CCC+HHMM-0010000-SAMETX--
```

Повідомленню передує 16 байтів преамбули, і воно передається **3 рази** автоматично, як вимагає стандарт SAME.

## Параметри

Частота за замовчуванням 162,550 МГц (метеорадіо NOAA), смуга 1,75 МГц, модуляція AFSK/FM, тон Mark 2083 Гц / Space 1563 Гц, ~520,83 біт/с, девіація FM 5 кГц, 3 повтори.

Налаштування — у `tx_same.ini`.
