# NRF RX (декодер nRF24L01+)

![NRF RX на пристрої](annotated/app-037.jpg){ width="360" }

*Скріншот з пристрою: [Приймачі: огляд застосунків](Screens-Receivers#shot-037).*

## Вступ

Застосунок NRF декодує пакети трансіверів [nRF24L01+](https://www.nordicsemi.com/Products/2-4-GHz-proprietary) від Nordic Semiconductor. Це дешеві енергоощадні пристрої на 2,4 ГГц, поширені в бездротових клавіатурах, мишах, ігрових контролерах, пультах міні-дронів і хобі-проєктах. Вони використовують фірмовий протокол Nordic Enhanced ShockBurst (ESB).

Застосунок поки підтримує **лише режим 250 кбіт/с**. Режими 1 Мбіт/с і 2 Мбіт/с ще не реалізовано.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Про протокол

nRF24L01+ працює в ISM-діапазоні 2,4 ГГц на 128 каналах з кроком 1 МГц (канал 0 = 2400 МГц, канал 127 = 2527 МГц). Кожен пакет містить преамбулу, 5-байтову адресу, 9-бітове поле керування (довжина навантаження й ID), навантаження (0–32 байти) і 2-байтовий CRC. Декодер перевіряє CRC — показуються лише пакети з правильним CRC.

## Елементи керування

- **Frequency** — за замовчуванням **2480 МГц** (канал 80). Енкодер змінює кроком 100 Гц, натискання відкриває клавіатуру. Для конкретного пристрою встановіть частоту = `2400 + номер_каналу` МГц. Багато пристроїв перестрибують канали; активні канали допоможе знайти [Looking Glass](Looking-Glass).
- **AMP** — ВЧ-підсилювач: 0 — вимкнено, 1 — увімкнено (+14 дБ).
- **LNA** — малошумний підсилювач (0–40 дБ).
- **VGA** — підсилювач основної смуги (0–62 дБ).
- **Modem setup** — екран налаштування модему (застосунок налаштовує модем автоматично; кнопка для ручних змін).

## Відображення

Декодовані пакети показуються в консолі як шістнадцяткові байти:

```
addr: AA BB CC DD EE  data: XX XX XX XX ...
```

Кожен рядок — один прийнятий пакет, що пройшов CRC. Адреса завжди 5 байтів, далі — байти навантаження.

## Обмеження

- Підтримується лише **250 кбіт/с**. Пристрої на 1 чи 2 Мбіт/с не декодуються.
- Немає перестрибування каналів — приймач слухає одну фіксовану частоту.
- Чутливість HackRF на 2,4 ГГц обмежена. Пасивний прийом можливий, але дальність мала порівняно зі спеціальними приймачами 2,4 ГГц. Розташування антени близько до передавача значно покращує результат.
