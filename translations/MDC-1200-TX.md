# MDC-1200 TX (сигналізація MDC-1200)

![MDC-1200 TX на пристрої](annotated/app-071.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-071).*

MDC-1200 TX передає пакети сигналізації MDC-1200, які використовують у деяких системах двостороннього радіозв'язку для ідентифікації, аварійних сигналів, вибіркового виклику й дистанційного керування. Протокол — AFSK 1200 бод, переданий як субзвукові дані FM.

!!! danger "Потрібен дозвіл"
    Передавання команд MDC-1200 на робочі радіосистеми без дозволу незаконне й може заважати зв'язку. Використовуйте лише на власному обладнанні або з дозволу на тестування.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Параметри

Частота за замовчуванням 462,5625 МГц, AFSK Mark 1800 Гц / Space 1200 Гц, 1200 бод, девіація FM 2500 Гц, смуга 1 750 000 Гц, підсилення TX за замовчуванням 30.

## Елементи керування

- **Op** — тип операції (при виборі автоматично встановлює типовий **Arg**).
- **ID** (два поля 0–255) — 16-бітовий ID цільового пристрою як два десяткові байти (старший і молодший). Наприклад, ID 256 = `001` `000`.
- **Arg** (0–255) — байт аргументу операції.
- **Src** (два поля 0–255) — 16-бітовий ID джерела (лише для двопакетних операцій).
- **Start / Stop** — передати кадр (лише одноразово).

## Операції

| Операція | Код | Arg за замовч. | Тип |
|-----------|---------|-------------|-------------|
| PTT ID | 0x01 | 0x00 | Один |
| Emergency | 0x00 | 0x00 | Один |
| Radio Check | 0x63 | 0x85 | Один |
| Stun | 0x2B | 0x00 | Один |
| Unstun | 0x2B | 0x0C | Один |
| Status Req | 0x22 | 0x00 | Один |
| Status Resp | 0x06 | 0x00 | Один |
| Rem Monitor | 0x11 | 0x8A | Один |
| Message | 0x07 | 0x00 | Один |
| Sel Call 1 | 0x80 | — | Подвійний (Src) |
| Call Alert | 0x81 | — | Подвійний (Src) |
| Sel Call 2 | 0x82 | — | Подвійний (Src) |

Двопакетні операції надсилають два кодові слова: перше з ID цілі, друге з ID джерела.

Налаштування — у `tx_mdc_tx.ini`.
