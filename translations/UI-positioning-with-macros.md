# Позиціювання UI через макроси

Цей документ описує обов'язкове використання допоміжних макросів позиціювання UI для всіх нових застосунків на PortaPack. Макроси спрощують і стандартизують розміщення елементів, використовуючи символьну сітку замість сирих піксельних координат.

## Базова концепція

Елементи позиціонуються за символьними клітинками, де типовий шрифт — **8 пікселів завширшки** й **16 пікселів заввишки**. Усі параметри позиції задаються в кількості символів або рядків, а не в пікселях.

**Ключове правило:** нумерація з нуля. Перший символ/рядок — індекс `0`, другий — `1` тощо. Щоб поставити елемент на другий символ зліва й другий рядок згори, використайте `UI_POS_X(1)` і `UI_POS_Y(1)`.

## Константи

- `UI_POS_DEFAULT_HEIGHT 16` — типова висота одного рядка (px).
- `UI_POS_DEFAULT_HEIGHT_SMALL 8` — висота для меншого шрифту (px).
- `UI_POS_DEFAULT_WIDTH 8` — типова ширина символу (px).

## Вісь Y (вертикаль)

- `UI_POS_Y(linenum)` — верхня Y-координата для рядка. `UI_POS_Y(2)` → 32.
- `UI_POS_Y_BOTTOM(linenum)` — Y-координата відносно низу екрана. `linenum=0` — останній рядок (за межами екрана). **Враховуйте верхній рядок стану вручну, якщо він видимий.**

## Вісь X (горизонталь)

- `UI_POS_X(charnum)` — ліва X-координата для символу. `UI_POS_X(4)` → 32.
- `UI_POS_X_RIGHT(charnum)` — ліва X-координата відносно правого краю. `charnum=0` вирівнює початок елемента з правим краєм.
- `UI_POS_X_CENTER(charnum)` — початкова X-координата для горизонтального центрування рядка з `charnum` символів.
- `UI_POS_X_TABLE(colnum, currcol)` — ділить екран на `colnum` рівних колонок і повертає початкову X-координату колонки `currcol` (з нуля).

## Розміри

### Ширина

- `UI_POS_WIDTH(charnum)` — ширина в пікселях для кількості символів. `UI_POS_WIDTH(10)` → 80.
- `UI_POS_WIDTH_PERCENT(percent)` — ширина як відсоток ширини екрана.
- `UI_POS_WIDTH_REMAINING(charnum)` — ширина від позиції `charnum`-го символу до правого краю.
- `UI_POS_MAXWIDTH` — повна ширина екрана.

### Висота

- `UI_POS_HEIGHT(linecount)` — висота для кількості рядків. `UI_POS_HEIGHT(4)` → 64.
- `UI_POS_HEIGHT_PERCENT(percent)` — висота як відсоток висоти екрана.
- `UI_POS_HEIGHT_REMAINING(linenum)` — висота від рядка `linenum` до низу. **Враховуйте верхній рядок стану вручну.**
- `UI_POS_MAXHEIGHT` — повна висота екрана.

## Практичні приклади

### Приклад 1: базовий підпис

**До (жорсткі пікселі):**

```cpp
Text label_channel{ {0, 0, 16, 16}, "Ch" };
```

**Після (макроси)** — той самий результат, але намір значно зрозуміліший (елемент 2 символи завширшки, 1 рядок заввишки, у першій позиції):

```cpp
Text label_channel{
    {UI_POS_X(0), UI_POS_Y(0), UI_POS_WIDTH(2), UI_POS_HEIGHT(1)}, "Ch"
};
```

### Приклад 2: відносні та динамічні розміри

**Смуга RSSI** (з 22-го символу, займає більшу частину решти верхнього рядка, фіксована висота 4 px):

```cpp
RSSI rssi{ {UI_POS_X(21), UI_POS_Y(0), UI_POS_WIDTH_REMAINING(23), 4} };
```

**Кнопка Exit** (типовий футер — внизу, від правого краю):

```cpp
Button button_exit{
    {UI_POS_X_RIGHT(14), UI_POS_Y_BOTTOM(3), UI_POS_WIDTH(14), UI_POS_HEIGHT(2)}, "Exit"
};
```
