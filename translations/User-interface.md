# Інтерфейс користувача

Дисплей PortaPack має розмір 240×320 пікселів. Екран поділено на три горизонтальні смуги, які присутні завжди:

```
┌─────────────────────────────┐  ← 16 пікс.  Рядок заголовка
│                             │
│   Область вмісту застосунку │  ← 288 пікс.
│                             │
├─────────────────────────────┤  ← 16 пікс.  Інформаційний рядок
```

## Рядок заголовка

Верхні 16 пікселів — це [рядок заголовка](Title-Bar). Він містить:

- елементи навігації (стрілка «назад», назва застосунку) ліворуч;
- налаштовувані піктограми стану та кнопки швидких дій праворуч.

## Область вмісту застосунку

Середні 288 пікселів використовує поточний застосунок. У [головному меню](Main-Menu) тут показано сітку кнопок у два стовпці. Усередині застосунків тут розташовано його власні елементи керування та відображення.

## Інформаційний рядок

Нижні 16 пікселів завжди показують:

- **Ліворуч:** рядок версії прошивки (наприклад, `n_250606`). Якщо під час завантаження виявлено помилку контрольної суми прошивки, замість нього червоним показується `FLASH ERR`.
- **Праворуч:** годинник UTC, що оновлюється щосекунди. Відображення дати можна ввімкнути в **Settings → User Interface**.

## Заставка (splash)

Під час кожного завантаження перед головним меню показується заставка. Торкніться екрана або натисніть будь-яку кнопку, щоб пропустити її негайно.

За замовчуванням випадкове зображення вибирається з теки `SPLASH/` на SD-карті. Якщо в корені SD-карти є файл `splash.bmp`, використовується він, а випадковий вибір пропускається.

Показ заставки можна ввімкнути чи вимкнути в **Settings → Display**. Вимоги до формату зображення — на сторінці [Власна заставка](Create-a-custom-splash-screen).
