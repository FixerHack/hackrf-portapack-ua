# WAV Viewer (переглядач WAV)

![WAV Viewer на пристрої](annotated/app-106.jpg){ width="360" }

*Скріншот з пристрою: [Утиліти](Screens-Other#shot-106).*

WAV Viewer переглядає й відтворює моно-WAV-файли 8 біт без знака або 16 біт зі знаком. Приклади WAV лежать у теці `WAV/` на SD-карті, а записи застосунку Audio — у теці `AUDIO/`.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Створення сумісних WAV

На комп'ютері WAV можна сконвертувати з наявного аудіо в Audacity або ffmpeg:

```bash
# 8 біт без знака, моно, 48000 Гц
ffmpeg -i lovely_music.mp3 -ar 48000 -ac 1 -acodec pcm_u8 lovely_music.wav

# 16 біт зі знаком, моно, 48000 Гц
ffmpeg -i lovely_music.mp3 -ar 48000 -ac 1 -acodec pcm_s16le lovely_music.wav
```

> [!NOTE]
> Підтримуються лише **моно** WAV у кодуванні PCM **8 біт без знака** або **16 біт зі знаком**. Стерео й інші формати покажуть помилку під час відкриття.

## Інформація про файл

| Поле | Опис |
|-------|-------------|
| **File** | Ім'я файлу |
| **xx-bit mono** | Розрядність (8 чи 16) і кількість каналів |
| **Sample rate** | наприклад, `48000Hz` |
| **Title** | Назва з заголовка WAV (якщо є) |
| **Duration** | Тривалість у секундах |

## Відображення форми сигналу

- Головна панель **форми сигналу** показує відліки поточного вікна.
- Під нею — стиснута смуга **огляду амплітуди** по всьому файлу кольоровим спектром (темніше — тихіше, яскравіше — гучніше).
- Невеликий **індикатор вікна** показує, яку частину файлу видно зараз.

## Елементи керування

| Елемент | Опис |
|---------|-------------|
| **Open** | Відкрити файл `.WAV` з SD-карти |
| **▶ / ■** | Запустити чи зупинити відтворення |
| **Vol** | Гучність |
| **Position (s / ms)** | Перейти до певного моменту файлу |
| **Sample** | Перейти за номером відліку |
| **Scale** | Масштаб форми сигналу (1 = 1 відлік на піксель, більше — віддалення) |
| **Cursor A** | Позиція курсора A (блакитний) на формі сигналу (0–239 пікселів) |
| **Cursor B** | Позиція курсора B (пурпуровий) (0–239 пікселів) |
| **Delta** | Різниця часу між курсорами A і B — як тривалість і відповідна частота |

## Відтворення

▶ запускає відтворення з поточної позиції. Індикатор показує прогрес. Поля позиції оновлюються під час відтворення. Зміни вигляду форми сигналу під час відтворення застосовуються після його завершення.
