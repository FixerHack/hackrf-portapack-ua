# Spectrum Analyzer (аналізатор спектра)

Аналізатор спектра зі скануванням, що працює як лабораторний прилад. Він у ландшафтному режимі й охоплює від діапазону 10 кГц до всього 1 МГц – 6 ГГц. Має три траси, чотири маркери, водоспад і органи керування, змодельовані з меню софт-кнопок настільного аналізатора.

**Розташування:** `Receive` → `Spectrum` (зовнішній застосунок, зелений значок).

> [!NOTE]
> Показання рівня **відносні, не каліброві**. Застосунок переводить дБFS у рівень, віднімаючи підсилення LNA, VGA і AMP. Щоб читати абсолютні дБм, виміряйте відоме джерело й задайте **AMPT → Offst** (опорне зміщення).

!!! info "Скріншот"
    Окремого знімка цього застосунку у вашому архіві немає — його приклад буде додано пізніше (див. [завдання](tasks)). Тримати пристрій потрібно горизонтально (див. нижче).

## Як тримати пристрій

Застосунок повертає екран у **ландшафтний** режим. За замовчуванням тримайте PortaPack поверненим на 90° **проти годинникової стрілки**. D-pad повертається разом з екраном, тож «ліворуч» завжди ліворуч на екрані. Якщо зручніше тримати інакше, скористайтеся **DISP → Flip**, щоб повернути зображення на 180°. Під час виходу екран повертається у портретний режим.

## Компонування екрана

```
┌──────────────────────────────────────────────────────────────┐
│ Ref -40.0dB 10dB/ LNA24 VGA20 AMP-               CONT 12.3ms │  рядок стану
│ M1 433.92MHz -52.31dB  D2 +25kHz -18.40dB                    │  показання маркерів
├──────────────────────────────────────────────────────────────┤
│                сітка спектра (10 × 10 поділок)               │
├──────────────────────────────────────────────────────────────┤
│                         водоспад                             │  (опційно)
├──────────────────────────────────────────────────────────────┤
│ CF 433.92MHz  Span 20MHz  RBW 156.2kHz  VBW 156.2kHz   1tune │  анотація
│ Center                                  433.920 000 MHz      │  активна функція
│ < │FREQ │SPAN │AMPT │ BW  │TRACE│ MKR │DISP │                │  софт-кнопки
└──────────────────────────────────────────────────────────────┘
```

| Область | Вміст |
|---|---|
| **Рядок стану** | Опорний рівень, масштаб дБ/поділку, підсилення LNA/VGA, стан AMP, опорне зміщення. Праворуч: стан сканування (`CONT` безперервне, `SGL` одне, `HOLD` зупинено) і час одного проходу. |
| **Показання маркерів** | Вибраний маркер і наступний увімкнений. `Mn частота рівень` для звичайного, `Dn ±Δf ±ΔdB` для дельта-маркера. |
| **Сітка** | 10 вертикальних поділок (дБ/поділку), 10 горизонтальних (діапазон/10), 320 точок відображення. |
| **Водоспад** | Історія минулих проходів, найновіший угорі. Кольори від чорного (низ) через синій, блакитний, жовтий і червоний до білого (на опорному рівні). |
| **Анотація** | Центральна частота, діапазон, RBW, VBW і скільки перестроювань потрібно на один прохід. `SETTLE LOW` помаранчевим — якщо час стабілізації замалий. |
| **Активна функція** | Параметр, який зараз змінюють енкодер і кнопки вгору/вниз. |
| **Софт-кнопки** | `<` (назад) і поточне меню. |

## Керування

Модель як у справжнього аналізатора: вибираєте **софт-кнопку**, вона стає **активною функцією**, потім змінюєте її значення енкодером чи стрілками.

| Введення | Дія |
|---|---|
| **Вліво / вправо** | Переміщення курсора софт-кнопок |
| **Select** | Натиснути виділену софт-кнопку |
| **Енкодер** | Змінити активну функцію дрібними кроками |
| **Вгору / вниз** | Змінити активну функцію грубими кроками (зазвичай одна поділка) |
| **Назад** | У верхнє меню; з верхнього меню — вихід |

### Типи софт-кнопок

- **Кнопки меню** (FREQ, SPAN…) відкривають підменю.
- **Кнопки значень** (Centr, Span, Ref, RBW…): перше натискання робить кнопку активною функцією (синє тло). Для частот друге натискання відкриває **клавіатуру частоти**; для списків (дБ/поділку, RBW, Window…) — перемикає на наступне значення.
- **Перемикачі** (Amp, Fill, Wfall, Flip…) вмикаються/вимикаються одразу. Зелений підпис — увімкнено.
- **Кнопки дій** (Peak, Zoom+, >CF…) виконуються одразу.

### Сенсорний екран

- **Дотик до софт-кнопки** — натиснути.
- **Дотик або перетягування по сітці** — перемістити вибраний маркер (якщо був вимкнений — вмикає його).
- **Дотик до рядка активної функції** при активному Center/Start/Stop/Span — відкрити клавіатуру частоти.

## Меню

### FREQ

| Кнопка | Функція |
|---|---|
| **Centr** | Центральна частота |
| **Start** | Початкова частота (змінюється діапазон, кінцева лишається) |
| **Stop** | Кінцева частота (змінюється діапазон, початкова лишається) |
| **Keys** | Клавіатура частоти для активного Start/Stop/Span, інакше для Center |

Діапазон налаштування — 0–7,25 ГГц (поведінка на краях залежить від пристрою).

### SPAN

| Кнопка | Функція |
|---|---|
| **Span** | Діапазон кроками 1-2-5 (мінімум 10 кГц). Повторне натискання — клавіатура. |
| **Full** | Прохід 1 МГц – 6 ГГц. |
| **Zoom+** | Удвічі звужує діапазон навколо центру. |
| **Zoom-** | Удвічі розширює діапазон. |
| **Last** | Повернення до попереднього діапазону. |

### AMPT (амплітуда)

| Кнопка | Функція | Діапазон / крок |
|---|---|---|
| **Ref** | Опорний рівень (верхня лінія сітки) | −150…+30 дБ; дрібно 0,1 дБ |
| **dB/dv** | Вертикальний масштаб | 1, 2, 5, 10, 20 дБ/поділку |
| **LNA** | Підсилення LNA | 0…40 дБ, крок 8 |
| **VGA** | Підсилення VGA | 0…62 дБ, крок 2 |
| **Amp** | ВЧ-підсилювач (+14 дБ) | перемикач |
| **Offst** | Опорне зміщення для кожного показання (калібрування, зовнішні атенюатори/підсилювачі) | ±100 дБ |
| **AutoR** | Встановлює опорний рівень так, щоб пік траси 1 був трохи нижче верхньої лінії | дія |

Зміна підсилення очищає траси. Показаний рівень уже враховує LNA/VGA/AMP, тож зміна підсилення зсуває рівень шуму, а не сигнали.

> [!TIP]
> Якщо сильні сигнали дають паразитні складові чи піднятий рівень шуму по діапазону — вхідний каскад перевантажено. Зменште LNA або вимкніть Amp.

### BW (смуга й сканування)

| Кнопка | Функція |
|---|---|
| **RBW** | Роздільна смуга. **Auto** вибирає найменший ШПФ, комірки якого не ширші за точку відображення. Можна задати N = 256, 512, 1024, 2048. |
| **VBW** | Відеосмуга: скільки ШПФ усереднюється на одне перестроювання (1, 2, 4, 8, 16, 32). Більше — рівніший шум, повільніший прохід. |
| **Windw** | Вікно ШПФ: Rectangular, Hann, Blackman-Harris (за замовчуванням), Flat top. Flat top — для точних амплітуд, Blackman-Harris — для динамічного діапазону. |
| **Detct** | Як комірки ШПФ об'єднуються в точку при широкому діапазоні: Peak (за замовчуванням), Average, Sample, Neg peak. |
| **Bins** | Які комірки ШПФ використовує кожне перестроювання (див. нижче). |
| **Settl** | Час стабілізації після перестроювання. 0…5000 мкс; `<min` помаранчевим, якщо замало. |

**Bins:**

- **Upper sideband** — лише комірки вище гетеродина; тримає сплеск DC/LO та дзеркала поза трасою. Правильний вибір для HackRF One (за замовчуванням).
- **Both sidebands** — комірки з обох боків гетеродина; кожне перестроювання охоплює вдвічі більше, прохід швидший. Для PRALINE (за замовчуванням). На HackRF One показує сплеск і дзеркала.

**Час стабілізації:**

| Апаратура | За замовчуванням | Безпечний мінімум |
|---|---|---|
| HackRF One | 400 мкс | 350 мкс |
| PRALINE | 100 мкс | 0 мкс |

### TRACE

Три незалежні траси: **Tr 1** жовта, **Tr 2** блакитна, **Tr 3** пурпурова.

| Кнопка | Функція |
|---|---|
| **Tr n** | Вибір траси, на яку діють інші кнопки |
| *режим* | Режим вибраної траси |
| **AvgN** | Скільки проходів усереднює Average: 2…128 (за замовчуванням 8) |
| **Fill** | Заливка під трасою 1 |
| **Clear** | Очистити вибрану трасу |

Режими: **ClrW** (останній прохід), **MaxH** (максимум — для сплесків), **MinH** (мінімум), **Avg** (усереднення), **View** (заморозити), **Blnk** (сховати).

### MKR (маркери)

Чотири маркери M1…M4.

| Кнопка | Функція |
|---|---|
| **Mkr n** | Зробити маркер активним (енкодер рухає на точку, вгору/вниз на поділку) |
| *режим* | Off → Norm → Delta (Delta читає відносно M1; у M1 дельти немає) |
| **Peak** | На найвищий пік траси |
| **NxtPk** | На наступний нижчий пік (пік рахується, якщо вищий за 3 дБ над впадиною) |
| **>CF** | Центральна частота = частоті маркера |
| **>Ref** | Опорний рівень = рівню маркера |
| **AllOf** | Вимкнути всі маркери |

### DISP (відображення й сканування)

| Кнопка | Функція |
|---|---|
| **Wfall** | Увімкнути/вимкнути водоспад під спектром |
| **DLine** | Пунктирна горизонтальна опорна лінія з налаштовуваним рівнем |
| **Cont / Singl** | Безперервне чи одне сканування |
| **Run** | Перезапустити прохід |
| **Flip** | Повернути зображення на 180° |

Водоспад додає щонайбільше ~30 рядків на секунду; при швидшому скануванні проміжні проходи об'єднуються з утриманням піка.

## Типові сценарії

**Знайти й виміряти сигнал:** SPAN → Full для огляду; MKR → Peak на найсильніший, потім >CF; SPAN → Zoom+ кілька разів; AMPT → AutoR.

**Зловити переривчасті чи стрибучі сигнали:** TRACE → Tr 1 у MaxH, залишити працювати, стежити за водоспадом; Clear для перезапуску.

**Виміряти зсув між двома сигналами:** MKR → M1 на перший (Peak); Mkr2 у режим Delta, перемістити на другий; показання `D2 ±Δf ±ΔdB`.

## Поради

- **Повільний прохід?** Широкі діапазони з вузьким RBW потребують багатьох перестроювань. Прискорити: RBW Auto, менше VBW, або Bins → Both sidebands (якщо апаратура підтримує).
- **Сплеск у центрі на HackRF One?** Це проникнення гетеродина. Тримайте Bins на Upper sideband.
- **Розмазані несучі між перестроюваннями?** Замалий час стабілізації — збільште Settl.
- **Налаштування зберігаються** у файлі `rx_specan`.
