# APRS TX (передавання APRS)

![APRS TX на пристрої](annotated/app-053.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-053).*

Застосунок APRS TX надсилає повідомлення на вибраній частоті з налаштуванням потоку APRS. Позначений як Beta, але надсилає декодовані повідомлення в AFSK у правильному форматі AX.25.

> [!NOTE]
> Це [зовнішній застосунок](External-apps-informations); має бути на SD-карті в теці `APPS/`.

!!! danger "Потрібна радіоаматорська ліцензія"
    APRS працює на радіоаматорських частотах. Передавання на них потребує дійсної радіоаматорської ліцензії майже в усіх країнах, зокрема в Україні (дозвіл на користування радіочастотним ресурсом). **Поле Source має містити ваш власний ліцензований позивний.** Використання вигаданого чи чужого позивного незаконне.

## Поля

- **Source** — ваш власний ліцензований радіоаматорський позивний (наприклад, W1ABC), до 6 буквено-цифрових символів. Далі **SSID** — число 0–15 (найпоширеніший для PortaPack — 0).
- **Dest.** — це **не** позивний приймальної станції, а адреса призначення APRS. Для загального використання рекомендовано **APRS**. Випадковий позивний або порожнє поле призведе до того, що декодери APRS проігнорують пакет. SSID = 0.
- **Path** — шлях діджипітерів: `WIDE1-1` (один стрибок, для більшості мобільних і портативних), `WIDE1-1,WIDE2-1` (два стрибки), порожнє — лише прямий радіозв'язок.
- **Info field** — вміст повідомлення (кнопка **Set**, до 30 символів). **Перший символ має бути дійсним ідентифікатором типу даних APRS (DTI)**, інакше декодери не визначать тип пакета.

## Ідентифікатори типу даних (DTI)

Перший символ поля Info визначає тип даних:

| Символ | Тип | Повідомлення | Приклад |
|-----------|------|-----------|-------------------|
| > | Статус (найпростіший, без координат) | Ні | >Hello from PortaPack |
| ! | Позиція без мітки часу | Ні | !4071.27N/07400.59W-Hello |
| = | Позиція без мітки часу | Так | =4071.27N/07400.59W-Hello |
| / | Позиція з міткою часу | Ні | /181654z4071.27N/07400.59W-Hello |
| @ | Позиція з міткою часу | Так | @181654z4071.27N/07400.59W-Hello |
| : | Повідомлення конкретній станції | Так | :W1XYZ    :Hello there |
| ; | Звіт про об'єкт | Ні | ;OBJECT   *181654z... |
| _ | Метеозвіт (без позиції) | Ні | _10092345c000s000g000t068 |
| T | Телеметрія | Ні | T#001,100,200,... |

«Повідомлення» означає, що станція здатна приймати й підтверджувати повідомлення APRS. **Для початку використовуйте `>` (статус)** — без координат, міток часу, декодується всіма програмами APRS.

Заповнювач `?GPS?` у полі Info автоматично замінюється поточними координатами GPS, якщо активний GPS-модуль або задано Manual GPS. Приклад: `!?GPS?-Hello from PortaPack`.

## Мітки часу

Мітки часу з'являються в пакетах позиції з DTI `/` чи `@`; формат завжди 7 символів:

| Формат | Приклад | Значення |
|--------|---------|------|
| DDHHMMz | 181654z | День 18, 16:54 UTC — рекомендовано |
| DDHHMM/ | 181654/ | День 18, 16:54 місцевий час |
| HHMMSSh | 165400h | 16:54:00 UTC |

Довідник протоколу APRS рекомендує завжди використовувати формат zulu (z).

## Формат координат

- Широта: `DDmm.hhN` або `DDmm.hhS` (8 символів).
- Довгота: `DDDmm.hhE` або `DDDmm.hhW` (9 символів — завжди 3 цифри градусів, з провідним нулем за потреби).

Приклад: `4071.27N/07400.59W` — район Нью-Йорка. Символ між широтою й довготою — ідентифікатор таблиці символів (`/` основна, `\` альтернативна), символ одразу після довготи — код символу (`-` будинок, `>` авто, `[` бігун, `/` точка). Повний список — [APRS Symbol Tables](http://www.aprs.org/symbols.html).

## Висота

Коли є реальна позиція, висота передається як стандартне розширення коментаря APRS `/A=aaaaaa` після позиції. Вводиться в **метрах** у виборі позиції, конвертується у **фути** для шестизначного поля `/A=`.

## Частота

APRS працює на виділених частотах за регіонами:

| Частота | Регіон |
|-----------|--------|
| 144,390 МГц | Північна Америка |
| **144,800 МГц** | **Європа, Африка, Росія — використовуйте в Україні** |
| 144,575 МГц | Нова Зеландія |
| 144,640 МГц | Японія, Східна Азія |
| 145,175 МГц | Австралія |
| 145,825 МГц | МКС (у світі, лише коли МКС у межах дальності) |
| 432,500 МГц | Європа (UHF) |

За замовчуванням у застосунку 144,390 МГц.

## Налаштування підсилення

Унизу екрана: крок частоти, девіація (наприклад, 5 кГц), **Gain IF** (0–47; колір показує сумарну потужність: 0–17 зелений, 18–38 жовтий, 39–47 помаранчевий), **Amp** (0 або 14 дБ). Передавання починається кнопкою **Start** і зупиняється автоматично після надсилання пакета.

## Приклади

**Найпростіший (статус):**
- Source: W1ABC, SSID: 0; Dest.: APRS, SSID: 0; Path: WIDE1-1
- Info field: `>Hello from PortaPack`; Частота: 144,800 МГц (Європа)

**Позиція з міткою часу, висотою й коментарем:**
- Info field: `@181654z4071.27N/07400.59W-Hello from NYC /A=105`

## Протокол

APRS передається через **AX.25** модемом **Bell 202** на **1200 біт/с** (AFSK): тон **1200 Гц** — mark, **2200 Гц** — space.
