# OOK (передавання OOK-сигналів)

![OOK на пристрої](annotated/app-055.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-055).*

!!! danger "Лише власне обладнання"
    Застосунок призначений виключно для експериментів на обладнанні, яким ви володієте чи маєте дозвіл тестувати. Ви відповідаєте за дотримання закону.

OOK TX передає сигнали з амплітудною маніпуляцією (On-Off Keying) за протоколами відомих мікросхем-кодувальників. Зазвичай застосовується для тестування пультів, відчинювачів воріт і подібних пристроїв на 315 / 433,92 МГц. Дві вкладки: **Config** (ручне складання кадру) і **de Bruijn** (автоматичне сканування кодів).

## Вкладка Config

- **Type** — протокол мікросхеми. 14 типів (2260-R2, 2260-R4, 2262, 16-bit, 1527, 526E, 12E, 5026, UM3750, UM3758, BA5104, 145026, HT6xxx, TC9148) з різними символами адреси/даних, довжиною слова й типовою тактовою частотою.
- **Repeat** (1–99) — мінімальна кількість повторів кадру.
- **Clk** (1–1000 кГц) — тактова частота генератора кодувальника (змінює **Frame**).
- **Frame** (300–99999 мкс) — тривалість кадру (змінює **Clk**). Зв'язок: `frame_мкс = період_такту_мкс × довжина_слова`.
- **Symbols** — бітовий шаблон (A = адреса, D = дані, S = синхро; символи 0, 1, F залежно від типу).
- **Waveform** — живий перегляд форми сигналу.

## Вкладка de Bruijn

Передає послідовність де Брейна — циклічну послідовність, що містить кожну n-бітову комбінацію рівно раз. Використовується для сканування всіх можливих кодів заданої довжини.

- **Length** (3–24 біти) — довжина кодового слова n (охоплює всі 2ⁿ комбінацій).
- **Bit length** (два поля) — тривалість кожного біта в мкс (десятки + одиниці). Діапазон 10–889 мкс.

## Спільні елементи

- **Frequency / Gain / AMP** — стандартні (за замовчуванням 433,920 МГц).
- **Start / Stop** — почати/перервати.

Налаштування — у `tx_ook.ini`.
