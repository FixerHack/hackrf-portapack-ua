# Власна заставка (splash screen)

## Вступ

*Набрид стандартний екран увімкнення? Хочете власне зображення під час старту? Це можливо!*

Збережіть **24-бітовий BMP розміром 240×304** з назвою `splash.bmp` у корені SD-карти — і він стане заставкою під час увімкнення!

Для PortaRF роздільність — **320×464**.

Починаючи з прошивки 1.7.4, BMP-заставки з SD-карти можна переглядати у File Manager і робити поточною заставкою одним кліком.

Готові зображення можна знайти й поділитися у каналі `#splash-screens` на нашому [Discord](https://discord.gg/tuwVMv3).

Також є https://ppsplash.creativo.hu/ — там можна вибрати й завантажити заставки з добірки.

І звісно, можна скористатися https://hackrf.app/, щоб завантажити їх прямо в теку SPLASH (потрібна прошивка ≥ 2.0.1).

> [!TIP]
> Якщо заставку в налаштуваннях увімкнено, а файлу `/splash.bmp` на SD-карті немає, при кожному завантаженні показується випадкова заставка з теки SPLASH.

> [!WARNING]
> У новіших прошивках заставку вмикають/вимикають прапорцем у **Settings → Splash settings** ([Splash settings](Settings#splash-settings)). Не забудьте його позначити, якщо заставка не показується!

## Інструменти / як зробити

Змініть розмір у будь-якому графічному редакторі або скористайтеся `convert` з [ImageMagick](https://imagemagick.org) — потужного відкритого інструмента обробки зображень для всіх поширених ОС.

> [!NOTE]
> Починаючи з версії 7 [ImageMagick](https://imagemagick.org), команда `convert` чи `magick convert` видає попередження, що вона застаріла і слід використовувати лише `magick`.

```
$ convert source.jpg -resize 240x304 destination.bmp
```

### Якщо з'являються поля ліворуч і праворуч і вони вам не потрібні

```
$ convert source.jpg -resize 240x304 -gravity center -extent 240x304 destination.bmp
```

### Щоб вибрати колір заповнення при зміні розміру, додайте `-background колір` після `source.jpg`

```
$ convert source.jpg -background "#000000" -resize 240x304 -gravity center -extent 240x304 destination.bmp
```

або

```
$ convert source.jpg -background black -resize 240x304 -gravity center -extent 240x304 destination.bmp
```

Список готових кольорів: `convert -list color`.

### Перевірка параметрів заставки

```
$ identify destination.bmp
destination.bmp BMP3 240x300 240x304+0+0 8-bit sRGB 216054B 0.000u 0:00.000
```

Якщо написано «8-bit» — усе правильно. Це кількість бітів на кожну колірну складову; для sRGB 8+8+8 = 24 біти.

> [!TIP]
> Якщо ви зберегли зображення іншою програмою і `identify` показує правильні параметри, а заставка все одно не працює — сконвертуйте його ще раз за допомогою [ImageMagick](https://imagemagick.org) за інструкцією вище.

## Обмеження

- зображення має бути 24-бітовим BMP;
- ширина — рівно 240 пікселів;
- висота — від 1 до 304 пікселів; зайві рядки обрізаються.
