# Replay (відтворення IQ)

![Replay на пристрої](annotated/app-008.jpg){ width="360" }

*Скріншот з пристрою: [Трансівери, Recon, Capture…](Screens-Other#shot-008).*

Replay передає записані файли IQ (`.C16`, `.C8` або `.CU8`) в ефір. Файли можна відтворювати окремо або об'єднувати в плейлист (`.PPL`) для послідовного відтворення з необов'язковими паузами між записами.

!!! danger "Передавання"
    Replay **передає** записаний сигнал. Відтворення чужих сигналів (наприклад, пультів) без дозволу може бути незаконним. Див. [Призначення та законність](Intended-Use-and-Legality).

## Відображення

- **Рядок 1** — ім'я завантаженого файлу запису.
- **Рядок 2** — частота (редагується) і частота дискретизації поточного треку. Праворуч два індикатори: верхній — позиція в плейлисті, нижній — прогрес передавання файлу.
- **Рядок 3** — тривалість треку в секундах, підсилення TX (0–47), AMP TX (0/14), прапорець Loop (за замовчуванням увімкнено) і кнопка play/stop.
- **Рядок 4** — номер треку / всього (наприклад, `1/2`) ліворуч, ім'я плейлиста праворуч.

Під час передавання знизу показується живий водоспад.

## Елементи керування

- **◄ / ►** — попередній/наступний трек.
- **📄 (Додати файл)** — вибрати файл `.C16`/`.C8`/`.CU8` і додати в кінець плейлиста.
- **🗑 (Видалити)** — видалити вибраний трек із плейлиста.
- **📂 (Відкрити)** — завантажити плейлист `.PPL` (замінює поточний).
- **💾 (Зберегти)** — зберегти поточний плейлист.
- **Loop** — після останнього треку плейлист починається спочатку.
- **▶ / ■** — почати/зупинити відтворення.

Поле частоти редагується для кожного треку й не зберігається у файл плейлиста.

## Відтворення одного файлу

Коли застосунок відкривається з порожнім плейлистом, фокус одразу на кнопці «Додати файл». Натисніть її, виберіть файл — і фокус переходить на кнопку play, що дозволяє швидке відтворення у два натискання. Файл можна також відкрити прямо з File Manager.

## Файли плейлистів

Плейлисти мають розширення `.PPL` і зберігаються в теці `PLAYLIST/`. Це звичайні текстові файли з роздільником-комою:

```
АБСОЛЮТНИЙ_ШЛЯХ_ДО_ФАЙЛУ,ЗАТРИМКА_МС
# Рядки, що починаються з #, ігноруються
```

Затримка (у мілісекундах) необов'язкова.

> [!WARNING]
> Передзатримка реалізована як блокувальна пауза в потоці інтерфейсу. Довга затримка робитиме пристрій ніби «завислим» на цей час, і перервати її можна лише скиданням пристрою.

Приклад:

```
# Плейлист
/SAMPLES/TeslaChargePort_US.C16
/SAMPLES/TeslaChargePort_EU_AU.C16,100
```

Відтворює файл US, потім пауза 100 мс, потім файл EU/AU.

**Якщо немає метаданих:** якщо у файлу немає відповідного `.TXT`, застосовується поточна частота передавання й частота дискретизації 500 000 Гц.

## Збереження налаштувань

Налаштування зберігаються в `tx_replay.ini`.
