# SubGhzD (декодер пультів нижче 1 ГГц)

![SubGhzD на пристрої](annotated/app-028.jpg){ width="360" }

*Скріншот з пристрою: [Приймачі: огляд застосунків](Screens-Receivers#shot-028).*

SubGhzD (Sub-GHz Decoder) — пасивний приймач для декодування OOK/AM-сигналів пультів дистанційного керування нижче 1 ГГц: пульти воріт, гаражних дверей, дверні дзвінки, пристрої «розумного дому» та подібні передавачі ISM-діапазону. Він визначає протокол і показує декодовані дані у прокручуваному списку.

## Налаштування

- **Frequency** — за замовчуванням **433,92 МГц**. Змінюється енкодером або цифровою клавіатурою для інших ISM-діапазонів (наприклад, 315 МГц, 868 МГц).
- **RF Amp** (0 або 1) — вмикає/вимикає внутрішній ВЧ-підсилювач. Обережно з сильними сигналами.
- **LNA gain** (0–40) — підсилення малошумного підсилювача. Див. [Проблеми з якістю приймання](Help!-Im-not-receiving-anything!---Receive-Quality-Issues#gain-settings).
- **VGA gain** (0–62) — підсилення підсилювача основної смуги.
- **Clear** — очищає список декодованих сигналів на екрані. Файл журналу не змінюється.
- **Log** — якщо позначено, декодовані пакети записуються у CSV-файл з міткою часу на SD-карті: `LOGS/SUBGHZDLOG_YYYYMMDD_HHMMSS.CSV`. Заголовок файлу: `; Type; Bits; Data;`.

## Список декодованих сигналів

Кожен декодований пакет показується рядком із трьома стовпцями: **Type** (назва протоколу), **Bits** (довжина кадру в бітах) і **Age** (секунд від останнього прийому). Дублікати за вмістом сигналу об'єднуються: повторні передачі від того самого пульта оновлюють лічильник віку, а не додають нові рядки.

Вибір рядка відкриває детальний вигляд: тип протоколу, серійний номер, код кнопки, значення лічильника та інші декодовані поля для цього протоколу.

Для сигналів **KeeLoq** і **Superrollo** детальний вигляд завжди показує код Fix і зашифроване значення hop. Розшифроване значення **Hop** і кнопка **Save** показуються лише тоді, коли в `KEELOQKEYS/MFCODES` знайдено відповідний ключ виробника. Без ключа сигнал приймається й показується, але не може бути розшифрований і збережений для повторного передавання.

Коли кнопка Save доступна, вона зберігає дані декодованого пульта в `KEELOQREMOTES/<ім'я>.KEELOQ` на SD-карті для використання в застосунку [KeeLoq TX](KeeLoq-TX).

## Підтримувані протоколи

Реалізовано 45 протоколів з фіксованим і частково плаваючим кодом (KeeLoq) у діапазонах ISM 300–868 МГц:

Princeton, Bett, CAME, CAME Atomo, CAME Twee, Chamberlain Code, Clemsa, Doitrand, Dooya, FAAC, Gate TX, Holtek, Holtek HT12X, Holtek HT6P20B, Honeywell, Honeywell WDB, Hörmann, IDO, Intertechno V3, KeeLoq, Kingates Stylo 4K, Linear, Linear Delta 3, Magellan, Marantec, Marantec24, Mastercode, Megacode, Nero Radio, Nero Sketch, Nice FLO, Nice FLO RS, Phoenix V2, Power Smart, Security+ V1, Security+ V2, SMC5326, Somify Keytis, Somify Telis, Star Line, X10, Legrand, Gangqi, Restaurant Pager, Superrollo (GW60/HCS361).

> Примітка: Hörmann BiSecure (на основі FM) розпізнається, але в цьому застосунку не реалізований, бо потребує FM-демодуляції.

## Superrollo (GW60/HCS361)

Пульти Superrollo GW60 використовують чип плаваючого коду HCS361 із 67-бітовим OOK-кадром при Te=450 мкс. SubGhzD декодує ці сигнали й показує їх як тип протоколу **Superrollo**.

Повний порядок дій:

1. Налаштуйтеся на 433,92 МГц і натисніть кнопку пульта Superrollo.
2. Сигнал з'явиться у списку як **Superrollo**, 67 біт.
3. Відкрийте детальний вигляд — код Fix і зашифрований hop показуються завжди.
4. Якщо в `KEELOQKEYS/MFCODES` є запис `Superrollo`, також з'являться розшифроване значення Hop і кнопка **Save**.
5. Натисніть Save, введіть ім'я файлу — декодований пульт буде збережено в `KEELOQREMOTES/<ім'я>.KEELOQ`.
6. Відкрийте [KeeLoq TX](KeeLoq-TX), завантажте файл і передайте.

Без дійсного ключа виробника в MFCODES кроки 4–6 недоступні. Формат файлу MFCODES описано на сторінці [KeeLoq TX](KeeLoq-TX).

!!! warning "Лише власне обладнання"
    Повторне передавання кодів пультів допустиме лише для власних пристроїв або з дозволу власника.

## Збереження налаштувань

Стан прапорця Log зберігається в `rx_subghzd.ini` на SD-карті, якщо в глобальному меню [Settings](Settings#app-settings) увімкнено **App Settings**.
