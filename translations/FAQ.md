# Поширені запитання (FAQ)

- **Питання:** Мій пристрій `не завантажується` / `білий екран` / `чорний екран` після `оновлення прошивки` / `скидання` / `розрядження батарейки` / `виймання SD-карти`.
  > **Відповідь:** Прочитайте [Не завантажується](Won't-boot) і [Меню конфігурації](Config-Menu).
- **Питання:** Щось `працює ненормально` / `аварійно завершилось` / `не працює` / `поводиться неочікувано` / `Guru Meditation`.
  > **Відповідь:** Спробуйте [Повне скидання](Completely-reset); якщо не допомогло — [Оновлення Xilinx CPLD на платі HackRF](Updating-the-Xilinx-CPLD-on-hackrf-board); якщо досі не допомогло — [повідомте про проблему на GitHub](https://github.com/portapack-mayhem/mayhem-firmware/issues/new/choose).
- **Питання:** `Немає заставки` / `не показується час і дата` / `не працює сенсорний екран` / `зникла піктограма в рядку стану` / `ненормальний тайм-аут підсвічування` / `ненормально працює диск енкодера`.
  > **Відповідь:** Це параметр у налаштуваннях — перегляньте [Settings](Settings).
- **Питання:** Пише `xxx missing` / `can't find xxx` / `xxx read error` / `xxx is outdated` або ви `не бачите xxx`.
  > **Відповідь:** Переконайтеся, що вміст SD-карти правильно скопійовано та відповідає версії вашої прошивки.
- **Питання:** На водоспаді / IQ / спектрі з'являється несподіваний сплеск.
  > **Відповідь:** Це або [зміщення постійної складової (DC offset)](https://hackrf.readthedocs.io/en/latest/faq.html#what-is-the-big-spike-in-the-center-of-my-received-spectrum), або шум від живлення. Щоб зменшити шум, спробуйте живлення від внутрішнього акумулятора. З DC offset зробити нічого не можна.
