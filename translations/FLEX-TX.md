# Flex TX (передавання пейджерів FLEX)

![Flex TX на пристрої — екран передавача](annotated/ui-transmitter-pocsag.jpg){ width="320" }

*Окремого скріншота Flex TX у вашому архіві немає (див. [завдання](tasks)).*

## Вступ

Застосунок передає повідомлення пейджерів за протоколом [FLEX](https://en.wikipedia.org/wiki/FLEX_(protocol)) — односпрямованим пейджинговим протоколом Motorola з вищою пропускною здатністю, ніж POCSAG. Передавач генерує повний кадр FLEX: синхрошаблони, FIW, BIW (з необов'язковими метаданими мережі), кодування адреси й навантаження. Призначений для тестування й навчання з ліцензованим обладнанням.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

!!! danger "Потрібна ліцензія"
    FLEX працює на ліцензованих частотах. Передавання на комерційних пейджингових частотах без дозволу незаконне в усіх юрисдикціях.

## Елементи керування

### Capcode

Адреса пейджера (0–4297068542). Рядок під полем показує тип адреси й обчислені кадр/фазу:

| Діапазон | Тип |
|-------|------|
| 1 – 1 933 312 | Коротка адреса |
| 2 058 240 – 2 062 335 | Мережева адреса |
| 2 041 856 – 2 058 239 | Інфослужба |
| 2 062 336 – 2 062 351 | Тимчасова група #0–15 |
| 2 062 352 – 2 062 367 | Повідомлення оператора |
| 2 101 249 – 4 297 068 542 | Довга адреса (2 слова) |

Для звичайних повідомлень дійсні лише короткі й довгі адреси.

### Speed

Поки підтримується лише **1600/2FSK** (1600 бод, 2-рівнева FSK, фаза A) — базовий режим FLEX, який підтримують усі пейджери FLEX.

### Type

- **Alphanumeric** — вільний текст ASCII (до 240 символів);
- **Numeric** — BCD-цифри (дійсні символи `0-9 U - ] [ пробіл .`);
- **Short/tone** — короткий числовий вектор з порожнім навантаженням (пейджер декодує як сигнал);
- **Short numeric** — короткі BCD-цифри прямо у векторному слові (коротка адреса — до 3 цифр, довга — до 8).

### Message

Текст (кнопка **Set message**, до 240 символів). Для Numeric/Short numeric дійсні лише BCD-символи.

### Set Params (параметри FLEX)

Налаштування полів BIW, що несуть метадані мережі:

- **Date** — дата (рік 1994–2025, місяць, день);
- **Time** — час (година, хвилина, секунда з кроком 7,5 с);
- **TZ / DST / ExtSec** — часовий пояс, літній час, розширені секунди;
- **LocID / CovZone** — ID локального передавача (0–511) і зона покриття (0–31);
- **Country Code** — код країни (0–1023);
- **Roam** — прапорець роумінгу;
- **Msg#** — номер повідомлення (0–63, збільшується автоматично);
- **ERS** — цикли повторної синхронізації перед кадром (Count 1–10).

Поля дати й часу заповнюються з годинника RTC при відкритті застосунку.

## Передавання

- **Frequency** — за замовчуванням 931,74 МГц.
- **Gain** (0–47 дБ), **AMP** (0 або +14 дБ).

**START** починає передавання. Індикатор показує етапи: ERS-сплески (якщо ввімкнено), кадр 1/2 (нове повідомлення), кадр 2/2 (повтор). Через обмеження буфера основної смуги PortaPack передає окремі кадри як одиничні сплески, а не безперервний синхронізований сигнал.

## Через USB

Flex TX можна запустити віддалено через USB повідомленням типу `FlexTosend`.

Налаштування — у `SETTINGS/tx_flex.ini`.
