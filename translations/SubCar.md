# SubCar (декодер автомобільних брелоків)

![SubCar на пристрої](annotated/app-031.jpg){ width="360" }

*Скріншот з пристрою: [Приймачі: огляд застосунків](Screens-Receivers#shot-031).*

SubCar — застосунок-приймач для декодування сигналів безключового доступу (RKE) автомобільних брелоків. Він пасивно слухає на налаштованій частоті й намагається зіставити вхідні сигнали з бібліотекою відомих протоколів виробників, показуючи результати у прокручуваному списку.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Налаштування

- **Frequency** — за замовчуванням **433,92 МГц**, стандартний європейський діапазон RKE. Змінюється енкодером або цифровою клавіатурою для інших регіональних діапазонів (наприклад, 315 МГц у Північній Америці).
- **RF Amp** (0 або 1) — вмикає/вимикає внутрішній ВЧ-підсилювач.
- **LNA gain** (0–40) — підсилення малошумного підсилювача. Див. [Проблеми з якістю приймання](Help!-Im-not-receiving-anything!---Receive-Quality-Issues#gain-settings).
- **VGA gain** (0–62) — підсилення підсилювача основної смуги.
- **Mode** — режим демодуляції: **AM** (за замовчуванням) або **FM**. Більшість протоколів брелоків використовує AM (OOK); FM може знадобитися для деяких регіональних чи новіших реалізацій.
- **Clear** — очищає список на екрані (файл журналу не змінюється).
- **Log** — якщо позначено, декодовані пакети записуються у CSV-файл з міткою часу на SD-карті: `LOGS/SubCarLOG_YYYYMMDD_HHMMSS.CSV`. Заголовок файлу: `; Type; Bits; Data;`.

## Список декодованих сигналів

Кожен декодований пакет показується рядком із трьома стовпцями: **Type** (назва протоколу), **Bits** (довжина кадру в бітах) і **Age** (секунд від останнього прийому). Дублікати об'єднуються: повторні натискання тієї самої кнопки брелока оновлюють лічильник віку, а не додають новий рядок.

Вибір запису відкриває детальний вигляд: тип протоколу, серійний номер, код кнопки та додаткові декодовані поля, якщо вони є для цього протоколу.

## Підтримувані протоколи

| Протокол | Виробник |
|----------|-------------|
| Suzuki | Suzuki |
| VW | Volkswagen (кнопки: Lock, Unlock, Trunk, Panic, комбінації) |
| Subaru | Subaru |
| Kia V0–V5 | KIA |
| Ford V0 | Ford |
| Fiat V0 | Fiat |
| BMW V0 | BMW |

> Примітка: деякі протоколи з повним шифруванням плаваючого коду (Kia V6, PSA/Peugeot-Citroën) розпізнаються, але не декодуються, бо корисне навантаження повністю зашифроване.

## Збереження налаштувань

Режим модуляції та стан прапорця Log зберігаються в `rx_subcar.ini` на SD-карті, якщо в глобальному меню [Settings](Settings#app-settings) увімкнено **App Settings**.
