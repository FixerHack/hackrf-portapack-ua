# POCSAG TX (передавання пейджерів POCSAG)

![POCSAG TX на пристрої](annotated/app-066.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-066).*

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Вступ

Застосунок передає повідомлення за протоколом **POCSAG** — односпрямованим пейджинговим протоколом із 2-FSK модуляцією на вузькосмугових FM-каналах. Призначений для тестування, експериментів і навчання з ліцензованим радіоаматорським обладнанням або на частотах, на які у вас є дозвіл.

## Частота

За замовчуванням **466,175 МГц** (комерційна пейджингова частота в деяких регіонах). Змініть під своє використання:

| Частота | Використання |
|-----------|-----|
| 439,9875 МГц | Радіоаматорський DAPNET (у світі) |
| 466,075 МГц | Комерційний пейджинг (залежить від регіону) |
| 466,175 МГц | Комерційний пейджинг (за замовчуванням) |

Для радіоаматорського DAPNET використовуйте **439,9875 МГц** на **1200 біт/с** (реєстрація: [DAPNET](https://hampager.de)).

## Параметри повідомлення

### Bitrate

- **512 біт/с** — старі пейджери, більша дальність;
- **1200 біт/с** — найпоширеніша (DAPNET і більшість систем);
- **2400 біт/с** — швидше, менша дальність.

### Address

Адреса пейджера — 7-значне десяткове поле (0000000–9999999). Протокол підтримує 21-бітові адреси (макс. 2 097 151). Адреса 0 — широкомовна (приймають усі пейджери).

### Type

- **Address only** — без тексту (запуск тон-пейджерів);
- **Numeric only** — лише цифри: `0–9`, `S`, `U`, `]`, `[`, `-`, пробіл;
- **Alphanumeric** — повний текст ASCII, до 80 символів.

### Function

2-бітове поле (A–D), його значення визначає приймач. Умовно: A — тільки сигнал, B — цифрове, C — буквено-цифрове, D — голос. У разі сумніву — **A**.

### Phase

- **P (Positive)** — біти інвертуються перед передаванням;
- **N (Normal)** — як є (стандартна полярність POCSAG).

Якщо пейджер не реагує з однією полярністю, спробуйте іншу.

### Message

Текст, максимум **80 символів**. Введіть кнопкою **Set message**.

## Елементи керування передаванням

- **Frequency / Frequency Step** — частота й крок.
- **Channel Bandwidth** — зафіксовано на 1,75 МГц (вузькосмугова FM).
- **Gain (IF)** — підсилення TX (0–47).
- **AMP** — ВЧ-підсилювач (0 або +14 дБ).
- **START** — почати передавання.

## Через консоль USB

POCSAG TX можна запустити віддалено командою `sendpocsag` у [послідовній консолі USB](USB-Serial-Console):

```
sendpocsag <addr> <msglen> [baud] [type] [function] [phase]
```

Приклад — буквено-цифрове повідомлення на адресу 1234567 на 1200 біт/с:

```
sendpocsag 1234567 12 1200 2 A N
```

Потім надішліть: `Hello World!`.

## Законність

POCSAG працює на ліцензованих частотах. Передавання на комерційних пейджингових частотах без дозволу незаконне в усіх юрисдикціях. Передавання на радіоаматорських частотах (наприклад, 439,9875 МГц для DAPNET) потребує дійсної радіоаматорської ліцензії.

## Перевірка

Надійний спосіб перевірити передавання — застосунок [POCSAG RX](POCSAG-Receiver) на другому PortaPack або SDR-приймач із PDW (Windows) чи multimon-ng (Linux).
