# CVS Spam (кнопки виклику допомоги в магазинах)

![CVS Spam на пристрої](annotated/app-081.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-081).*

!!! danger "Потрібен дозвіл"
    Передавання сигналів, що запускають системи виклику допомоги в магазинах, без дозволу може бути незаконним. Використовуйте лише для досліджень систем, якими ви володієте або маєте дозвіл тестувати.

CVS Spam відтворює заздалегідь записані файли IQ, щоб запустити бездротові кнопки виклику допомоги покупцям (як у CVS Pharmacy тощо). Це передавач «сирого» IQ-відтворення — він не генерує сигнали програмно, а програє файли `.c16` чи `.cu8` з SD-карти.

Частота зафіксована на **433,920 МГц**.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Підготовка SD-карти

Покладіть файли `.c16` чи `.cu8` у теку `CVSFILES/`. Застосунок показує всі знайдені файли (до 50 на сторінку). Якщо тека порожня — «Empty directory!».

## Елементи керування

- **Список файлів** — прокручування; виділений файл буде передано кнопкою CALL.
- **`<` / `>`** — сторінки.
- **CALL** — передати вибраний файл раз; вибір того самого файлу під час передавання зупиняє його.
- **CHAOS** — безперервне випадкове відтворення (новий файл за псевдовипадковою послідовністю LFSR, пауза 100 мс).
- **STOP** — зупинити.
