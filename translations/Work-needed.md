# Потрібна робота (ідеї майбутніх покращень)

Прошивка Mayhem постійно розвивається. Якщо маєте час і навички, є кілька можливостей для внеску.

> **Примітка:**
> - Щоб тримати список Issues на GitHub чистим, деякі пропозиції покращень закрито на GitHub і перенесено сюди — тож при пошуку додавайте «closed» issues.
> - Через обмеження розміру ROM нові застосунки, можливо, доведеться робити «зовнішніми» (завантаженими з файлу на SD-картці, а не з ROM).

## Список побажань

- **Analog TV:** додати підтримку NTSC.
- **Аудіо:** додати запис із мікрофона у WAV-файл.
- **Файли захоплення:** складніше редагування файлів захоплення.
- **ERT-лічильники:** підтримка більшої кількості типів комунальних лічильників.
- **Зовнішні застосунки:** винести незавершені чи рідко використовувані застосунки назовні.
- **Порт з інших проєктів:** підтримка додаткових радіопристроїв/функцій з інших відкритих проєктів (rtl_433, Flipper Zero тощо).
- **SD-картка:** покращити продуктивність.
- **Шумоглушник (squelch):** підтримка в усіх режимах приймача; уніфікувати значення між застосунками.
- **TPMS:** підтримка більшої кількості типів датчиків TPMS.
