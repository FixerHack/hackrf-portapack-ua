# Doom

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

Гра Doom від RocketGod (@rocketgod-git). Дуже спрощений Doom, але навіть він уже важкий для нашого маленького пристрою :-)

## Керування

- **Select** — почати гру.
- **Кнопки напрямку** — рух.
- **Select** — стріляти.
- Торкніться лівого верхнього кута екрана, щоб вийти.
