# Battleship (морський бій)

Battleship — морська стратегія для двох гравців по радіо між двома PortaPack. Кожен гравець розставляє кораблі на полі, а потім гравці по черзі називають координати, намагаючись потопити флот суперника. Ходи передаються й приймаються бездротово через основну смугу POCSAG2 — це єдина гра в Mayhem для двох пристроїв з радіозв'язком.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

!!! warning "Передавання"
    Гра **передає** радіосигнал. Використовуйте дозволену частоту й мінімальну потужність (див. [Призначення та законність](Intended-Use-and-Legality)).

## Підготовка

1. Обидва гравці вибирають частоту й підсилення — вони мають збігатися на обох пристроях.
2. Кожен гравець вибирає колір команди: **Red** або **Blue**.
3. Кораблі розставляються на полі сенсорним екраном або енкодером.
4. Коли обидва готові, гра починається.

## Керування

- **Сенсорний екран** — торкайтеся, щоб розставляти кораблі й вибирати координати під час гри.
- **Енкодер** — переміщення по полю.
- **Кнопки напрямку** — переміщення курсора.
- **Select** — підтвердити дію.

## Налаштування радіо

- **Frequency** — налаштовується; обидва пристрої мають використовувати ту саму частоту.
- **RF Amp**, **LNA**, **VGA** — стандартне підсилення для TX і RX.

## Рахунок

Перемоги й поразки показуються на екрані як `W:x L:x`.
