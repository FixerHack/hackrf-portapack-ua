# Freq. Manager (менеджер частот)

![Freq. Manager на пристрої](annotated/app-089.jpg){ width="360" }

*Скріншот з пристрою: [Утиліти](Screens-Other#shot-089).*

**Freq Manager** (Freqman) — менеджер бази частот. Він дозволяє переглядати, створювати, редагувати й видаляти записи частот, згруповані в іменовані списки (категорії). Ці списки спільні з іншими застосунками, як-от [Recon](Recon), [Scanner](Scanner) і [Audio](Audio-Receivers), які можуть завантажувати їх напряму.

## Розташування на SD-карті

Файли freqman зберігаються в теці `FREQMAN/` на SD-карті як звичайні файли `.TXT`. Кожен файл — одна категорія.

## Використання

Верхній рядок показує поточну категорію (файл). Обертайте енкодер, щоб перебирати категорії.

| Кнопка | Дія |
|--------|--------|
| 📄 (значок нового файлу) | Створити нову категорію |
| 🗑 (червоний кошик угорі) | Видалити поточну категорію |
| **Edit** | Відкрити повний екран редагування вибраного запису |
| **Frequency** | Швидко змінити лише частоту вибраного запису |
| **Description** | Швидко змінити лише опис вибраного запису |
| ➕ (значок додавання) | Додати новий запис у поточну категорію |
| ✖ (червоний значок видалення) | Видалити вибраний запис |
| **Exit** | Вийти із застосунку |

Екран редагування дозволяє задати: тип запису, частоту A, частоту B, модуляцію, смугу, крок, тон (CTCSS) і опис.

## Формат файлу freqman

Звичайний текст, один запис у рядку. Поля — пари `ключ=значення` через кому.

- Порожні рядки ігноруються.
- Рядки, що починаються з `#`, — коментарі.
- Максимальна довжина опису — 30 символів.
- Максимум записів у файлі — 150 (зайве обрізається).

> [!WARNING]
> Усе, що не відповідає відомому полю, мовчки ігнорується.

### Поля типу запису

Кожен запис має починатися з однієї з таких пар:

| Ключі | Тип | Опис |
|------|------|-------------|
| `f=частота` | Single | Одна частота |
| `a=початок,b=кінець` | Range | Діапазон частот для сканування |
| `r=rx_частота,t=tx_частота` | HamRadio | Радіоаматорський ретранслятор: частоти RX і TX. У режимі сканера TX сканується як одна частота. |
| `l=частота_прослуховування,t=tx_частота` | Repeater | Ретранслятор: частота прослуховування (також одиночна, коли режим ретранслятора неактивний) і зсув TX |

### Необов'язкові поля

| Ключ | Опис |
|-----|-------------|
| `m=модуляція` | Вид модуляції |
| `bw=смуга` | Смуга (має йти **після** `m=` у рядку) |
| `s=крок` | Крок частоти — має сенс лише для записів Range |
| `c=тон` | Частота тону CTCSS — має сенс лише для записів HamRadio |
| `d=опис` | Довільний опис (до 30 символів) |

### Можливі значення модуляції

| Значення | Примітки |
|-------|-------|
| `AM` | |
| `NFM` | |
| `WFM` | |
| `SPEC` | Спектр / «сирий» IQ |
| `AMFM` | Спеціальна: AM+FM демодуляція для КХ-метеофаксу (застосунок [WeatherFax](WeatherFax)) |
| `FMAM` | Спеціальна: FM+AM демодуляція для NOAA APT 137 МГц (застосунок [NOAA](NOAA)) |

### Можливі значення смуги

- **AM:** `DSB 9k`, `DSB 6k`, `USB+3k`, `LSB-3k`, `CW`
- **NFM:** `8k5`, `11k`, `12k5`, `16k`
- **WFM:** `80k`, `180k`, `200k`
- **SPEC:** `12k5`, `16k`, `25k`, `32k`, `50k`, `75k`, `100k`, `150k`, `250k`, `500k`, `600k`, `750k`, `1000k`, `1250k`, `1500k`, `1750k`, `2000k`, `2250k`, `2500k`, `3000k`, `3500k`, `4000k`, `4500k`, `5000k`, `5500k`

### Можливі значення кроку

`10Hz`, `50Hz`, `0.1kHz`, `1kHz`, `5kHz`, `6.25kHz`, `8.33kHz`, `9kHz`, `10kHz`, `12.5kHz`, `15kHz`, `25kHz`, `30kHz`, `50kHz`, `100kHz`, `250kHz`, `500kHz`, `1MHz`

## Приклад файлу

```
# Мій список частот
f=468000000,d=Single Freq
f=468000000,m=AM,d=Single Freq AM
f=468000000,m=NFM,bw=12k5,d=Single Freq NFM
f=468000000,m=WFM,bw=200k,d=Single Freq WFM
f=468000000,m=AM,bw=USB+3k,d=Single Freq AM USB
a=87000000,b=110000000,m=WFM,bw=200k,s=50kHz,d=WFM radio search
r=430150000,t=430550000,d=HAM relay
r=430150000,t=430550000,m=NFM,bw=12k5,c=88.5,d=HAM with CTCSS
l=430150000,t=431150000,m=SPEC,bw=1000k,d=1MHz repeat txoffset
```

!!! tip "Опис — латиницею"
    Екранна клавіатура не має кирилиці, тож описи (`d=`) пишіть латиницею — інакше можуть відображатися неправильно.
