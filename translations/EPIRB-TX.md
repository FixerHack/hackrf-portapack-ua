# EPIRB TX (симуляція аварійних маяків)

![EPIRB TX на пристрої](annotated/app-082.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-082).*

## Огляд

**EPIRB TX** імітує аварійні маяки **ELT/EPIRB/PLB** системи [КОСПАС-САРСАТ](https://www.sarsat.noaa.gov/cospas-sarsat-system-overview/).

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

!!! danger "НАДЗВИЧАЙНО ВАЖЛИВО"
    Застосунок передає **лише тестові** кадри маяка («Self-Test»). Його **НЕ МОЖНА** використовувати для надсилання справжніх (не тестових) даних маяка, бо це може **ініціювати пошуково-рятувальну операцію**. Використовуйте лише в екранованому середовищі. Застосунок призначений для тестування декодерів 406 МГц, які використовують рятувальні команди радіоаматорів.

## Маяки

Аварійні маяки КОСПАС-САРСАТ використовують на суднах (**EPIRB**), літаках (**ELT**) або особами (**PLB**), щоб допомогти знайти місце аварії. Є два покоління маяків 406 МГц:

- **Перше покоління (FGB)** — манчестерський BPSK-сигнал;
- **Друге покоління (SGB)** — модуляція DSSS-OQPSK.

## Можливості

Два режими передавання:

- **Сигнал 406 МГц** (BPSK для FGB або DSSS-OQPSK для SGB) з даними маяка;
- **Аварійний аудіосигнал AM 121,5 МГц**.

Дані маяка — з двох джерел: набір **тестових маяків** у файлі `EPIRB/BEACONS.TXT` або **ручний редактор** (вибір типу й розташування).

Кадри можна надсилати періодично (прапорець `Resend`) кожні **50 секунд**. Прапорець `AM signal` перемикає на AM-сигнал 121,5 МГц наприкінці кадру BPSK/OQPSK. `Send on change` надсилає новий кадр при зміні параметра.

## Протокол

FGB — манчестерська BPSK, 400 біт/с, фаза ±63°. SGB — OQPSK, 300 біт/с з розширенням DSSS. Аварійний AM-сигнал 121,5 МГц — аудіосигнал зі свіпом 3 Гц від 300 до 1600 Гц (типовий звук ELT).

## Режим редактора

- Тип маяка (`ELT` / `EPIRB` / `PLB`);
- протокол розташування (`Standard` / `User` / `National`);
- формат (`FGB` / `SGB`);
- країна;
- прапорець `Internal` — маяк має вбудований засіб визначення позиції;
- розташування через **локатор Maidenhead** або карту (кнопка `Set pos.`).

## Режим файлу BEACONS.TXT

Вибір маяка з прикладів у `EPIRB/BEACONS.TXT`. Прапорець `Slideshow` автоматично переходить до наступного маяка після кожного надсилання.

Формат `BEACONS.TXT` — CSV із трьох стовпців, роздільник `;`, рядки з `#` — коментарі: назва маяка, опис, дані (36-символьний hex для FGB із заголовком `FFFED0` або 63-символьний hex для SGB).

## Блок передавання

- `Resend every xx s.` — періодичне повторення;
- `AM signal` — передавати аварійний сигнал 121 МГц між кадрами;
- `AM frequency` — частота аварійного сигналу;
- `Send on change` — повтор при зміні;
- `Start`/`Stop` — активувати/зупинити симуляцію;
- `AM chan` / `BPSK chan` — канали для AM і BPSK/OQPSK.
