# LGE Tool (системи лазертагу)

![LGE Tool на пристрої](annotated/app-072.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-072).*

LGE Tool передає фірмові ВЧ-кадри керування деяких систем лазертагу в діапазоні ISM 868 МГц. Система використовує FSK-пакети на основі RFM69 з фіксованим ID мережі та синхрословом. Інструмент спочатку написав Furrtek для проєкту portapack-havoc.

!!! danger "Потрібен дозвіл"
    Інструмент призначений для досліджень і тестування обладнання, яким ви володієте чи керуєте. Передавання команд керування чужими системами без дозволу може бути незаконним.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Параметри радіо

Три фіксовані канали в діапазоні 868 МГц (за замовчуванням **868,067 МГц**):

| Канал | Частота |
|---------|-----------|
| 1 | 868,067 МГц |
| 2 | 868,183 МГц |
| 3 | 868,295 МГц |

Модуляція FSK, 9600 бод, девіація 4000 Гц, смуга 2 500 000 Гц, формат RFM69 (Network ID 5, Sync `0x2DD4`).

## Елементи керування

- **Frame** — тип кадру команди (див. нижче).
- **All ch.** (за замовчуванням увімкнено) — передавати на всіх трьох каналах по черзі.
- **Room** (1–2) — номер арени.
- **Text** — нік гравця чи команди (до 15 символів).
- **Team** (1–6) — номер команди.
- **Player** (1–50) — номер гравця.

## Типи кадрів

| Кадр | Опис | Поля |
|-------|-------------|-------------|
| **Key** | Імітує влучання у гравця | Room, Player |
| **Set nickname** | Призначає нік гравцю | Room, Player, Team, Text |
| **Set team** | Задає назву команди | Team, Text |
| **Brdcst nick** | Транслює нік усім | Player, Team, Text |
| **Start** | Команда початку гри | Room |
| **Game over** | Команда кінця гри | Room |
| **Set vest** | Налаштування жилета | див. нижче |

### Set vest

- **ID** (1–2) — ідентифікатор жилета.
- **Pow** (1–10) — потужність «зап».
- **Time** (1–25, ×100 мс) — тривалість «зап».
- **Heartbeat** (за замовчуванням увімкнено) — сигнал життя від жилета.
- **RX tick** (за замовчуванням увімкнено) — сигнал прийому від жилета.

Консоль показує «сирі» hex-байти кожного кадру. Налаштування — у `tx_lge.ini`.
