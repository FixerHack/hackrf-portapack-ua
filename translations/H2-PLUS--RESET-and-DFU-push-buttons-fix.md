# Виправлення кнопок RESET і DFU на старих PortaPack H2+ (плата v3.6)

Ця процедура виправляє дві проблеми деяких старих **PortaPack H2+ з платою v3.6**:

- кнопка **RESET** «підвішує» пристрій замість перезапуску;
- кнопка **DFU** неправильно працює з поточною прошивкою Mayhem.

Проблему розв'язує оновлення прошивки CPLD у PortaPack.

!!! danger "Важливо"
    Процедуру перевірено лише на описаній нижче апаратній конфігурації. Не застосовуйте її на інших ревізіях PortaPack, якщо їхню сумісність не перевірено незалежно. Неправильне програмування CPLD може зробити пристрій непрацездатним.

## 1. Вимога до прошивки

Перш ніж почати, переконайтеся, що PortaPack працює на **свіжій прошивці Mayhem** з командами CPLD у послідовній консолі USB. Для цього підключіть пристрій до Mayhem Hub через USB (https://hackrf.app/) і оновіть прошивку до останньої нічної версії.

## 2. Перевірте, що ваша апаратура підходить

Візуально перевірте, що ваш PortaPack — це:

- **PortaPack H2+**;
- **плата версії 3.6**;
- корпус CPLD: **QFP100**.

Потім підключіть PortaPack до **Mayhem Hub** і відкрийте послідовну консоль USB. Виконайте:

```text
cpld_info portapack
```

Перевірені пристрої повідомляли:

```text
CPLD IDCODE: 0x00025610
CPLD Model: AGM AG256SL100
CPLD firmware checksum: 0x17DDE5B1
```

Продовжуйте, лише якщо **ВСЕ** збігається:

**PortaPack H2+ → плата v3.6 → AGM AG256SL100 (QFP100) → початкова контрольна сума CPLD `0x17DDE5B1`**

Якщо хоч щось не збігається, **не використовуйте цю процедуру**.

## 3. Отримайте файл програмування CPLD

Використайте офіційний файл програмування CPLD Mayhem (з офіційного репозиторію Mayhem на GitHub або вашого форку):

```text
hardware/portapack_h4m/CPLD/Supra/portapack_h4m_cpld.prg
```

Ім'я файлу: `portapack_h4m_cpld.prg`

### Перевірте файл на комп'ютері

Перш ніж завантажувати на SD-карту PortaPack, перевірте його SHA256 одним із трьох способів.

1. Linux:
    ```bash
    sha256sum portapack_h4m_cpld.prg
    ```
2. Windows PowerShell:
    ```powershell
    Get-FileHash .\portapack_h4m_cpld.prg -Algorithm SHA256
    ```
3. Windows Bash:
    ```bash
    sha256sum portapack_h4m_cpld.prg
    ```

Очікуваний SHA256:

```text
210c891c0207ea705fce6282c592d91f421c18e306aa91d8bd3af57d41cc0977
```

**Не продовжуйте, якщо SHA256 не збігається точно.**

## 4. Завантажте файл PRG на SD-карту

Через **Mayhem Hub** (друга кнопка зліва) завантажте `portapack_h4m_cpld.prg` у **кореневу теку SD-карти** PortaPack.

Перевірте, що файл є:

```text
ls /
```

Ви маєте побачити `portapack_h4m_cpld.prg`.

### Перевірте завантажений файл (без пошкоджень)

Виконайте в Mayhem Hub:

```text
crc32 /portapack_h4m_cpld.prg
```

Очікуваний CRC32: `0x050D8A24`

**Не продовжуйте, якщо значення не збігається точно.**

## 5. Важливе пояснення щодо контрольних сум

Не плутайте три різні значення:

| Перевірка | Очікуване значення |
|---|---|
| SHA256 файлу PRG | `210c891c0207ea705fce6282c592d91f421c18e306aa91d8bd3af57d41cc0977` |
| CRC32 завантаженого файлу PRG | `0x050D8A24` |
| Контрольна сума CPLD після програмування | `0x20F48814` |

> **УВАГА:** заводську прошивку CPLD з контрольною сумою `0x17DDE5B1` наразі неможливо відновити простим зчитуванням/дампом CPLD.
>
> Не продовжуйте, якщо ревізія плати, модель/IDCODE CPLD, початкова контрольна сума CPLD, SHA256 файлу PRG і CRC32 завантаженого файлу не збігаються точно з наведеними значеннями.

## 6. Запрограмуйте CPLD

Виконайте:

```text
cpld_write portapack eeprom portapack_h4m_cpld.prg
```

Процес має повідомити:

```text
CPLD IDCODE: 0x00025610
CPLD Model: AGM AG256SL100
Reading file...
Magic found: 3397A006
Writing data to CPLD...
New CPLD firmware checksum: 0x20F48814
```

> **УВАГА:** не від'єднуйте живлення USB, не натискайте RESET/DFU, не виймайте SD-карту й не переривайте роботу пристрою під час програмування CPLD.

## 7. Перепідключіть Mayhem Hub і перевірте CPLD

Після завершення програмування **знову підключіть Mayhem Hub** до пристрою, перш ніж вводити інші команди. Потім виконайте:

```text
cpld_info portapack
```

Перевірте:

```text
CPLD IDCODE: 0x00025610
CPLD Model: AGM AG256SL100
CPLD firmware checksum: 0x20F48814
```

Оновлення CPLD завершено.

## 8. Перевірте RESET і DFU

### RESET

Натисніть кнопку RESET. PortaPack має перезапуститися й нормально завантажитися, а не зависнути. Коротка візуальна затримка перед завантаженням — нормально: РК-екран зберігає попереднє зображення, поки мікроконтролер перезапускається; зображення зміниться, коли мікроконтролер знову ініціалізує екран.

### DFU

Перевірте кнопку DFU з поточною прошивкою Mayhem. Процедура DFU має працювати нормально без від'єднання живлення USB.

## Результати

До оновлення CPLD:

```text
CPLD checksum: 0x17DDE5B1
RESET: FAIL
DFU:   FAIL
```

Після оновлення CPLD:

```text
CPLD checksum: 0x20F48814
Magic:         0x3397A006
RESET: PASS
DFU:   PASS
```

Сигнал DFU також перевірено електрично до й після оновлення. До оновлення відпущений сигнал DFU мав неправильний/граничний низький рівень близько **1,1–1,2 В**. Після оновлення виміряно чисті логічні рівні близько **0 В LOW / 3,2 В HIGH**, без аномального постійного струму через R30.

## Перевірка

Процедуру незалежно перевірено на **двох PortaPack H2+ з платою v3.6**, обидва з `AGM AG256SL100 (QFP100)` і початковою контрольною сумою `0x17DDE5B1`. Їх було встановлено на HackRF One **r6** і HackRF One **r9**. Після оновлення обох до контрольної суми `0x20F48814`: RESET працює правильно; DFU працює правильно; загальну функціональність PortaPack перевірено; погіршення функцій чи ВЧ-характеристик не виявлено.
