# Dino Game (динозаврик)

Dino Game — нескінченний біг на кшталт офлайн-гри з динозавриком у браузері. Динозавр біжить сам, а гравець має ухилятися від перешкод — кактусів і птеродактилів. Швидкість поступово зростає. Перед стартом можна вибрати складність.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Керування

- **Select** або **вгору** — стрибок (одне натискання — звичайний стрибок).
- **Вниз** — пригнутися (під низькі перешкоди).
- **Енкодер** — також стрибок.

## Рахунок

Рахунок безперервно зростає, поки динозавр живий. Найкращий результат зберігається між сеансами.
