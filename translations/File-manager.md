# File Manager (файловий менеджер)

![File Manager на пристрої](annotated/app-088.jpg){ width="360" }

*Скріншот з пристрою: [Утиліти](Screens-Other#shot-088).*

Керує файлами на SD-карті.

## Керування

- Енкодер або кнопки вгору/вниз — переміщення між елементами.
- Кнопка select (центральна) — увійти в теку або вибрати елемент для дії.
- Кнопка вправо — вибрати теку для дії (наприклад, перейменувати теку).
- Кнопка вліво або тека «..» — піднятися на рівень вище.
- «-->» — наступна сторінка (зазвичай унизу списку).
- «<--» — попередня сторінка (зазвичай угорі списку).

Маленька стрілка, що блимає праворуч, показує, що нижче є ще елементи. Імена, довші за ширину екрана, автоматично прокручуються горизонтально, коли їх виділено.

## Посторінковий перегляд

Коли елементів забагато, сортування вимикається (не вистачає пам'яті), а вмикається посторінковий перегляд, що дозволяє бачити набагато більше елементів. У рядках кнопок сторінок замість розміру показується номер сторінки, на яку ви перейдете.

## Обробники типів файлів

Вибір деяких файлів відкриває переглядач вмісту. Кнопка вправо відкриває панель інструментів для таких файлів. Вихід із переглядача, відкритого так, повертає в Fileman.

- **BMP-файли** відкриваються в переглядачі заставок, якщо лежать у теці SPLASH (і їх можна зробити заставкою). BMP в інших теках відкриваються в переглядачі BMP.
- **TXT-файли** відкриваються в Notepad. Виняток: TXT у теці WATERFALLS відкривають діалог копіювання схеми водоспаду.
- **PPL, C8, CU8 і C16** відкриваються в Replay у правильному режимі.
- **PNG-файли** відкриваються в переглядачі знімків екрана (лише знімки, зроблені на пристрої). Під час перегляду будь-яка кнопка повертає в Fileman.

## Кнопки

![Панель File Manager](https://github.com/user-attachments/assets/81cb210f-34b6-49bc-8d38-c85892bd681a)

Коли елемент вибрано, на панелі інструментів доступні такі команди:

| № | Кнопка | Дія |
|---|---|---|
| 1 | **Rename** | перейменувати файл чи теку |
| 2 | **Timestamp Rename** | перейменувати, додавши дату |
| 3 | **Cut** | вирізати — додати в буфер для переміщення (через Paste) |
| 4 | **Copy** | копіювати в буфер |
| 5 | **Paste** | перемістити/скопіювати вміст буфера в поточну теку |
| 6 | **New Folder** | створити нову теку в поточній |
| 7 | **New File** | створити порожній файл у поточній теці |
| 8 | **Notepad** | відкрити файл у текстовому редакторі |
| 9 | **Trim** | відкрити файл запису в IQ Trim |
| 10 | **Delete** | видалити файл чи теку |
| 11 | **Clean** | стерти всі файли в теці |
| 12 | **Show Hidden** | показати приховані файли |
| 13 | **Exit** | вийти з файлового менеджера |

!!! tip "Завдання"
    На вашому знімку кнопки — лише значки без підписів. Знімок із вибраним файлом допоможе підписати кожну (див. [З-3.3](tasks)).

## Файли-«партнери»

Файли записів (.C8, .CU8, .C16) мають «партнерський» файл .TXT з метаданими. Перейменування чи видалення одного з пари пропонує виконати ту саму дію з іншим.

## Відомі теки

Повний опис тек — на сторінці [Вміст SD-карти](SD-Card-Content). Окремі уточнення:

- **/ (корінь)** — поточна заставка (`splash.bmp`) і всі теки.
- **FIRMWARE** — рекомендована тека для образів прошивки Mayhem.
- **FREQMAN** — списки частот для Freqman, Scanner, Recon і Looking Glass.
- **SETTINGS** — налаштування застосунків (.ini), `PMEM_FILEFLAG` і `pmem_settings` (лише якщо постійна пам'ять зберігається на SD-карті), `DATE_FILEFLAG` (для псевдодати, коли батарейка розряджена) і `blacklist` (список вимкнених застосунків).
- **SPLASH** — приклади заставок. Щоб вибрати нову заставку, відкрийте BMP у FileMan і натисніть кнопку вправо — файл скопіюється в корінь як новий `splash.bmp` (також має бути ввімкнено «Show Splash» у налаштуваннях).

## Відомі проблеми

- Після певної кількості елементів список не сортується (апаратне обмеження — не вистачає пам'яті).
- Copy & Paste не працює з теками (Cut & Paste з теками тепер працює).
- Щоб видалити теку, вона має бути порожньою (спершу очистіть її кнопкою Clean).
- Cut/Copy/Paste не працює з файлами-«партнерами».

**Порада:** для складнішої роботи з файлами й теками користуйтеся застосунком SD Over USB і комп'ютером.
