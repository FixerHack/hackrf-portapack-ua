# KISS TNC (контролер вузла терміналу)

![KISS TNC на пристрої](annotated/app-087.jpg){ width="360" }

*Скріншот з пристрою: [Трансівери…](Screens-Other#shot-087).*

Застосунок **KISS TNC** перетворює PortaPack на двосторонній KISS TNC (Terminal Node Controller) через послідовний порт USB. Він приймає пакети APRS/AX.25 з радіо й пересилає їх на підключений комп'ютер як кадри KISS, а кадри KISS від комп'ютера передає в ефір як AX.25 через AFSK 1200 бод.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Що таке KISS TNC?

KISS (Keep It Simple, Stupid) — протокол, що дозволяє програмі на комп'ютері надсилати й приймати кадри пакетного радіо AX.25 через TNC по послідовному з'єднанню. Тут PortaPack виконує роль TNC, а послідовний порт USB — зв'язок із комп'ютером. Підійде будь-яке ПЗ APRS чи пакетного радіо з підтримкою послідовного KISS TNC — наприклад, Direwolf (як клієнт), APRSISCE/32, APRSdroid.

## Елементи керування

| Поле | Опис |
|-------|-------------|
| **Frequency** | Частота RX/TX. За замовчуванням 144,390 МГц (у Європі/Україні — 144,800 МГц) |
| **RF Amp** | ВЧ-підсилювач увімк/вимк |
| **LNA** | Підсилення LNA |
| **VGA** | Підсилення VGA |
| **RSSI** | Індикатор сили сигналу |
| **USB** | `Connected` чи `Disconnected` — чи відкрив комп'ютер послідовний порт |
| **RX** | Лічильник пакетів AX.25, прийнятих з радіо й пересланих на комп'ютер |
| **TX** | Лічильник кадрів від комп'ютера, переданих у ефір |
| **Console** | Журнал прийнятих пакетів у вигляді `ДЖЕРЕЛО>ПРИЗНАЧЕННЯ` |

Рядок стану вгорі перемикається між **Listening** (приймання) і **Transmitting** (передавання). На вашому знімку — «Listening», USB «Disconnected».

## Підключення комп'ютера

Підключіть PortaPack до комп'ютера через USB. Послідовний порт USB з'являється як стандартний CDC-пристрій. Відкрийте його в програмі пакетного радіо й налаштуйте як KISS TNC на будь-якій швидкості.

> [!NOTE]
> У Linux пристрій зазвичай `/dev/ttyACM0`, у Windows — COM-порт. У Linux і macOS драйвер не потрібен; Windows може попросити стандартний CDC-драйвер.

## Робота

- **RX:** застосунок постійно слухає на заданій частоті. Коли декодовано дійсний пакет AX.25, він загортається в кадр KISS і надсилається на комп'ютер; лічильник RX збільшується, у консолі з'являються позивні джерела й призначення.
- **TX:** коли комп'ютер надсилає кадр даних KISS, застосунок перемикається на передавання, надсилає кадр AX.25 через AFSK 1200 бод Bell 202, потім повертається в RX.

> [!WARNING]
> Максимальне корисне навантаження кадру — **200 байтів**. Більші кадри мовчки відкидаються.

## Технічні подробиці

| Параметр | Значення |
|-----------|-------|
| Модуляція | AFSK Bell 202 |
| Швидкість | 1200 бод |
| Mark / Space | 1200 Гц / 2200 Гц |
| Частота за замовчуванням | 144,390 МГц |
| Макс. розмір кадру TX | 200 байтів |
| Обрамлення KISS | Стандартне (`0xC0` FEND, `0xDB` FESC) |
