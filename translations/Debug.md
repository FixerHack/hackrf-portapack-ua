# Меню Debug (діагностика)

![Меню Debug на пристрої](annotated/app-093.jpg){ width="320" } ![Меню Debug, сторінка 2](annotated/app-094.jpg){ width="320" }

*Скріншоти з пристрою: [Утиліти та Debug](Screens-Other#shot-093).*

Меню Debug містить апаратну діагностику, інструменти перегляду пам'яті та утиліти розробника. Частина пунктів вбудована, інші — зовнішні застосунки (`.ppma`), що завантажуються з SD-карти й автоматично з'являються в меню Debug, коли SD-карта є.

!!! warning "Обережно"
    Деякі інструменти (Memory Dump, Peripherals) дозволяють **записувати** в пам'ять і регістри. Неправильний запис може спричинити збій або навіть пошкодити апаратуру. Якщо не впевнені — лише переглядайте.

## Audio Test

> [!NOTE]
> Це [зовнішній застосунок](External-apps-informations); потрібен файл `audio_test.ppma` на SD-карті.

Генерує синусоїдальний тон заданої частоти й тривалості для перевірки аудіотракту. Тривалість 0 — безперервний тон. Також можна змінити частоту дискретизації й крок частоти. Перемикач динаміка визначає, чи використовувати вбудований динамік (якщо є).

## Battery

> [!NOTE]
> Показується лише тоді, коли виявлено мікросхему керування акумулятором MAX17055 (лише H4M).

Показує «сирий» вміст регістрів мікросхеми MAX17055: напруга, струм, ємність, рівень заряду та інші параметри — у декодованому вигляді з одиницями. Енкодер гортає сторінки регістрів.

## Buttons Test

![Buttons Test на пристрої](annotated/app-095.jpg){ width="320" }

Показує в реальному часі введення від усіх органів керування: кнопок напрямку, енкодера й сенсорного екрана. Корисно, щоб перевірити, що кнопки спрацьовують правильно, а енкодер крокує чисто, без пропусків і подвійних кроків. Екран також має тест довгого натискання кнопок напрямку й кнопки DFU.

## Debug Dump

> [!NOTE]
> Зовнішній застосунок; потрібен `debug_pmem.ppma` на SD-карті.

Записує файл з діагностичною інформацією (вміст постійної пам'яті, версія прошивки, дані про апаратуру) в теку `DEBUG/` на SD-карті. Корисно для звітів про помилки чи діагностики налаштувань.

## Ext Module

Показує інформацію про підключений модуль розширення PortaPack (PPMod), що працює через I2C: назва модуля, версія прошивки та список застосунків модуля. Якщо модуль не підключено — «No module connected». Оновлюється раз на секунду.

## ExtSensor

> [!NOTE]
> Зовнішній застосунок; потрібен `extsensors.ppma` на SD-карті.

Шукає зовнішні датчики на I2C і показує їхні показання. Підтримує датчики середовища з температурою, вологістю й тиском (наприклад, BME280). Знайдені адреси I2C-пристроїв перелічуються під час запуску.

## Font Viewer

> [!NOTE]
> Зовнішній застосунок; потрібен `font_viewer.ppma` на SD-карті.

Показує вбудовані набори символів шрифтів 5×8 і 8×16, що використовує інтерфейс Mayhem.

## M0 Stack Dump

Записує вміст стека ядра M0 у файл у теці `DEBUG/` на SD-карті. Використовується для діагностики збоїв чи переповнення стека процесора M0.

## Memory Dump

Дозволяє зберегти область пам'яті у файл у теці `DEBUG/` у шістнадцятковому ASCII-форматі. Також дає прямий доступ на читання й запис до певних адрес пам'яті для налагодження.

> [!WARNING]
> Адреси пам'яті мають бути кратними 4, інакше виникне збій. Запис за деякими адресами може пошкодити апаратуру. Будьте обережні.

## Peripherals

Показує «сирий» вміст регістрів радіомікросхем HackRF, які залежать від апаратної ревізії:

| Апаратура | Мікросхеми |
|---|---|
| R1–R8 (OG) | RFFC5072, MAX2837, Si5351C, аудіокодек, SGPIO |
| R9 / R10C | RFFC5072, MAX2839, Si5351A, аудіокодек, SGPIO |
| HackRF Pro | RFFC5072, MAX2831, Si5351A, FPGA iCE40, аудіокодек, SGPIO |

Якщо виявлено мікросхему батареї MAX17055 (H4M), вона також тут. Окремі регістри можна читати чи записувати. Якщо регістрів більше, ніж вміщує екран, обертайте енкодер, коли виділено кнопку Update.

> [!WARNING]
> Запис у деякі регістри може пошкодити апаратуру. Будьте обережні.

!!! tip "Як дізнатися ревізію свого HackRF"
    Починаючи з HackRF One r6, ревізію визначає прошивка, і її показує `hackrf_info`. Плату R9 можна впізнати без розбирання через Peripherals: якщо в списку є **MAX2839** і **Si5351A** — це R9 (або R10C); якщо **MAX2837** і **Si5351C** — R1–R8. Це питання є у [завданнях (З-5.5)](tasks).

## Persistent Memory

Показує 256-байтову область постійної пам'яті (p.mem) як шістнадцятковий дамп, розбитий на сторінки. Енкодер гортає сторінки. Поточне зміщення від початку p.mem показано в лівому стовпці.

Унизу — поточний розмір структури `data_t` і збережена контрольна сума. Контрольна сума обчислюється з перших 252 байтів і зберігається в останніх 4 байтах. Версія конфігурації — перші 4 байти дампу.

## Pro Debug

> Показується лише на HackRF **Pro** (збірка PRALINE). На H1/H2/H4/H4M не з'являється.

Підменю низькорівневої діагностики вхідного ВЧ-тракту й тактування HackRF Pro. Для розробників і налагодження апаратури, а не для щоденного використання.

| Інструмент | Призначення |
|---|---|
| WFM Audio | Налагодження аудіотракту WFM |
| Clocks | Стан тактових доменів Pro |
| MSynth | Налагодження MultiSynth Si5351 |
| Radio Diag | Огляд діагностики радіо |
| Radio Debug | Регістри/налагодження радіо Pro |
| Signal Path | Стан тракту сигналу RX/TX |
| System Diag | Системна діагностика |
| PLL A | Налагодження PLL A Si5351 |
| PLL B | Налагодження PLL B Si5351 |
| GPIO | Стан GPIO |
| RFFC Status | Стан змішувача/синтезатора RFFC5072 |
| RFFC Tuning | Налагодження налаштування RFFC5072 |
| MAX2831 | Регістри трансівера MAX2831 |
| Si5351 | Регістри тактового генератора Si5351 |
| SGPIO Clk | Детектор тактового сигналу SGPIO |
| Baseband | Стан основної смуги |
| SGPIO Live | Живий монітор SGPIO |

## Reboot

Негайно перезавантажує пристрій.

## SD Card

Показує інформацію про вставлену SD-карту й дозволяє перевірити її на цілісність читання/запису.

## Temperature

> [!NOTE]
> Зовнішній застосунок; потрібен `mcu_temperature.ppma` на SD-карті.

Показує поточну температуру з вбудованого цифрового датчика MAX2837 (R1–R8) або MAX2839 (R9/R10C). Точність — приблизно ±4,33 °C на крок.

## Touch Test

Дозволяє малювати на екрані стилусом, щоб перевірити калібрування й точність сенсорного екрана.

Керування:

- **Select** — повернутися в меню Debug;
- **Вліво** — змінити колір пера на випадковий (утримуйте для швидкого перебору);
- **Вниз** — залити екран випадковим кольором;
- **Енкодер** — змінити товщину пера.

Значок знімка екрана працює, але прихований — натисніть точно в його місце на рядку заголовка. Щоб покращити калібрування сенсорного екрана, див. [Settings → Calibration](Settings#calibration).
