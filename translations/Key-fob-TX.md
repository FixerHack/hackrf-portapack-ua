# Key fob TX (брелоки безключового доступу)

![Key fob TX на пристрої](annotated/app-076.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-076).*

!!! danger "Юридичне попередження"
    Передавання сигналів безключового доступу до автомобілів, якими ви не володієте, незаконне в більшості юрисдикцій і може розцінюватися як спроба викрадення чи незаконне втручання в роботу радіопристрою. Використовуйте лише на власному авто для тестування й досліджень.

Key fob TX передає сигнали безключового доступу (RKE) з фіксованим кодом для сумісних автомобільних брелоків. Поки підтримується лише **Subaru**. Кадр — фіксований OOK-сигнал (без плаваючого коду KeeLoq). Передається 4 рази поспіль на 433,920 МГц.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Налаштування

- **Make** — виробник (поки лише **Subaru**).
- **Command** — команда: **Lock**, **Unlock**, **Trunk**.
- **Payload A / Payload B** — «сирі» байти кадру (оновлюються при зміні Make/Command, можна редагувати вручну).
- **Transmit / Stop** — почати/зупинити послідовність із 4 повторів.

Налаштування — у `tx_keyfob.ini`.
