# Знімки екрана

Значок камери в [рядку заголовка](Title-Bar) робить знімок поточного екрана й зберігає його на SD-карту.

!!! tip "Для цієї документації"
    Знімки, зроблені пристроєм, — найкращий матеріал для сайту: вони чіткі й однакового розміру. Див. [завдання З-0](tasks).

## Файли

Знімки зберігаються як 24-бітові PNG у теці `SCREENSHOTS/` на SD-карті:

```
SCREENSHOTS/SCR_0000.PNG
SCREENSHOTS/SCR_0001.PNG
...
```

Лічильник автоматично збільшується від найбільшого наявного номера. Нумерація починається з `SCR_0000.PNG`, коли тека порожня. Можна зберегти до 10 000 знімків (0000–9999); коли лічильник вичерпано, нові знімки не зберігаються.

Розмір екрана — 240×320 пікселів. Розмір файлу залежить від вмісту екрана через стиснення PNG — зазвичай 90–150 КБ.

## Як зробити знімок

**З пристрою:** торкніться значка камери в рядку заголовка. Значок можна приховати в **Settings → User Interface** — якщо його не видно, спершу ввімкніть його там.

**Через послідовну консоль USB:** команда `screenshot` зберігає знімок із тією самою схемою імен:

```
screenshot
```

Як підключитися й користуватися консоллю — див. [USB Serial Console](USB-Serial-Console).

> [!NOTE]
> Тека `SCREENSHOTS/` створюється автоматично під час першого використання, якщо її ще немає.
