# Режим сну

Режим сну вимикає підсвічування екрана й переводить контролер РК-дисплея в режим низького споживання. Пристрій продовжує працювати як звичайно — обробка сигналів, вивід звуку й приймання тривають без перерв. Змінюється лише дисплей.

## Увімкнення режиму сну

**Вручну:** торкніться значка сну (місяць) у [рядку заголовка](Title-Bar). Підсвічування вимкнеться одразу.

**Автоматично:** автовимкнення підсвічування налаштовується в **Settings → User Interface** (параметр «Backlight off after»). Коли ввімкнено, підсвічування гасне після певного часу бездіяльності. Варіанти: 5 с, 15 с, 30 с, 1 хв, 3 хв, 5 хв, 10 хв, 1 год. За замовчуванням вимкнено.

Значок сну можна приховати з рядка заголовка в **Settings → User Interface**.

## Пробудження дисплея

Натисніть будь-яку кнопку або поверніть диск енкодера. Перша дія лише будить дисплей і нічого іншого не запускає. Дотик до сенсорного екрана дисплей **не** будить.

## Що робить і чого не робить режим сну

| | Стан під час сну |
|---|---|
| Підсвічування | **Вимкнено** |
| Контролер РК | **Призупинено** |
| Основна обробка (ядро M4) | **Працює** — обробка сигналів триває |
| Аудіовихід | **Активний** — звук грає далі |
| Приймання / передавання | **Активні** — без змін |

> [!NOTE]
> Режим сну — це лише економія енергії дисплея. Це не режим очікування чи низького споживання для радіочастини. Щоб зупинити роботу радіо, вийдіть із поточного застосунку або вимкніть пристрій.
