# Усунення несправностей

Щось не працює? Почніть із **[FAQ](FAQ)** та таблиці «проблема → розв'язок» **[SolveBoard](SolveBoard)** — вони охоплюють більшість типових проблем. Якщо це не допомогло, виберіть відповідну тему нижче.

## 🔌 Завантаження та живлення
- **[Не завантажується](Won't-boot)** — порожній, білий або чорний екран, або пристрій не запускається
- **[Меню конфігурації](Config-Menu)** — доступ до низькорівневого меню конфігурації / відновлення
- **[Розряджена батарейка (монетна комірка)](Dead-Coin-Cell-Battery)** — годинник і дата постійно скидаються: заміна батарейки RTC
- **[H2+: виправлення кнопок RESET і DFU](H2-PLUS--RESET-and-DFU-push-buttons-fix)** — ремонт кнопок reset / DFU на платах H2+

## 💾 Прошивка та відновлення
- **[Оновлення прошивки](Update-firmware-troubleshooting)** — проблеми під час оновлення прошивки
- **[Діагностика оновлення прошивки у Windows](Diagnose-firmware-update-in-Windows)** — діагностика оновлення у Windows
- **[DFU-накладення](DFU-overlay)** — відновлення пристрою через DFU-накладення
- **[Заводські налаштування](Factory-Defaults)** — відновлення типових налаштувань
- **[Повне скидання](Full-reset)** — повернення до чистого стану
