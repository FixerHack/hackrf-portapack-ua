# Утиліти (Utilities)

Розділ **Utilities** містить інструменти й допоміжні застосунки. Застосунки, позначені ⬡, — зовнішні: зберігаються як файли `.ppma` на SD-карті й мають збігатися з версією поточної прошивки.

Скріншоти всіх утиліт з вашого пристрою — на сторінці [Трансівери, Recon, Capture, Replay та утиліти](Screens-Other).

| Застосунок | Опис |
|---|---|
| [Antenna Length](Antennas) ⬡ | Розраховує довжину антени для поширених типів антен |
| [Calculator](Calculator) ⬡ | Науковий калькулятор зі зворотною польською нотацією (RPN) |
| [Cart Lock](Cart-Lock) ⬡ | Передавач блокування візків у магазинах (через аудіовихід) |
| [Debug](Debug) | Апаратні й програмні засоби діагностики |
| [File Manager](File-manager) | Перегляд, копіювання, переміщення, перейменування й видалення файлів на SD-карті |
| [Flash Utility](Flash-Utility) | Запис прошивки з SD-карти |
| [Freq. Manager](Freq-manager) | Керування збереженими списками частот (файли freqman) |
| [IQ Trim](IQ-trim) | Обрізання «тиші» на початку й наприкінці файлів запису |
| [Metronome](Metronome) ⬡ | Звуковий метроном із регульованим темпом |
| [Notepad](Notepad) | Простий текстовий редактор для файлів на SD-карті |
| [Playlist Editor](Playlist-Editor) ⬡ | Створення й редагування плейлистів `.PPL` для Replay |
| [Rand Pwd](Random-password) ⬡ | Генератор випадкових паролів |
| [SD Over USB](SD-Over-USB) ⬡ | Робить SD-карту USB-накопичувачем для комп'ютера |
| [Stopwatch](Stopwatch) ⬡ | Секундомір |
| [Tuner](Tuner) ⬡ | Камертон для налаштування музичних інструментів |
| [WardriveMap](WardriveMap) ⬡ | Показує на карті записи з GPS-координатами |
| [Waterfall Designer](Waterfall-Designer) ⬡ | Налаштування кольорової схеми водоспаду |
| [WAV Viewer](Wav-viewer) ⬡ | Відтворення й перегляд WAV-файлів з SD-карти |
| [Wipe SD Card](Wipe-SD-Card) ⬡ | Стирання (форматування) SD-карти |
