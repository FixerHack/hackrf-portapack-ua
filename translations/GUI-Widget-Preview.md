# Попередній перегляд віджетів GUI

## Вступ

Цим інструментом можна легко переглядати віджети без компіляції. Фреймворк здебільшого готовий, бракує лише кількох віджетів. Якщо ви готові реалізувати відсутні — ласкаво просимо.

## Синтаксис

```
widget_preview.py path/to/myfile_containing_widgets_declaration.hpp
```
