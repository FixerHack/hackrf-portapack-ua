# Time Sink (осцилограф)

![Time Sink на пристрої](annotated/app-030.jpg){ width="360" }

*Скріншот з пристрою: [Приймачі: огляд застосунків](Screens-Receivers#shot-030).*

Time Sink — переглядач форми сигналу в часовій області, «осцилограф для радіо». Він малює компоненту I (синфазну) потоку IQ як графік «амплітуда — час» по екрану. Застосунки на кшталт [Looking Glass](Looking-Glass) показують частотну область (спектр), а Time Sink — часову (форму сигналу в часі).

Аналог у GNU Radio — блок-джерело **Time Sink**.

## Відображення

Область форми сигналу займає нижню частину екрана (під заголовком з трьох рядків). Кожен горизонтальний піксель відповідає одній із **240 точок даних**, узятих із прийнятого буфера основної смуги. Вертикальна вісь — амплітуда, центральна лінія — нуль. Показується лише компонента I (дійсна).

## Налаштування

### Рядок 0 — частота й підсилення

- **Frequency** — за замовчуванням 433,920 МГц. Використовуйте енкодер або торкніться, щоб відкрити клавіатуру.
- **Frequency step** — крок налаштування енкодером.
- **RF Amp** (0 або 1) — вмикає/вимикає внутрішній ВЧ-підсилювач.
- **LNA gain** (0–40) — підсилення малошумного підсилювача. Див. [Проблеми з якістю приймання](Help!-Im-not-receiving-anything!---Receive-Quality-Issues#gain-settings).
- **VGA gain** (0–62) — підсилення підсилювача основної смуги.

### Рядок 1 — частота дискретизації й децимація

- **SR (Sample Rate)** — частота дискретизації основної смуги. Варіанти: **1,0 МГц, 2,0 МГц, 5,0 МГц, 10,0 МГц, 20,0 МГц**. За замовчуванням 2,0 МГц. Вищі частоти фіксують швидші фронти сигналу; нижчі дають повільнішу, більш «збільшену» часову розгортку.
- **DEC (Decimation)** — діапазон 0–128. Керує тим, скільки буферів основної смуги пропускається між оновленнями екрана. Кожен буфер — близько 2048 відліків. За DEC=0 екран оновлюється з кожним буфером; за DEC=128 — з кожним 129-м. Збільште DEC, щоб уповільнити оновлення трас для повільних чи періодичних сигналів.

### Рядок 2 — післясвічення й тригер

- **PST (Persistence)** — кількість попередніх кадрів форми сигналу, що одночасно лишаються видимими на екрані. Варіанти: **1, 2, 4, 8, 16**. За PST=1 показується лише поточна траса; вищі значення накладають кілька недавніх трас, як режим післясвічення цифрового осцилографа. Максимум 16 кадрів через обмеження пам'яті у форматі зовнішніх застосунків.
- **TRM (Trigger Mode)** — керує синхронізацією форми сигналу:
    - `Off` — вільний біг, без синхронізації;
    - `Rise` — запуск за зростальним фронтом, що перетинає рівень тригера;
    - `Fall` — запуск за спадним фронтом, що перетинає рівень тригера.

    При спрацюванні тригера застосунок знаходить точку перетину в кожному кадрі й вирівнює зображення за цією позицією, стабілізуючи форму сигналу. Застосовується гістерезис ±2, щоб запобігти хибним спрацюванням. Тригер фіксується на найближчому до попереднього перетині для стабільності від кадру до кадру.
- **LVL (Trigger Level)** — діапазон від −127 до +127. Встановлює поріг амплітуди для виявлення тригера відносно середини сигналу (0 — центр). Не впливає, коли TRM встановлено на Off.

## Збереження налаштувань

Усі налаштування (частота дискретизації, DEC, післясвічення, режим і рівень тригера) зберігаються в `rx_time_sink.ini` на SD-карті, якщо в глобальному меню [Settings](Settings#app-settings) увімкнено **App Settings**.
