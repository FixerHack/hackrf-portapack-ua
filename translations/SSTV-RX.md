# SSTV RX (телебачення з повільним скануванням)

![SSTV RX на пристрої](annotated/app-035.jpg){ width="360" }

*Скріншот з пристрою: [Приймачі: огляд застосунків](Screens-Receivers#shot-035).*

Приймає й декодує передачі SSTV (телебачення з повільним скануванням), показуючи зображення в реальному часі й зберігаючи його у BMP на SD-карті.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Налаштування

- **Frequency** — частота приймання. Змінюється енкодером або клавіатурою.
- **RF Amp** (0 або 1) — внутрішній ВЧ-підсилювач.
- **LNA gain** (0–40) і **VGA gain** (0–62) — див. [Проблеми з якістю приймання](Help!-Im-not-receiving-anything!---Receive-Quality-Issues#gain-settings).
- **Volume** — гучність.
- **Mode** — режим SSTV. За замовчуванням **Scottie 2**. Підтримується шість режимів:

| Режим | Код VIS | Пікселів | Рядків | мс/піксель |
|------|----------|--------|-------|----------|
| Scottie 1 | 60 | 320 | 256 | 0.432 |
| Scottie 2 | 56 | 320 | 256 | 0.275 |
| Scottie DX | 76 | 320 | 256 | 1.080 |
| Martin 1 | 44 | 320 | 256 | 0.458 |
| Martin 2 | 40 | 320 | 256 | 0.229 |
| SC2-180 | 55 | 320 | 256 | 0.734 |

- **Ph** (Phase, −50…+50) — горизонтальний зсув пікселів для вирівнювання початку рядка. Застосовується одразу; між сеансами не зберігається.
- **Slnt** (Slant, −100…+100) — корекція дрейфу таймінгу кроками 0,1 %. Застосовується одразу; між сеансами не зберігається.

## Поле Calib

Під вибором режиму поле **Calib** показує стан виявлення синхронізації під час прийому — лічильник синхронізації та пропоновані корекції фази/нахилу.

## Відображення зображення

Прийняте зображення малюється рядок за рядком у реальному часі, масштабоване до доступної області. Внутрішня роздільність — завжди 320 × 256.

## Start / Stop

**Start RX** починає прийом (кнопка стає **Stop RX**). Щоразу при Start RX на SD-карті створюється новий BMP з міткою часу. Stop RX (або закриття застосунку) завершує файл.

Зображення зберігаються в `SSTV/RX/SSTV_YYYYMMDD_HHMMSS.BMP`.

## Про модуляцію

Застосунок декодує лише SSTV з **FM-модуляцією**. SSB-SSTV (USB/LSB), типовий на КХ-радіоаматорстві, не підтримується. FM-SSTV використовується на VHF/UHF (наприклад, 144,500 МГц у Європі) та через деякі супутники.
