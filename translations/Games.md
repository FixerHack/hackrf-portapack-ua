# Ігри (Games)

![Меню Games на пристрої](annotated/app-014.jpg){ width="320" }

Mayhem містить кілька ігор і візуальних демонстрацій, у які можна грати прямо на PortaPack без жодної радіоактивності (крім Battleship).

| Гра | Опис |
|-----|-------------|
| [2048](2048) | Головоломка з плитками: з'єднуйте однакові, щоб отримати 2048 |
| [Battleship](Battleship) | Морський бій для двох гравців по радіо між двома PortaPack (через POCSAG2) |
| [Blackjack](Blackjack) | Класична карткова гра проти автоматичного дилера |
| [Breakout](Breakout) | Класичний арканоїд — розбивайте цеглинки м'ячиком |
| [Digital Rain](Digital-Rain) | Заставка «цифровий дощ» у стилі «Матриці» — без керування, «назад» для виходу |
| [Dino Game](Dino-Game) | Нескінченний біг — стрибайте й пригинайтеся, щоб оминати перешкоди |
| [Doom](Doom) | Порт класичного шутера від першої особи |
| [Morse P](Morse-P) | Тренажер передавання азбуки Морзе з автоматичним розпізнаванням точок і тире |
| [Pac-Man](Pac‐Man) | Класична аркада-лабіринт |
| [Snake](Snake) | Класична «змійка» |
| [Space Invaders](Space-Invaders) | Класична аркада-стрілялка, режими Easy/Hard |
| [Tetris](Tetris) | Класичний «тетріс» |

!!! tip "Як вийти з гри"
    Більшість ігор RocketGod (Breakout, Snake, Tetris, Doom) не мають видимої кнопки «назад». Натисніть **одночасно ВЛІВО і ВГОРУ** — фокус перейде на приховану кнопку виходу у правому верхньому куті — і натисніть **Select**. Або торкніться лівого верхнього кута екрана.

Скріншоти окремих ігор ще не зроблено — див. [завдання З-3.1](tasks).
