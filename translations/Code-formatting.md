# Форматування коду

Ми використовуємо clang-format версії 18. Уся конфігурація — у файлі `.clang-format`.

## Форматування всього проєкту

Для всіх платформ надано готові бінарні файли clang-format 18. Щоб відформатувати весь проєкт, запустіть відповідний скрипт із кореня репозиторію:

**Linux/Mac:**

```bash
./format-code.sh
```

**Windows (PowerShell):**

```powershell
.\format-code.ps1
```

> ⚠️ **Перед пушем** завжди запускайте цей скрипт. clang-format, інтегрований в IDE (VS Code, CLion тощо), може давати інший результат навіть за тієї ж версії й того ж `.clang-format`, що спричинить збій перевірки форматування на GitHub.

## VS Code

Переконайтеся, що встановлено розширення C/C++ від Microsoft — воно автоматично підхопить файл `.clang-format`. Можна використовувати автовідступ IDE під час розробки, але **не покладайтеся на нього замість скрипта перед комітом**.

## CLion

У CLion вбудований clang-format: натисніть Ctrl + Shift + L (Windows і Linux) для автовідступу з файлом `.clang-format`. Але **не замінюйте ним скрипт перед комітом**. (У KDE типова комбінація — Alt + Shift + L.)

## Для мейнтейнерів: керування бінарними файлами clang-format

Готові бінарні файли зберігаються в `tools/clang-format-bin/<версія>/` з підтекою на кожну платформу (linux-x86_64, linux-arm64, macos-arm64, windows-x86_64). Кореневі скрипти `format-code.sh` і `format-code.ps1` делегують до `tools/clang-format.sh` і `tools/clang-format.ps1`, які автоматично вибирають правильний бінарник.

### Оновлення версії clang-format

1. Відредагуйте `tools/fetch-clang-format.sh` і оновіть номер версії.
2. Запустіть скрипт — він завантажить бінарники й створить відповідні теки з версіями. (Завантаження із серверів LLVM може тривати довго.)
3. Перевірте кожен бінарник. Деяким платформам потрібні додаткові бібліотеки (наприклад, `libtinfo.so.5` для Linux) — покладіть її в підтеку `lib/`.
4. Відредагуйте `tools/clang-format.sh` і `tools/clang-format.ps1`, встановивши нову версію.

> Кілька версій можуть співіснувати в `tools/clang-format-bin/`. Активна — та, що задана в `tools/clang-format.sh` і `.ps1`.
