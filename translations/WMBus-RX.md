# WMBus RX (бездротові лічильники wM-Bus)

![WMBus RX на пристрої — екран приймача](annotated/ui-receiver-list-subghzd.jpg){ width="320" }

*Окремого скріншота WMBus RX у вашому архіві немає (див. [завдання](tasks)).*

Приймає й декодує телеметрію **Wireless M-Bus** (wM-Bus) від комунальних лічильників — води, газу, тепла й електроенергії, що передають по радіо в діапазоні 868 МГц.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Огляд

Wireless M-Bus (EN 13757) — європейський стандарт, за яким розумні лічильники передають дані споживання й стану. Застосунок приймає пакети, перевіряє кожен контрольною сумою wM-Bus і декодує ідентифікатор лічильника та (для незашифрованих кадрів) значення.

Виберіть **режим** під лічильник, налаштуйтеся на відповідну частоту — прийняті пакети з'являться в консолі.

| Режим | Частота | Примітки |
|---|---|---|
| **T-Mode** | 868,95 МГц | кодування 3-of-6 (за замовчуванням) |
| **C-Mode** | 868,95 МГц | компактний режим |
| **S-Mode** | 868,3 МГц | повільніший, стаціонарний режим |

> Застосунок не перестроюється автоматично — встановіть поле частоти відповідно до вибраного режиму.

## Елементи керування

| Елемент | Опис |
|---|---|
| **Mode** | Режим wM-Bus: T / C / S. |
| **Frequency** | Частота режиму (крок 10 кГц). |
| **RF Amp** | ВЧ-підсилювач: `0` — вимкнено, `1` — увімкнено (+14 дБ). |
| **LNA** | Підсилення ПЧ (0–40 дБ). Див. [Проблеми з якістю приймання](Help!-Im-not-receiving-anything!---Receive-Quality-Issues#gain-settings). |
| **VGA** | Підсилення основної смуги (0–62 дБ). |
| RSSI / Channel | Індикатори сили сигналу й потужності каналу. |
| **Last Err** | Причина відхилення останнього кадру (помилка CRC, довжини, кодування…) або `None`. |

## Декодовані поля

| Поле | Значення |
|---|---|
| **Mfr** | Виробник — 3-літерний код із заголовка лічильника |
| **ID** | Серійний номер лічильника (hex) |
| **Ver** | Байт версії пристрою |
| **Type** | Тип пристрою / середовища — вода, холодна/гаряча вода, газ, електроенергія, тепло, розподільник тепла, димовий датчик |
| **CI / Enc** | Байт керувальної інформації й стан шифрування: `None`, `AES-128`, `DES` або `Mode n` |
| **V:** | До трьох декодованих значень (лише для незашифрованих кадрів) |
| **Hex** | «Сирий» шістнадцятковий дамп кадру |

Зашифровані кадри (AES-128 / DES) розпізнаються, але їхні значення без ключа не читаються.

## Протокол

Wireless M-Bus (EN 13757-4) працює в діапазоні 868 МГц з FSK. T-Mode використовує кодування 3-of-6, C-Mode — новіший компактний, S-Mode — повільніший стаціонарний. Кожен кадр перевіряється CRC wM-Bus (поліном `0x3D65`).
