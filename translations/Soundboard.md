# Soundboard (передавання WAV як FM)

![Soundboard на пристрої](annotated/app-064.jpg){ width="360" }

*Скріншот з пристрою: [Передавачі: огляд застосунків](Screens-Transmitters#shot-064).*

Soundboard передає файли `.WAV` з SD-карти як FM-аудіо. Виберіть файл і натисніть START або ввімкніть Random для випадкового порядку.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

!!! danger "Передавання регулюється законом"
    Цей застосунок **передає** радіосигнали. Передавання без дозволу в більшості випадків незаконне. Використовуйте лише дозволені частоти й потужність, власне обладнання або екрановане середовище. Див. [Призначення та законність](Intended-Use-and-Legality).

## Список файлів

WAV-файли завантажуються з теки `WAV/` на SD-карті (до 50 на сторінку; кнопки `<=` / `=>`). Файли мають бути моно, 8 біт без знака або 16 біт зі знаком PCM. Частота дискретизації читається із заголовка WAV — надійно працюють файли 24000–48000 Гц. Стерео й інші формати мовчки пропускаються.

## Елементи керування

- **Loop** — повторювати вибраний файл.
- **Random** — щоразу при START грати випадковий файл.
- **Key** — субзвуковий тон на несучій: стандартні тони CTCSS або пілот-тони бездротових мікрофонів (Shure 19 кГц, Axient 28 кГц, Sennheiser 32/32,768 кГц, Sony 32,382 кГц). **None** — вимкнено.
- **Vol** — гучність (недоступна, показується `--`, коли активний тон Key).
- **START / STOP** — почати/зупинити.

## Підготовка WAV

Моно, 8 біт без знака або 16 біт зі знаком PCM, 24000–48000 Гц. Приклади — 48000 Гц / 8 біт. Швидка конвертація через `sox`:

```
for f in ./*.wav; do sox "$f" -r 48000 -c 1 -b 8 --norm "conv/$f"; done
```

Налаштування — у `tx_soundboard.ini`.
