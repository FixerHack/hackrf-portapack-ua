# Playlist Editor (редактор плейлистів)

![Playlist Editor на пристрої](annotated/app-099.jpg){ width="360" }

*Скріншот з пристрою: [Утиліти](Screens-Other#shot-099).*

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

## Вступ

Застосунок створює й змінює плейлисти (файли `.PPL`) для [Replay](Replay).

## Як користуватися

1. Відкрийте наявний плейлист (**Open PPL**) або створіть новий з нуля (поле **PPL file: New**).
2. Редагуйте записи (**Edit Item**) та/або вставляйте нові (**Ins. After** — вставити після поточного).
3. Збережіть плейлист (**Save PPL**).

## Поля редагування/вставлення

- **Delay** — затримка перед записом; регулюється енкодером.
- **Browse** — вибрати файл запису для відтворення.
- **Input Delay** — задати власну затримку з клавіатури замість енкодера.
