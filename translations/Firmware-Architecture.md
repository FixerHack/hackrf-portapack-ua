# Архітектура прошивки

Двоядерний мікроконтролер LPC4320 у HackRF One має обмежені ресурси для програмно-визначеного радіо: усього 200 КБ RAM і 1 МБ SPI-флешу.

## Розподіл праці

У LPC4320 два ядра:

- **Cortex-M4F** — виконує baseband-обробку сигналу.
- **Cortex-M0** — виконує всі завдання інтерфейсу користувача та просту постобробку сигналів/пакетів.

Прошивка Cortex-M4F має три потоки ChibiOS (за спаданням пріоритету):

- **Baseband** — отримує буфери baseband-семплів і обробляє їх для відновлення аудіо, пакетів тощо.
- **RSSI** — отримує буфери семплів RSSI (індикація рівня прийнятого сигналу) і обчислює метрики для відображення. У майбутньому може використовуватися для запуску захоплень і AGC приймача.
- **Default** — потік усередині main(), що отримує події від інших потоків і повідомлення від ядра M0 (UI).

Прошивка Cortex-M0 має лише один потік — default, який чекає на події від переривань і на повідомлення від ядра M4 (baseband).

## Карта пам'яті

Абсолютні адреси на LPC4320:

```
0x1000_0000 0x1001_8000 96k Локальний SRAM
0x1008_0000 0x1008_8000 32k Локальний SRAM
0x1008_8000 0x1008_a000  8k Локальний SRAM
0x1400_0000 0x1410_0000  1M SPIFI-флеш (кешований доступ)
0x2000_0000 0x2000_c000     AHB SRAM
0x8000_0000 0x8010_0000  1M SPIFI-флеш (прямий доступ)
0xe000_0000             Приватна шина ядра ARM (окрема для M4 і M0)
```

Як використовуються області в коді PortaPack:

```
0x1000_0000 96k Локальний SRAM для RAM M4 (стек, купа, дані)
0x1008_0000 32k Локальний SRAM для коду M4 (секція text)
0x1008_8000  8k Локальний SRAM для зв'язку M4/M0
0x1400_0000  1M SPIFI-флеш для bootstrap M4, коду M0, оверлеїв коду M4
0x2000_0000 64k AHB SRAM для RAM M0 (стек, купа, дані)
```

## Філософія

Код M4 виконується з локального SRAM заради швидкодії. DSP-код — це щільні цикли, йому не потрібно багато місця, тож для нього вистачає меншого блоку SRAM.

Дані M4 тримають в окремому блоці RAM для максимальної швидкодії: M4 може одночасно діставати інструкції й дані з різних блоків через окремі шини I-code і D-code. Більший блок SRAM — для baseband-даних, коефіцієнтів фільтрів і проміжних даних.

Код M0 виконується переважно з флешу, бо UI й некритичний код значно більші за DSP-код M4 — виграш у місці переважує втрату швидкодії. Інтерфейс SPIFI розігнано до максимуму (100 МГц SCK, quad-SPI, кешований доступ), що дає ~400 Мбіт/с.

Дані M0 — в області AHB RAM, щоб не конкурувати з кодом і даними M4.

Є невелика область SRAM на живленні VBAT (0x40041000, 256 байтів) для збереження стану системи при вимкненні живлення.

Дані RAM M4 і M0 доступні через пряму адресацію — це дає змогу передавати вказівники між M4 і M0.
