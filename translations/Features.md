# Можливості та характеристики

## Апаратна частина HackRF

HackRF — це плата SDR, до якої підключається PortaPack. Mayhem підтримує кілька версій.

### HackRF One (R1–R9)

HackRF One — оригінальна плата, створена Майклом Оссманном у Great Scott Gadgets. Вона випускалася в кількох апаратних ревізіях (R1–R9), усі повністю підтримуються Mayhem.

| Характеристика | Значення |
|---|---|
| Трансівер | Напівдуплексний |
| Робоча частота | від 1 МГц до 6 ГГц |
| Частоти дискретизації | 2–20 Мвибірок/с (квадратурні) |
| Розрядність | 8 біт |
| Макс. потужність RX | −5 дБм (перевищення загрожує незворотним пошкодженням; до 10 дБм безпечно з вимкненим RX-підсилювачем) |
| USB | High-Speed USB 2.0, Type-A або Micro-B |

#### Макс. потужність TX (HackRF One)

| Діапазон частот | Приблизна потужність TX |
|---|---|
| 10 – 2150 МГц | 5–15 дБм (зростає зі зниженням частоти) |
| 2150 – 2750 МГц | 13–15 дБм |
| 2750 – 4000 МГц | 0–5 дБм (зростає зі зниженням частоти) |
| 4000 – 6000 МГц | −10…0 дБм (зростає зі зниженням частоти) |

Виміряні значення: [емпіричне вимірювання потужності TX](https://www.reddit.com/r/hackrf/comments/hi8275/measurement_of_the_hackrf_one_output_power/).

#### CLKout / CLKin (HackRF One)

| Ревізія обладнання | Поведінка |
|---|---|
| R1–R8 (OG, Si5351C) | Налаштовується користувачем 4 кГц–60 МГц у Settings → Radio |
| R9 (Si5351A) | Фіксовані 10 МГц, лише програмне вмикання/вимикання |

Рівень сигналу: від 0 до 3 В на високоомне навантаження (меандр).

---

### HackRF One R10C

R10C — варіант HackRF One виробництва OpenSourceSDRLab, який продається в комплекті з PortaPack H4M. Використовує той самий чипсет і архітектуру, що й R9 (тактовий генератор Si5351A), і трактується прошивкою Mayhem ідентично. Єдина апаратна відмінність від R9 — роз'єм **USB-C** замість Micro-B.

| Характеристика | Значення |
|---|---|
| Основа | HackRF One R9 |
| USB | High-Speed USB 2.0, **Type-C** |
| CLKout | Фіксовані 10 МГц (як у R9) |
| Сумісність із прошивкою | Повна підтримка Mayhem (визначається як R9) |

> [!NOTE]
> Попри «R10» у назві, R10C не пов'язаний із HackRF Pro. Це HackRF One з роз'ємом USB-C виробництва третьої сторони.

---

### HackRF Pro

HackRF Pro було анонсовано Great Scott Gadgets 26 червня 2025 року. Це значне вдосконалення HackRF One зі збереженням зворотної сумісності. Mayhem підтримує його через збірку PRALINE.

| Характеристика | Значення |
|---|---|
| Трансівер | Напівдуплексний |
| Робоча частота | від 100 кГц до 6 ГГц |
| Діапазон налаштування | від 0 Гц до 7,1 ГГц |
| Частоти дискретизації | До 20 Мвибірок/с (стандартно); до 40 Мвибірок/с (4-бітова половинна точність) |
| Розрядність | 8 біт стандартно; 16-бітова розширена точність на низьких частотах дискретизації (типовий ENOB 9–11); 4 біти половинної точності |
| Опорний тактовий сигнал | Вбудований TCXO (без залежності від GP_CLKIN) |
| Логіка | FPGA iCE40 (замінює CPLD HackRF One) |
| USB | High-Speed USB 2.0, Type-C |

#### CLKout / CLKin (HackRF Pro)

Налаштовується користувачем 4 кГц–60 МГц у Settings → Radio (той самий діапазон, що й у HackRF One R1–R8).

## Апаратна частина PortaPack

PortaPack — це плата розширення, що підключається до HackRF і надає автономний інтерфейс користувача. Існує кілька версій. Повне порівняння дивіться в розділі [Версії PortaPack](PortaPack-Versions).

| Функція | Деталі |
|---|---|
| Дисплей | Кольоровий РК-дисплей 320 × 240 пікс. (ILI9341), 2,4″ (H1) або 3,2″ (H2/H4M) |
| Сенсорний екран | Резистивний, поріг налаштовується |
| Керування | Диск енкодера + 5 кнопок напрямку (вгору/вниз/вліво/вправо/select) |
| Накопичувач | Слот microSD (FAT32) |
| Аудіовихід | Роз'єм 3,5 мм для навушників/динаміка |
| Мікрофон | Вбудований (лише H2M, H4M) |
| Мікросхема керування акумулятором | Так (лише H4M) |
| Порт GPIO | Роз'єм розширення (лише H4M) |
| GPS | Підтримується зовнішній GPS-модуль (NMEA через UART) |

## Прошивка Mayhem

Mayhem — це прошивка спільноти для HackRF + PortaPack, яка значно розширює можливості прошивки Havoc, від якої її відгалужено.

### Категорії застосунків

| Категорія | Опис |
|---|---|
| [Приймачі](Receivers) | Декодування та відображення сигналів: ADS-B, AIS, APRS, POCSAG, ACARS, EPIRB та багато інших |
| [Передавачі](Transmitters) | Передавання широкого спектра сигналів і протоколів |
| [Трансівери](Transceivers) | Повноцінні застосунки приймання/передавання: мікрофон, KISS TNC |
| [Recon](Recon) | Сканер частот і мисливець за сигналами |
| [Capture](Capture) | Запис даних IQ на microSD у форматі .C16 або .C8 |
| [Replay](Replay) | Відтворення записаних файлів IQ |
| [Remote](Remote) | Віддалене керування через USB |
| [Looking Glass](Looking-Glass) | Широкосмуговий огляд спектра |
| [Утиліти](Utilities) | Інструменти: калькулятор антен, файловий менеджер, IQ trim, блокнот та інше |
| [Налаштування](Settings) | Конфігурація пристрою, параметри радіо, дисплей, теми |
| [Ігри](Games) | Вбудовані ігри: Tetris, Doom, Pac-Man та інші |
| [Debug](Debug) | Апаратна діагностика та інструменти розробника |
| [Зовнішні застосунки](External-apps-informations) | Завантажувані застосунки .ppma з SD-карти |

### Ключові можливості прошивки

- **Зовнішні застосунки**: завантаження додаткових застосунків з SD-карти без перепрошивання.
- **Знімки екрана**: збереження зображення дисплея у файл PNG на SD-карті.
- **Прихований режим (Stealth)**: вимкнення підсвічування під час TX.
- **Режим сну**: вимкнення дисплея за збереження роботи радіо.
- **Власна заставка**: завантаження користувацького BMP-зображення під час завантаження.
- **Теми**: кілька кольорових тем інтерфейсу.
- **Інтеграція GPS**: застосунки можуть використовувати дані про позицію від підключеного GPS-модуля.
- **Збереження налаштувань застосунків**: параметри кожного застосунку зберігаються на SD-карті.
- **Менеджер частот**: збереження та виклик іменованих частот.
- **Редактор списків відтворення**: послідовне відтворення кількох записів.

### Примітки

- Напівдуплекс означає, що пристрій може передавати або приймати, але не одночасно.
- Робочий діапазон частот (1 МГц–6 ГГц для HackRF One) охоплює більшість поширених радіослужб. Детальний розподіл дивіться у [Вікіпедії: розподіл частот](https://uk.wikipedia.org/wiki/Розподіл_радіочастот).
- Перш ніж передавати, завжди прочитайте [Призначення та законність використання](Intended-Use-and-Legality) і ознайомтеся з місцевими правилами.
