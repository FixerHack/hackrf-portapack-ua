# Процес pull request

## Створення PR

Перш ніж створити PR, зробіть форк репозиторію Mayhem-Firmware у свій акаунт GitHub. Відкрийте репозиторій, натисніть `fork` → `create new fork`.

Завантажте свій форк: `git clone https://github.com/<ваш_юзернейм>/mayhem-firmware/ --recursive`.

Працюйте з клонованим форком як зазвичай: додавайте/комітьте зміни з осмисленими описами. Після змін відкрийте свій форк у браузері. Якщо ви синхронізували зміни, угорі з'явиться `This branch is [N commits ahead of] portapack-mayhem/mayhem-firmware:next`. Натисніть `[N commits ahead of]` і зелену кнопку `Create Pull Request`. Далі дотримуйтесь інструкцій і дайте осмислений опис.

### Варіант для досвідчених

Процес вище спрощено. Зазвичай він добре працює для дрібних змін. Але для чіткості краще робити зміни в новій гілці, а не в типовій `next`:

1. Зробіть форк, клонуйте, налаштуйте підмодулі.
2. У локальному репозиторії:
    ```
    git checkout next
    git pull
    git checkout -b branch_name
    ```
3. Зробіть зміни й протестуйте.
4. Коли готові до PR:
    ```
    git add -A
    git commit -m "що ви змінили"
    git push -u origin branch_name
    ```
5. Зробіть PR на сайті GitHub.

> [!NOTE]
> Питання: що, якщо я вже зробив зміну в гілці next, а тепер хочу «досвідчений» спосіб?
> Відповідь: зробіть cherry-pick ваших комітів із next у нову гілку, потім запуште нову гілку, а після цього скиньте або синхронізуйте next на сайті GitHub.

## Процес злиття

Щоб ваш PR злили:

- щонайменше один затверджувач коду має схвалити ваш код;
- якщо рецензенти залишили коментарі, усі вони мають бути позначені як вирішені;
- усі 3 перевірки форматування коду мають пройти успішно (не знаєте, як форматувати? див. [Форматування коду](Code-formatting)).

Коли все зроблено, затверджені учасники побачать зелену кнопку злиття. Решта побачать, що тести пройшли, і мають попросити затвердженого учасника злити код.

### Юзернейми в журналі змін nightly

Нова збірка `next` виходить щоночі. Ваш внесок додається до списку змін того дня. Щоб ваш акаунт відображався правильно, увімкніть «Keep my email addresses private» — тоді ваш юзернейм буде взято з приватної no-reply-адреси.
