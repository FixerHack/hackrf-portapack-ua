# Повне скидання

Повне скидання заново записує і прошивку HackRF, і прошивку Mayhem з нуля та перевстановлює весь вміст SD-карти. Використовуйте це як останній засіб, коли інші кроки не допомогли.

> [!WARNING]
> Цей процес видаляє всі налаштування й вміст SD-карти. Спершу збережіть важливі файли.

## Кроки

1. Скопіюйте важливі файли з SD-карти на комп'ютер.
2. Завантажте останній реліз зі [сторінки релізів](https://github.com/portapack-mayhem/mayhem-firmware/releases). Файл `mayhem_vX.X.X.ppfw.tar` містить і прошивку, і весь вміст SD-карти в одному архіві.
3. Вийміть із PortaPack SD-карту й батарейку-таблетку. Покладіть їх у безпечне місце так, щоб вони не торкалися одна одної.
4. Переведіть HackRF у режим DFU. Пробуйте способи по черзі, доки один не спрацює — світлодіоди мають засвітитися, а екран залишиться порожнім:
    - утримуйте одночасно RESET і DFU, спершу відпустіть RESET, потім DFU;
    - утримуйте DFU, підключіть USB-кабель, відпустіть DFU;
    - утримуйте DFU, увімкніть пристрій (натисніть енкодер на H1/H2 або вимикач на H4M), відпустіть DFU, потім підключіть USB;
    - підключіть USB, утримуйте DFU і від'єднайте USB, відпустіть DFU, підключіть USB знову.
5. Запишіть базову прошивку HackRF через DFU:
    - **Windows:** двічі клацніть `mayhem_flasher.bat` з пакета релізу й дотримуйтесь підказок. Після цього не від'єднуйте й не перезавантажуйте пристрій.
    - **Linux / macOS:**
        1. Встановіть `dfu-util` менеджером пакунків (наприклад, `sudo apt install dfu-util`, `brew install dfu-util` або `pacman -Sy dfu-util`).
        2. Розпакуйте пакет релізу, відкрийте термінал у цій теці й виконайте:
            ```
            dfu-util --device 1fc9:000c --download hackrf_one_usb.dfu
            ```
        3. Після цього не від'єднуйте й не перезавантажуйте пристрій.
6. Запишіть прошивку Mayhem — **не від'єднуючи пристрій після кроку 5**:
    - **Windows:** знову запустіть `mayhem_flasher.bat` і дотримуйтесь підказок.
    - **Linux / macOS:**
        1. Встановіть хост-інструменти `hackrf` (наприклад, `sudo apt install hackrf`, `brew install hackrf` або `pacman -Sy hackrf`).

            > [!NOTE]
            > Стабільний репозиторій Ubuntu може містити застарілий пакет `hackrf`. Якщо виникають помилки, зберіть хост-інструменти з вихідного коду або використовуйте дистрибутив із «плаваючими» релізами.

        2. Розпакуйте пакет прошивки й виконайте (підставте ім'я файлу вашої версії):
            ```
            hackrf_spiflash -w portapack-h1_h2-mayhem.bin
            ```
7. Підготуйте SD-карту:
    1. Відформатуйте її у FAT32 на комп'ютері — див. [Як відформатувати SD-карту](How-to-Format-SDCard).
    2. Якщо ви завантажили `ppfw.tar`, розпакуйте його й скопіюйте весь вміст на SD-карту. Якщо завантажили окремий `COPY_TO_SDCARD.zip` — розпакуйте й скопіюйте його.
    3. Поки що не вставляйте SD-карту.
8. Якщо пристрій і досі не завантажується, виконайте кроки зі сторінки [Не завантажується](Won't-boot).
9. Вимкніть пристрій, зачекайте щонайменше 1 хвилину, потім вставте SD-карту й батарейку-таблетку.
10. Увімкніть пристрій, перейдіть у **Settings → P.Memory Mgmt → Reset P.Mem to defaults → YES**, потім вимкніть і зачекайте щонайменше 1 хвилину.
11. Якщо пристрій досі не завантажується правильно, повторіть кроки [Не завантажується](Won't-boot) (для правильного збереження конфігурації завантаження потрібні і SD-карта, і батарейка).
12. Увімкніть — повне скидання завершено.

## Примітки

- Якщо комп'ютер не розпізнає пристрій, хоч що б ви робили, спробуйте інший комп'ютер з Linux і щонайменше 5 різних USB-кабелів.
- Якщо прошивання через DFU в Linux не вдається, перевірте, що `dfu-util` оновлено.
- Як необов'язковий додатковий крок можна оновити Xilinx CPLD на платі HackRF: [Оновлення Xilinx CPLD](Updating-the-Xilinx-CPLD-on-hackrf-board).
- Якщо після повного скидання проблема залишилася, створіть issue на GitHub.
