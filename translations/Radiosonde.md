# Radiosonde (метеозонди)

![Radiosonde на пристрої](annotated/app-023.jpg){ width="360" }

*Скріншот з пристрою: [Приймачі: огляд застосунків](Screens-Receivers#shot-023).*

Приймає й декодує телеметрію метеорологічних радіозондів — повітряних куль, що під час підйому передають координати GPS, температуру, вологість та інші атмосферні дані.

## Огляд інтерфейсу

### Налаштування

- **Frequency** — частота для моніторингу. За замовчуванням **402,7 МГц** — основний міжнародний діапазон передавання радіозондів. Змінюється енкодером або цифровою клавіатурою.
- **RF Amp** (0 або 1) — вмикає/вимикає внутрішній ВЧ-підсилювач.
- **LNA gain** (0–40) — підсилення малошумного підсилювача. Див. [Проблеми з якістю приймання](Help!-Im-not-receiving-anything!---Receive-Quality-Issues#gain-settings).
- **VGA gain** (0–62) — підсилення підсилювача основної смуги.
- **RSSI** — індикатор сили сигналу.
- **Volume** — гучність звуку.

### Декодовані поля

Застосунок показує спільний набір полів для всіх типів зондів. Поля, недоступні для певного типу, показуються як `...`. Вертикальна швидкість обчислюється застосунком із послідовних значень висоти GPS і міток часу пакетів.

| Поле | Meteomodem M10 | Meteomodem M20 | Meteomodem M2K2 | Vaisala RS41-SG |
|-------|:--------------:|:--------------:|:---------------:|:---------------:|
| Тип | ✓ | ✓ | ✓ | ✓ |
| ID / серійний номер | ✓ | ✓ | — | ✓ |
| Дата й час | ✓ | ✓ | ✓ | ✓ |
| Напруга батареї | ✓ | ✓ | ✓ | ✓ |
| Номер кадру | — | ✓ | — | ✓ |
| Температура | ✓ | ✓ | — | ✓ |
| Вологість | ✓ | ✓ | — | ✓ |
| Тиск | — | ✓ | — | — |
| GPS (широта / довгота / висота) | ✓ | ✓ | ✓ | ✓ |
| Вертикальна швидкість | ✓ | ✓ | ✓ | ✓ |

### Прапорці

- **Log** — записує прийняті пакети на SD-карту. Щоразу під час відкриття застосунку створюється новий файл з міткою часу: `LOGS/SONDE_YYYYMMDD_HHMMSS.TXT`. Журнал містить «сирі» біти пакетів і мітку часу прийому.
- **CRC** — вмикає перевірку CRC. Коли активна, пакети з невірною контрольною сумою відкидаються, а не показуються. CRC підтримується для M10, M20 та RS41-SG; для M2K2 перевірка CRC не реалізована.

### Звуковий сигнал при пакеті

Під час прийому пакета застосунок подає звуковий сигнал, висота якого залежить від рівня RSSI. Ця поведінка керується глобальним параметром **Beep on packets** у [Settings → Audio](Settings#audio), а не прапорцем застосунку.

### Кнопки карти

- **See QR** — генерує QR-код `geo:широта,довгота` для останньої прийнятої позиції GPS. Відскануйте код смартфоном — відкриється картографічний застосунок на цих координатах.
- **See on map** — відкриває вбудовану карту світу з центром на останній прийнятій позиції GPS. Потрібен файл `world_map.bin` у теці `/ADSB/` на SD-карті.

### Збереження налаштувань

Стан прапорців Log і CRC зберігається в `rx_sonde.ini` на SD-карті, якщо в глобальному меню [Settings](Settings#app-settings) увімкнено **App Settings**.
