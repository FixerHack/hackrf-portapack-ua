# Remote (панель кнопок)

![Remote на пристрої](annotated/app-010.jpg){ width="360" }

*Скріншот з пристрою: [Трансівери, Recon, Capture…](Screens-Other#shot-010).*

Застосунок Remote дозволяє створити власну панель кнопок і прив'язати кожну до файлу запису для відтворення одним дотиком.

Файли `.REM` зберігаються в теці `REMOTES/` на SD-карті. Нові панелі автоматично називаються `REMOTE_0001.REM`, `REMOTE_0002.REM` тощо.

Це [зовнішній застосунок](External-apps-informations) (файл `.ppma` на SD-карті).

!!! danger "Передавання"
    Кнопки **передають** записані сигнали. Використовуйте лише з власними пристроями або з дозволу.

## Головний інтерфейс

- **Назва** — верхній рядок показує назву панелі. Виберіть, щоб перейменувати (до 30 символів).
- **Кнопки** — до 12 налаштовуваних кнопок у сітці 4×3. Виберіть кнопку, щоб передати її файл; вибір ще раз — зупинити. Довге натискання Select відкриває редагування кнопки.
- **Водоспад** — міні-водоспад під сіткою під час передавання.
- **Gain / Amp** — підсилення й ВЧ-підсилювач передавача (панель TX унизу).
- **Loop** — безперервно повторювати запис, доки не зупинити.
- **Ім'я файлу** — поточний файл панелі (без розширення). Виберіть, щоб перейменувати.
- **Кнопка «+»** — додати нову порожню кнопку.
- **Нова панель** — зберегти поточну й почати нову порожню.
- **Відкрити панель** — зберегти поточну й відкрити наявний `.REM` з `REMOTES/`.

Панелі зберігаються автоматично під час виходу.

## Редагування кнопки

- **Name** — підпис на кнопці (до 30 символів).
- **Path** — вибрати файл запису (`.C16` / `.C8`) з `CAPTURES/`.
- **Freq** — центральна частота передавання (за замовчуванням із метаданих файлу або поточна частота TX).
- **Rate** — частота дискретизації з метаданих (або 500 ksps). Лише показ.
- **Icon** — значок на кнопці (0 = без значка; 1–24 — з набору).
- **FG Color** / **BG Color** — колір тексту/значка та тла (0–20).
- **Preview** — живий перегляд кнопки.
- **Trash (червоний)** — видалити кнопку після підтвердження.
- **Done** — зберегти зміни.

## Формат файлу .REM

Файли панелей — звичайний текст, редагуються будь-яким редактором. Порожні рядки й рядки з `#` ігноруються. Перший значущий рядок — **назва** панелі. Кожен наступний (до 12) описує одну кнопку:

```
шлях_запису,назва_кнопки,індекс_значка,індекс_тла,індекс_тексту,частота_гц,частота_дискретизації
```

Приклад:

```
My Remote
CAPTURES/door.C16,Door,6,3,1,433920000,500000
CAPTURES/lock.C16,Lock,0,17,1,433920000,500000
```

Порядок кнопок на екрані відповідає порядку рядків, тож кнопки можна переставляти, змінюючи порядок рядків.

## Поради

- Утилітою [IQ Trim](IQ-trim) обріжте тишу із записів, щоб вони передавалися миттєво.
- Якщо поруч із записом є файл метаданих `.txt`, його частота й частота дискретизації використовуються автоматично.
