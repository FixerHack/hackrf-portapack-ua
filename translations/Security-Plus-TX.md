# Security+ TX (гаражні ворота Chamberlain/LiftMaster)

Передає сигнали з плаваючим кодом **Security+ 2.0**, які використовують відчинювачі гаражних воріт і приводи воріт Chamberlain, LiftMaster і Craftsman.

Це [зовнішній застосунок](External-apps-informations); має бути на SD-карті в теці `APPS/`.

!!! danger "Юридичне попередження"
    Передавання сигналів до воріт чи приводів, якими ви не володієте, незаконне. Використовуйте лише з власним обладнанням для легітимного тестування безпеки.

## Можливості

- Кодує й передає пакети з плаваючим кодом Security+ 2.0 (двопакетний кадр, манчестерський OOK);
- плаваючий код автоматично збільшується після кожної передачі, щоб лишатися синхронним із приймачем;
- необов'язкове поле даних;
- режим навчання (пара без збільшення плаваючого коду);
- збереження/завантаження конфігурацій із файлів `.SECPLUS`.

## Протокол

Security+ 2.0 використовує OOK з манчестерським кодуванням на 4000 біт/с на 315 МГц. Кожна передача — два пакети поспіль; уся передача повторюється **3 рази**. Плаваючий код — 28-бітовий лічильник, фіксований код — 40-бітовий ідентифікатор. Плаваючий код має лишатися в межах вікна синхронізації приймача (зазвичай ±256 від останнього прийнятого значення).

## Елементи керування

| Елемент | Опис |
|---|---|
| **Open** | Відкрити `.SECPLUS` із теки `SECPLUS/` |
| **Save** | Зберегти поточні дані у файл |
| **Name** | Назва пульта |
| **Fixed** | 40-бітовий фіксований код (hex, 10 цифр) |
| **Rolling** | 28-бітовий плаваючий код (hex, 7 цифр) |
| **Data** | Необов'язкове 32-бітове навантаження (прапорець Data) |
| **Learn** | Плаваючий код **не** збільшується після TX (для пари чи повтору) |
| **Autosave** | Автозбереження файлу після кожної передачі (за замовчуванням) |

Стандартні елементи передавача (частота, LNA, VGA, AMP, TX) — унизу.

## Файл .SECPLUS

Один рядок CSV: `version;name;has_data;fixed_code;rolling_code;data`. Приклад: `2;MyGarage;0;1A2B3C4D5E;0001F4;00000000`. Файл `SECPLUS/DEFAULT.SECPLUS` створюється автоматично при першому запуску.
