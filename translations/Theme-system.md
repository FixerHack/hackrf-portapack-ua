# Система тем

У PortaPack є система тем, щоб кожен застосунок міг використовувати одну палітру кольорів, яку користувач може змінити.

## Використання

Важливо користуватися цією системою заради однакового UI. Є випадки, коли потрібні конкретні кольори (наприклад, у водоспаді) — тоді використовуйте їх.

Щоб скористатися системою, підключіть **theme.hpp** і замість `Color::grey()` тощо використовуйте відповідний об'єкт теми. Наприклад, підписи зазвичай були LightGrey; тепер використовуйте світлий колір переднього плану шаблону:

```cpp
Theme::getInstance()->fg_light
```

Стилі здебільшого починаються з `fg_` (foreground, передній план) або `bg_` (background, фон) і мають рівні: light, medium, dark, darker, darkest. Якщо вам важливо, щоб передній план кнопки був світлим, використовуйте `fg_light` — тоді передній план буде світлим, а фон — таким, що добре читається.

Є спеціальні кольори для станів «помилка», «попередження», «ок»: `error_dark`, `warning_dark`, `ok_dark`. Є й стилі кольорів: `fg_red`, `fg_green`, `fg_yellow`, `fg_orange`… Використовуйте їх, бо тема може перевизначати колір: у «червоній темі» колір 255,0,0 може бути іншим для кращого контрасту. Якщо використати `Color::red()`, він може читатися гірше, ніж `fg_red` теми.

Якщо використовуєте колір теми, наприклад `fg_red->foreground`, використовуйте і його фоновий відповідник `fg_red->background`. Фон застосунку зазвичай `bg_darkest->background`.

Стилі не обов'язково використовувати як об'єкт стилю. Для підписів можна вказати лише колір переднього плану: `Theme::getInstance()->fg_light->foreground`, а для фону — `Theme::getInstance()->bg_darkest->background`.

## Створення нової теми

1. Відкрийте `theme.hpp` і додайте новий клас, похідний від `ThemeTemplate`:
   ```cpp
   class ThemeMyNewTheme : public ThemeTemplate {
      public:
       ThemeMyNewTheme();
   };
   ```
2. Додайте його в enum `ThemeId` усередині класу `Theme`, **перед** `MAX`.
3. У `theme.cpp` додайте блок `case` для нового enum у функції `Theme::SetTheme()`.
4. Реалізуйте конструктор класу й створіть **кожен** елемент! Якщо забудете хоч один — тема «покладе» PortaPack. Найкраще — скопіювати наявну тему й змінити в ній кольори.
5. Завжди перевіряйте тему всюди: відкрийте кожен застосунок і шукайте відсутні чи нечитабельні тексти.
