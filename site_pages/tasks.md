# Завдання для вас

На цій сторінці зібрано все, що потрібно від вас, щоб документація стала точнішою. Сторінка оновлюється разом із сайтом.

**Як відповідати:** пишіть мені номер завдання та відповідь, наприклад: *«З-1.2: це перемикач звуку, при натисканні стає червоним»*. Файли (скріни, фото) надсилайте архівом, як раніше. В імені файлу, якщо можна, вкажіть номер завдання: `З-2.3_audio.png`.

**Статуси:** 🔴 — потрібно зараз · 🟡 — бажано · 🟢 — виконано.

---

## З-0. Як робити знімки екрана без камери (прочитайте спершу)

Знімки, зроблені самим пристроєм, чіткіші за фото й мають однаковий масштаб, тож рамки й стрілки ставляться точно.

1. Відкрийте потрібний екран.
2. Торкніться значка **камери** в рядку заголовка (див. [Інтерфейс на вашому пристрої](ui-guide.md), значок №2).
3. Знімок збережеться на SD-карту в теку **`SCREENSHOTS`** у форматі PNG (`SCR_0001.PNG`, `SCR_0002.PNG` …).
4. Підключіть SD-карту до комп'ютера (або застосунок **SD Over USB**) і скопіюйте теку.
5. Запишіть, який номер файлу до якого завдання (можна просто в текстовому файлі поруч).

> Якщо значок камери не видно — ввімкніть його: **Settings → User Interface → Show/Hide Status Icons**.

## З-2. Знімки екранів «у роботі» 🔴

Зараз більшість екранів знято в стані очікування — списки порожні, графіків немає. Щоб пояснити, **як виглядає результат**, потрібні знімки під час реального приймання. Порядок важливості — зверху вниз. Приймання (RX) законне; передавати нічого не потрібно.

| № | Застосунок | Що зняти | Підказка, як отримати сигнал |
|---|---|---|---|
| З-2.1 | **Audio** | водоспад з FM-станцією, режим WFM | 88–108 МГц, будь-яка місцева FM-станція |
| З-2.2 | **Looking Glass** | водоспад діапазону з активністю | пресет або MIN 88 / MAX 108 |
| З-2.3 | **Capture** | процес запису (червона кнопка натиснута) + файл у теці CAPTURES | будь-яка FM-станція, Rate 500k |
| З-2.4 | **Replay** | екран з відкритим записом із З-2.3 (не натискайте старт!) | відкрийте файл кнопкою «додати» |
| З-2.5 | **ADS-B RX** | список літаків + екран деталей одного літака + карта | 1090 МГц, AMP=1, біля вікна |
| З-2.6 | **SubGhzD** | список розпізнаних пультів + екран деталей | натисніть ваш пульт воріт/шлагбаума/брелок поруч (433,92 МГц) |
| З-2.7 | **Weather** | список метеодатчиків | 433,92 МГц, якщо поруч є бездротова метеостанція |
| З-2.8 | **TPMS RX** | список датчиків шин | 433,9 МГц біля машини, що рухається / щойно зупинилась |
| З-2.9 | **BLE RX** | екран деталей одного пристрою (натиснути на рядок) | будь-який телефон із Bluetooth поруч |
| З-2.10 | **Level** | графік з сигналом (FM-станція) | будь-яка FM-станція |
| З-2.11 | **Search** | знайдений сигнал (Locked!) та журнал | діапазон 88–108 МГц |
| З-2.12 | **Scanner** | зелені цифри — захоплений сигнал | `LOAD` → FM_STANDARD_BAND.TXT |
| З-2.13 | **Recon** | знайдений сигнал | будь-який діапазон з активністю |
| З-2.14 | **Radio** | збережені слоти з частотами | збережіть 2–3 FM-станції кнопкою Save |
| З-2.15 | **POCSAG RX** | прийняте повідомлення (якщо є в регіоні) | можна пропустити, якщо пейджерів немає |
| З-2.16 | **Radiosonde** | прийнятий зонд (якщо пощастить) | 400–406 МГц, зонди запускають о 00 і 12 UTC |

Для кожного пункту достатньо 1–3 знімків.
