# Stealth Mode

Stealth mode is a toggle in the [[Title-Bar|title bar]]. When the icon is highlighted green, stealth mode is active.

## What it does

When stealth mode is enabled and a transmission is started, the screen backlight turns off automatically. The **TX LED** blinks once per second during the transmission to indicate that the device is active.

To turn the backlight back on, press any hardware button or turn the encoder. Touching the screen is not sufficient — only physical button presses and encoder movement will wake the display.

## Enabling and disabling

Tap the stealth icon in the title bar to toggle stealth mode on or off. When enabling it for the first time, a confirmation dialog appears:

> *"You just enabled stealth mode. When you transmit, screen will turn off."*

The setting is stored in persistent memory and survives reboots.

> [!NOTE]
> The stealth icon can be hidden from the title bar via **Settings → User Interface** (the "Stealth" toggle in the hide/show icons list). Even when hidden, the setting itself remains active if it was previously enabled.re upgrade.
