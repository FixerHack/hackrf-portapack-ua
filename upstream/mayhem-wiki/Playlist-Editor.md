This is an [external app](External-apps-informations) (`.ppma` file on the SD card).

# Introduction

That application allows you to create/modify playlists.

# How to use

- Open an existing playlist, or create a new playlist from scratch
- Edit items and/or insert some new ones
- Save playlist

# Edit/Insert fields

- Delay: use rotary encoder to adjust delay
- Browse: select capture file to replay
- Input Delay: set a custom delay using the keyboard instead of using the rotary encoder
