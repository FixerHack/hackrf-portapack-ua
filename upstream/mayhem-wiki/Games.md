Mayhem includes several games and visual demos playable directly on the PortaPack without any radio activity.

| App | Description |
|-----|-------------|
| [2048](2048) | Sliding tile puzzle — merge matching tiles to reach 2048 |
| [Battleship](Battleship) | Two-player naval strategy game played over RF between two PortaPack devices using POCSAG2 |
| [Blackjack](Blackjack) | Classic casino card game against an automated dealer |
| [Breakout](Breakout) | Classic brick-breaking arcade game |
| [Digital Rain](Digital-Rain) | Matrix-style falling character screensaver — no interaction, press back to exit |
| [Dino Game](Dino-Game) | Endless runner — jump and duck to avoid obstacles |
| [Doom](Doom) | Port of the classic first-person shooter |
| [Morse P](Morse-P) | Morse code keying trainer with automatic dit/dah detection and audio feedback |
| [Pac‐Man](Pac%E2%80%90Man) | Classic maze arcade game |
| [Snake](Snake) | Classic snake game |
| [Space Invaders](Space-Invaders) | Classic fixed-shooter arcade game with Easy/Hard difficulty |
| [Tetris](Tetris) | Classic falling block puzzle game |
