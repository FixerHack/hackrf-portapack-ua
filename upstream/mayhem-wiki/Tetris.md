# Introduction

The classic Tetris game ! Select the level using the arrow keys or the rotary encoder, press 'select' to start !

# Controls
- Move the blocks using the arrow keys
- Rotate the blocks using 'select' key or the rotary encoder
- Simultaneously press key 'left' and key 'up' => put the focus on the hidden 'go back to main menu' icon on the top right part of the screen, click 'select' key to exit the game
