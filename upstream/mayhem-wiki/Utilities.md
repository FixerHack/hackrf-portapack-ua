The Utilities category contains tools and helper applications. Apps marked with ⬡ are external apps stored as `.ppma` files on the SD card and must match the currently running firmware version.

* [Antenna Length](https://github.com/portapack-mayhem/mayhem-firmware/wiki/antennas) ⬡ — Calculates antenna lengths for common antenna types.
* [Calculator](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Calculator) ⬡ — General-purpose calculator.
* [Cart Lock](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Cart-Lock) ⬡ — Shopping cart lock transmitter.
* [Debug](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Debug) — Hardware and software diagnostic tools.
* [File Manager](https://github.com/portapack-mayhem/mayhem-firmware/wiki/File-manager) — Browse, copy, move, rename and delete files on the SD card.
* [Flash Utility](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Flash-Utility) — Flash firmware images stored on the SD card.
* [Freq. Manager](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Freq-manager) — Manage saved frequency lists (freqman files).
* [IQ Trim](https://github.com/portapack-mayhem/mayhem-firmware/wiki/IQ-trim) — Trim silence from the start and end of capture files.
* [Metronome](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Metronome) ⬡ — Audible metronome with adjustable tempo.
* [Notepad](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Notepad) — Simple text editor for reading and writing files on the SD card.
* [Playlist Editor](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Playlist-Editor) ⬡ — Create and edit `.PPL` playlist files for the Replay app.
* [Rand Pwd](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Random-password) ⬡ — Generates random passwords.
* [SD Over USB](https://github.com/portapack-mayhem/mayhem-firmware/wiki/SD-Over-USB) ⬡ — Exposes the SD card as a USB mass-storage device.
* [Stopwatch](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Stopwatch) ⬡ — Stopwatch and timer.
* [Tuner](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Tuner) ⬡ — Audio frequency tuner.
* [WardriveMap](https://github.com/portapack-mayhem/mayhem-firmware/wiki/WardriveMap) ⬡ — Displays GPS wardriving logs on a map.
* [Waterfall Designer](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Waterfall-Designer) ⬡ — Customize the waterfall display color scheme.
* [WAV Viewer](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Wav-viewer) ⬡ — Play and inspect WAV audio files from the SD card.
* [Wipe SD Card](https://github.com/portapack-mayhem/mayhem-firmware/wiki/Wipe-SD-Card) ⬡ — Securely erases the SD card.
