# Waterfalls color schemes

You can change the waterfalls color scheme by going through Utilities-->File Manager into WATERFALLS directory and select one of the file with the middle button.

If you want to revert to the default scheme, apply the default.txt setting or delete waterfall.txt file at the root of the sdcard.

# Create your own

- Add a new file in WATERFALLS
- Add colors lines (index,R,G,B)
- all settings range from 0 to 255 (index included)
- Generated colors are gradients between the set of 'index,R,G,B' lines
- Support comments with lines starting with '#'

You can have a look at the files, particularly the default.txt which also contain the formatting informations mentioned here.
