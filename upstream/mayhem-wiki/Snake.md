# Introduction

- Snake game by RocketGod (@rocketgod-git) https://betaskynet.com

It's like the name says: the snake game :-)

You are starting as a single block snake. Eat the fruits to get it longer!!

# Controls
- 'select' to start the party
- Use the arrow keys to change the direction of the snake
- Simultaneously press key 'left' and key 'up' => put the focus on the hidden 'go back to main menu' icon on the top right part of the screen, click 'select' key to exit the game or optionally tap the top left corner of the screen to exit.
