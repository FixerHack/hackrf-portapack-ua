Battleship is a two-player naval strategy game played over RF between two PortaPack devices. Each player places their ships on a grid, then takes turns calling coordinates to try to sink the opponent's fleet. Move data is transmitted and received wirelessly using the POCSAG2 baseband, making it the only multiplayer game in Mayhem that requires two devices and an RF link.

This is an [external app](External-apps-informations) (`.ppma` file on the SD card).

# Setup

1. Both players select a frequency and gain settings — these must match on both devices.
2. Each player selects a team colour: **Red** or **Blue**.
3. Ships are placed on the grid using the touchscreen or encoder knob.
4. Once both players are ready, the game begins.

# Controls

* **Touchscreen**: Tap to place ships and select coordinates during play.
* **Encoder knob**: Navigate the grid.
* **Left / Right / Up / Down buttons**: Move cursor.
* **Select**: Confirm action.

# RF Settings

* **Frequency**: Configurable — both devices must use the same frequency.
* **RF Amp**, **LNA**, **VGA**: Standard gain controls for TX and RX.

# Scoring

Wins and losses are tracked and displayed as `W:x L:x` on screen.
