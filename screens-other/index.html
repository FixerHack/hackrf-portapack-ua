    Трансівери, Recon, Capture, Replay та утиліти¶

    Скріншоти з вашого пристрою

    Усі знімки зроблено на HackRF One + PortaPack H2 з прошивкою Mayhem v2.4.0. Більшість застосунків показано у стані «за замовчуванням», до приймання чи передавання. Опис складено за вікі Mayhem та екранами; дрібні відмінності залежать від версії прошивки.

    Інші розділи головного меню: Transceiver, Recon, Capture, Replay, Remote, Looking Glass, Utilities (з меню Debug) і Games.

    Меню розділів¶

    Transceiver¶

    Пункти меню: Mic, KISS TNC.

    Елементи екрана:

    1. Назва розділу та значки стану
    2. Mic — голосовий трансівер (вибрано)
    3. KISS TNC — пакетний TNC
    4. NEXT › (на цій сторінці немає наступної)

    Utilities — сторінка 1¶

    Пункти меню: File Manager, Freq. Manager, IQ Trim, Notepad, Debug, Flash Utility, Antenna Length, Calculator, Metronome, PlaylistEdit, Rand Pwd, SD Over USB.

    Елементи екрана:

    1. Назва розділу та значки стану
    2. Вибрана кнопка (File Manager)
    3. Кнопки утиліт (2 стовпці)
    4. NEXT › — наступна сторінка

    Utilities — сторінка 2¶

    Пункти меню: Calculator, Metronome, PlaylistEdit, Rand Pwd, SD Over USB, Wipe SD card, Cart Lock, Stopwatch, Tuner, WAV Viewer, WardriveMap, Wt Design (Waterfall Designer).

    Елементи екрана:

    1. Назва розділу та значки стану
    2. Вибрана кнопка (Wt Design)
    3. Кнопки утиліт
    4. ‹ PREV — попередня сторінка

    Games¶

    Пункти меню: Battleship, Blackjack, Breakout, Dino Game, Doom, 2048, Morse P, Snake, Space Invaders, Tetris, DigitalRain, Pac-Man.

    Елементи екрана:

    1. Назва розділу та значки стану
    2. Вибрана кнопка (Battleship)
    3. Кнопки ігор
    4. NEXT › — наступна сторінка

    Трансівери¶

    Microphone (трансівер)¶

    Напівдуплексний голосовий трансівер: NFM, WFM, AM, USB, LSB, DSB-SC; PTT і VOX, CTCSS, Roger beep, окремі частоти TX/RX.

    • Кнопка PTT TX, TX-IQ-CAL, прапорці Roger beep, Hear Mic, RX audio.

    Докладніше на сторінці застосунку

    Елементи екрана:

    1. MIC-GAIN, Boost — підсилення мікрофона
    2. F — частота, TXBW — смуга TX, Gain, Amp, Mode
    3. VOX enable — автоматичне керування голосом
    4. LVL, ATT, DEC — параметри VOX
    5. TONE KEY (CTCSS), Roger beep, Hear Mic
    6. Receiver: RX audio, F RX=TX
    7. VOL, RXBW, F_RX, SQ (шумоподавлювач), LNA/VGA/AMP
    8. PTT TX — утримувати для передавання
    9. TX-IQ-CAL — калібрування
    10. Індикатор рівня мікрофона

    KISS TNC¶

    Контролер вузла терміналу в режимі KISS для пакетного радіозв'язку / APRS (AX.25).

    • Статус USB (Disconnected), лічильники RX/TX.

    Докладніше на сторінці застосунку

    Елементи екрана:

    1. Рядок заголовка
    2. Частота (144,39 МГц)
    3. AMP / LNA / VGA
    4. Listening — стан
    5. USB — стан зв'язку з комп'ютером (Disconnected)
    6. RX / TX — лічильники пакетів

    Recon, Capture, Replay, Remote, Looking Glass¶

    Recon¶

    Сканер частот і «мисливець за сигналами»: сканує списки частот та діапазони, реєструє знайдені сигнали.

    • Кнопки PAUSE, AUDIO, STORE, CONFIG, SEARCH, RECON.

    Докладніше на сторінці застосунку

    Елементи екрана:

    1. Рядок заголовка
    2. LNA / VGA / AMP — підсилення; VOL — гучність
    3. Поточний режим і список/діапазон, що скануються (RECON_RESULTS)
    4. Індикатор RSSI, номер знайденого / всього (2/22), рівень сигналу
    5. Поточна частота та рівні RSSI (поточний / середній / макс.)
    6. START / END — межі діапазону сканування
    7. RECON, LOOP, CONFIG, SEARCH — керування й налаштування
    8. Режим збігу, крок, смуга, поріг шумоподавлювача (SQUELCH)
    9. PAUSE, AUDIO, STORE, FW>, RST, MIC TX, REMOVE

    Replay¶

    Передає записані файли IQ (.C16/.C8/.CU8) або плейлисти .PPL.

    • Кнопки навігації між треками, додавання/видалення файлу, відкриття й збереження плейлиста; прапорець Loop.

    Докладніше на сторінці застосунку

    Елементи екрана:

    1. Рядок заголовка
    2. Частота (і частота дискретизації) поточного треку
    3. Індикатори прогресу: плейлист (верх) і файл (низ)
    4. Gain, Amp, Loop, ▶ Play/Stop
    5. Підказка: відкрийте плейлист або додайте запис
    6. ◄ ► трек, додати, видалити, відкрити та зберегти плейлист

    Capture¶

    Записує IQ-дані на SD-карту у форматі .C16 (або .C8) разом з метаданими.

    • Rate — частота дискретизації (рекомендовано ≤ 500 кГц), Format (C16/C8), Trim — автообрізання; червона кнопка запускає запис, нижче — водоспад.

    Докладніше на сторінці застосунку

    Елементи екрана:

    1. Рядок заголовка
    2. Частота запису, крок, підсилення AMP/LNA/VGA і RSSI
    3. Rate — частота дискретизації; Format — C16 або C8
    4. Trim — автообрізання; тривалість / вільне місце
    5. REC — червона кнопка запуску запису
    6. Водоспад спектра в смузі запису

    Remote¶

    Створює власну панель кнопок, прив'язаних до файлів запису для одним дотиком.

    • Файли .REM у теці REMOTES/; кнопки + (додати), Новий, Відкрити; прапорець Loop.

    Докладніше на сторінці застосунку

    Елементи екрана:

    1. Рядок заголовка
    2. Назва панелі () — вибрати, щоб перейменувати
    3. Поле кнопок панелі (до 12 кнопок 4×3); під час передавання — міні-водоспад
    4. Gain / Amp, Loop та ім'я файлу REMOTE_0000
    5. «+» додати кнопку, нова панель, відкрити панель

    Looking Glass¶

    Широкосмуговий спектр-водоспад по великому діапазону частот.

    • MIN/MAX/RANGE — межі діапазону, FILTER, PRESET, режими відображення SPECTR/LIVE-V/PEAK-V, F-/S- (швидко/точно).

    Докладніше на сторінці застосунку

    Елементи екрана:

    1. MIN / MAX — межі діапазону, LNA/VGA — підсилення
    2. RANGE — ширина діапазону; FILTER — згладжування; AMP
    3. PRESET — готові діапазони з SD-карти (Manual)
    4. bip — звуковий сигнал при виявленні
    5. MARKER — маркер частоти, переміщується енкодером
    6. RES — роздільність; VOL — гучність; режим F-SPCTR-V
    7. Область водоспаду (з'являється після початку сканування)

    Утиліти¶

    File Manager¶

    Файловий менеджер SD-карти: перегляд тек, копіювання, перейменування, видалення.

    • Показано кореневий каталог SD-карти (AIS, APPS, AUDIO, CAPTURES тощо) і кількість файлів у теках.

    Докладніше на сторінці застосунку

    Елементи екрана:

    1. Рядок заголовка
    2. Path — поточний шлях (корінь SD-карти)
    3. Вибрана тека (ADSB, 5 файлів)
    4. Список тек і файлів: назва та кількість елементів
    5. Created — дата створення вибраного
    6. Дії: вирізати, копіювати, вставити, видалити, перейменувати…
    7. Інші дії та Exit — вийти

    Freq. Manager¶

    Менеджер збережених частот (списки freqman): редагування частоти й опису.

    • Кнопки Edit, Frequency, Description, +, Exit.

    Докладніше на сторінці застосунку

    Елементи екрана:

    1. F: — вибраний файл частот (ACARS)
    2. Додати / видалити файл списку
    3. Список частот з описами (вибрана підсвічено)
    4. Edit — редагувати запис
    5. Frequency — змінити частоту
    6. Description — змінити опис
      • додати запис, × видалити запис
    8. Exit — вихід

    IQ Trim¶

    Обрізає записаний файл IQ, залишаючи лише корисну частину сигналу.

    • Capture File — файл, Start/End/Samples/Max Pwr/Cutoff/Amplify, кнопка Trim.

    Докладніше на сторінці застосунку

    Елементи екрана:

    1. Рядок заголовка
    2. Capture File — файл IQ
    3. Open File… — відкрити файл запису
    4. Start / End — межі корисної частини (у відліках)
    5. Samples, Max Pwr — кількість і потужність
    6. Cutoff — поріг відсікання (7%)
    7. Amplify — підсилення результату
    8. Trim — виконати обрізання

    Notepad¶

    Простий текстовий блокнот (наприклад, для файлу blacklist у SETTINGS).

    Докладніше на сторінці застосунку

    Елементи екрана:

    Докладніше на сторінці застосунку

    Елементи екрана:

    2. Піктограма руйнівної утиліти (червона)
