    Оновлення прошивки¶

    Пристрої HackRF постачаються з прошивкою у флеш-пам'яті SPI. Прошивку можна оновити за допомогою USB-кабелю та хост-комп'ютера.

    Ці інструкції дозволяють оновити прошивку, щоб скористатися новими можливостями чи виправленнями помилок.

    Оновлення прошивки SPI flash¶

    Щоб оновити прошивку HackRF Pro, скористайтеся програмою hackrf_spiflash:

    hackrf_spiflash -w hackrf_pro_usb.bin

    Двійковий файл прошивки (hackrf_pro_usb.bin) можна знайти в теці firmware-bin в останньому пакеті релізу або зібрати самостійно з вихідного коду. Для HackRF One чи інших платформ використовуйте файл «.bin» з відповідною назвою платформи, наприклад hackrf_one_usb.bin. Якщо збирати з вихідного коду, файл називатиметься hackrf_usb.bin.

    Програма hackrf_spiflash входить до складу hackrf-tools.

    Записуючи образ прошивки у SPI flash, обов'язково вибирайте прошивку з ім'ям файлу, що закінчується на «.bin».

    Після запису прошивки в SPI flash може знадобитися скинути пристрій HackRF, натиснувши кнопку RESET або від'єднавши та знову під'єднавши його.

    Якщо ви отримуєте помилку з HACKRF_ERROR_NOT_FOUND, це часто проблема з правами доступу в ОС.

    Лише за потреби: відновлення прошивки SPI flash¶

    Якщо прошивку, встановлену в SPI flash, пошкоджено, або ви програмуєте саморобний HackRF уперше, ви не зможете одразу скористатися програмою hackrf_spiflash, як описано вище. Виконайте такі кроки:

    1. Дотримуйтесь інструкцій із завантаження DFU, щоб запустити HackRF у режимі завантаження DFU.
    2. Введіть dfu-util --device 1fc9:000c --alt 0 --download hackrf_pro_usb.dfu, щоб завантажити прошивку з пакета релізу в ОЗП. Для HackRF One чи інших платформ використовуйте файл «.dfu» з відповідною назвою платформи, наприклад hackrf_one_usb.dfu.
    3. Виконайте описану вище процедуру оновлення прошивки SPI flash, щоб записати образ прошивки «.bin» у SPI flash.

    Лише за потреби: завантаження DFU¶

    Режим завантаження DFU зазвичай потрібен лише тоді, коли прошивка працює неправильно або її ніколи не встановлювали.

    Мікроконтролер LPC43xx на HackRF може завантажуватися з кількох джерел коду. За замовчуванням HackRF завантажується з флеш-пам'яті SPI (SPIFI). Також можна завантажити HackRF у режимі завантаження DFU (USB). У режимі завантаження DFU HackRF визначається в USB, чекає на код, що доставляється за стандартом DFU (Device Firmware Update) через USB, а потім виконує цей код із ОЗП. SPIFI у режимі DFU зазвичай не використовується і не змінюється.

    Щоб запустити HackRF Pro або HackRF One у режимі DFU, утримуйте кнопку DFU під час увімкнення живлення або під час натискання й відпускання кнопки RESET. Потім відпустіть кнопку DFU. На HackRF One має засвітитися світлодіод 3V3. На HackRF Pro усі світлодіоди мають залишатися вимкненими. Тепер HackRF готовий приймати прошивку через USB.

    Щоб запустити Jawbreaker у режимі DFU, замкніть два контакти на одній із колодок «BOOT», коли вперше подається живлення. Потрібно замкнути контакти 1 і 2 колодки P32 на Jawbreaker. Колодка P32 на більшості Jawbreaker позначена «P2_8», але на прототипах може бути позначена «2». Контакт 1 позначений «VCC». Контакт 2 — центральний. Після завантаження DFU має засвітитися VCCLED, а 1V8LED не світиться. Тепер Jawbreaker готовий приймати прошивку через USB.

    Через DFU слід використовувати лише образи прошивки з іменем файлу, що закінчується на «.dfu», а не «.bin».

    Отримання DFU-Util¶

    На свіжих встановленнях ОС може знадобитися отримати копію DFU-Util. У більшості дистрибутивів Linux вона доступна як пакет, наприклад на Debian/Ubuntu:

    sudo apt-get install dfu-util

    Якщо ви користуєтеся платформою без пакета dfu-util, інструкції зі збирання є на сторінці збирання dfu-util на SourceForge.

    cd ~
sudo apt-get build-dep dfu-util
sudo apt-get install libusb-1.0-0-dev
git clone git://git.code.sf.net/p/dfu-util/dfu-util
cd dfu-util
./autogen.sh
./configure
make
sudo make install

    Тепер у вашій системі встановлено поточну версію DFU Util.

    Оновлення CPLD¶

    Старіші версії прошивки HackRF (до релізу 2021.03.1) вимагають додаткового кроку для запису бітового потоку в CPLD.

    Щоб оновити образ CPLD, спершу оновіть прошивку SPI flash, libhackrf і hackrf-tools до встановлюваної версії. Потім:

    hackrf_cpldjtag -x firmware/cpld/sgpio_if/default.xsvf

    Через кілька секунд три світлодіоди мають почати блимати. Це означає, що CPLD успішно запрограмовано. Скиньте пристрій HackRF, натиснувши кнопку RESET або від'єднавши та знову під'єднавши його.
